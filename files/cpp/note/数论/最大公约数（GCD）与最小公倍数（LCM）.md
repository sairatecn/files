# 最大公约数（GCD）与最小公倍数（LCM）

## 1. 基本定义

- **最大公约数（GCD）**：能同时整除两个或多个整数的最大正整数。记作 `gcd(a, b)`。
- **最小公倍数（LCM）**：能同时被两个或多个整数整除的最小正整数。记作 `lcm(a, b)`。
- **核心关系**：  
  $$
  \text{lcm}(a, b) = \frac{|a \times b|}{\text{gcd}(a, b)}
  $$
  注意乘法可能溢出，建议用 `a // gcd * b` 计算。

---

## 2. 朴素算法（枚举法）

**思路**：从较小的数开始，递减检查每个数能否同时整除两个数，第一个满足条件的即为 GCD。

**示例**：求 gcd(146, 89)  
从 89 往下枚举，直到找到能同时整除 146 和 89 的数（此处为 1）。

**复杂度**：O(min(a, b))，适合极小数值。

---

## 3. 辗转相除法（欧几里得算法）

**定理**：`gcd(a, b) = gcd(b, a % b)`，反复迭代直到余数为 0，此时除数为 GCD。

**计算过程**（146, 89）：
```
146 = 89×1 + 57
89  = 57×1 + 32
57  = 32×1 + 25
32  = 25×1 + 7
25  = 7×3  + 4
7   = 4×1  + 3
4   = 3×1  + 1
3   = 1×3  + 0   → 余数为 0，除数为 1 → gcd = 1
```

**Python 实现**（迭代）：
```python
def gcd(a, b):
    a, b = abs(a), abs(b)
    while b != 0:
        a, b = b, a % b
    return a
```

**递归版**：
```python
def gcd(a, b):
    return abs(a) if b == 0 else gcd(b, a % b)
```

**复杂度**：O(log min(a, b))，高效通用。

---

## 4. 最小公倍数计算

利用 GCD 快速得到 LCM：
```python
def lcm(a, b):
    return abs(a) // gcd(a, b) * abs(b)
```

对于多个数，两两迭代即可。

---

## 5. 扩展与备注

- 辗转相除法也适用于大整数，是竞赛和工程中的标准方法。
- 可扩展为**扩展欧几里得算法**，用于求解 `ax + by = gcd(a, b)` 的整数解，在密码学中常见。
- 内置函数：Python 的 `math.gcd()`，C++ 的 `std::gcd()` 可直接使用。
