# 判断数正负

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $N$ ，判断其正负性：

- 若 $N>0$ ，输出 positive；
- 若 $N=0$ ，输出 zero；
- 若 $N<0$ ，输出 negative。

## 输入描述

一行包含一个整数 $N$ 。

## 输出描述

根据 $N$ 的取值输出对应的字符串。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
positive
```
## 题解

### 解题思路

根据整数 `N` 的正负性分三种情况输出不同的字符串，是典型的单变量多分支判断问题。由于三种情况互斥且覆盖所有可能，用 `if-else` 三段式即可直接对应题意。

### 算法分析

1. 读入整数 `N`。
2. 若 `N > 0` 输出 `positive`；否则若 `N == 0` 输出 `zero`；否则（即 `N < 0`）输出 `negative`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n > 0) {            // 正数
        cout << "positive" << endl;
    } else if (n == 0) {    // 零
        cout << "zero" << endl;
    } else {                // 负数
        cout << "negative" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，只做一次判断。
- **空间复杂度**：$O(1)$。
