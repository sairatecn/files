# 最大数输出

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入三个整数，输出其中的最大整数。

## 输入描述

一行，包含三个整数，数与数之间以一个空格分开。

## 输出描述

输出一行，包含一个整数，即三个数中的最大值。

## 示例

### 用例输入 1

```text
10 20 56
```

### 用例输出 1

```text
56
```
## 题解

### 解题思路

在三个数中找最大值，用一个变量 `mx` 初值设为第一个数，再依次与另外两个数比较并更新，即可在不排序的情况下得到最大值。

### 算法分析

1. 读入 `a`、`b`、`c`。
2. `mx = a`；若 `b > mx` 则 `mx = b`；若 `c > mx` 则 `mx = c`。
3. 输出 `mx`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int mx = a;          // 先假设第一个数最大
    if (b > mx) mx = b;  // 与第二个数比较
    if (c > mx) mx = c;  // 与第三个数比较
    cout << mx << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定比较两次。
- **空间复杂度**：$O(1)$。
