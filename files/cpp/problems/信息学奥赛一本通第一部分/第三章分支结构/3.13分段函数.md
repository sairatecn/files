# 分段函数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

编写程序，计算下列分段函数 $y=f(x)$ 的值，结果保留到小数点后三位。

## 输入描述

一个浮点数 $x$ (0≤x<20)。

## 输出描述

输出 $f(x)$ ，结果保留到小数点后三位。

## 示例

### 用例输入 1

```text
1.0
```

### 用例输出 1

```text
1.500
```
## 题解

### 解题思路

根据自变量 `x` 所在的区间，套用对应的表达式计算 `y`，属于典型的多区间 `if-else` 分支问题。注意区间端点：题目给定 $0 \le x < 20$，且相邻区间首尾相接（$<5$、$<10$、其余 $\ge 10$），用依次缩小的判断条件即可无缝覆盖，结果保留 3 位小数。

### 算法分析

1. 读入浮点数 `x`。
2. 若 `x < 5`：`y = -x + 2.5`；
   否则若 `x < 10`：`y = 2 - 1.5 * (x-3)^2`；
   否则（`10 <= x < 20`）：`y = x * x - 1.5`。
3. 以定点方式保留 3 位小数输出 `y`。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x;
    cin >> x;
    double y;
    if (x < 5) {
        y = -x + 2.5;                    // 第 1 段
    } else if (x < 10) {
        y = 2 - 1.5 * (x - 3) * (x - 3); // 第 2 段：(x-3)^2 用连乘表示
    } else {
        y = x * x - 1.5;                 // 第 3 段
    }
    cout << fixed << setprecision(3) << y << endl;  // 保留 3 位小数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
