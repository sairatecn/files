# 求一元二次方程

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

利用公式 $x1=−b+b2−4ac2ax_1=\frac{-b+\sqrt{b^2-4ac}}{2a}x1​=2a−b+b2−4ac​​$ , $x2=−b−b2−4ac2ax_2=\frac{-b-\sqrt{b^2-4ac}}{2a}x2​=2a−b−b2−4ac​​$ 求一元二次方程 $ax2+bx+c=0ax^2+bx+c=0ax2+bx+c=0$ 的根， $a≠0a\neq 0a=0$ 。结果保留到小数点后5位。
输出形式：

- 若两个实根相等，输出 $x1=x2=...x_1=x_2=...x1​=x2​=...$ ;
- 若两个实根不等，小者在前，输出 $x1=...;x2=...x_1=...;x_2=...x1​=...;x2​=...$ ;
- 若无实根，输出’No answer!’

## 输入描述

输入一行，包含三个浮点数 $a,b,c$ ，以空格分开。

## 输出描述

输出一行，表示方程的解，精确到小数点后5位。

## 示例

### 用例输入 1

```text
-15.97 19.69 12.02
```

### 用例输出 1

```text
x1=-0.44781;x2=1.68075
```
## 题解

### 解题思路

先算判别式 $\Delta = b^2 - 4ac$：
- $\Delta < 0$：无实根，输出 `No answer!`；
- $\Delta \ge 0$：用求根公式算出两根，按从小到大排序后输出；
- 两根相等时按 `x1=x2=...` 格式输出。
结果统一保留小数点后 5 位。注意 `a` 可能为负，需比较两根大小后保证 `x1 <= x2`。

### 算法分析

1. 读入 `a`、`b`、`c`（浮点数）。
2. `delta = b*b - 4*a*c`。
3. 若 `delta < 0` 输出 `No answer!`。
4. 否则 `x1 = (-b - sqrt(delta)) / (2a)`，`x2 = (-b + sqrt(delta)) / (2a)`；若 `x1 > x2` 交换二者。
5. 若两根近乎相等（`fabs(x1-x2) < 1e-8`）输出 `x1=x2=...`，否则输出 `x1=...;x2=...`（保留 5 位小数）。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    double a, b, c;
    cin >> a >> b >> c;
    double delta = b * b - 4 * a * c;  // 判别式

    if (delta < 0) {
        cout << "No answer!" << endl;  // 无实根
    } else {
        double x1 = (-b - sqrt(delta)) / (2 * a);
        double x2 = (-b + sqrt(delta)) / (2 * a);
        if (x1 > x2) {                 // 保证 x1 为较小根
            double t = x1; x1 = x2; x2 = t;
        }
        cout << fixed << setprecision(5);  // 保留 5 位小数
        if (fabs(x1 - x2) < 1e-8) {
            cout << "x1=x2=" << x1 << endl;
        } else {
            cout << "x1=" << x1 << ";x2=" << x2 << endl;
        }
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
