# 整数大小比较

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入两个整数 $x$ 和 $y$ ，比较它们的大小关系：

- 若 $x>yx > yx>y$ ，输出字符 >
- 若 $x=yx = yx=y$ ，输出字符 =
- 若 $x<yx < yx<y$ ，输出字符 <

## 输入描述

- 一行，包含两个整数 $x$ 和 $y$ ，中间用单个空格隔开。
- 数据范围： $0≤x<2320 \le x < 2^{32}0≤x<232$ ， $−231≤y<231-2^{31} \le y < 2^{31}−231≤y<231$ 。

## 输出描述

- 输出一个字符，表示 $x$ 与 $y$ 的大小关系。

## 示例

### 用例输入 1

```text
1000 100
```

### 用例输出 1

```text
>
```
## 题解

### 解题思路

读入两个整数 `x`、`y`，用 `if-else` 三分支比较二者大小并输出对应的关系字符。注意数据范围：`x` 可达 $2^{32}-1$，`y` 可为负，均超出 32 位有符号 `int` 上限，因此用 `long long` 存储最稳妥。

### 算法分析

1. 读入 `x`、`y`（用 `long long`）。
2. `x > y` 输出 `>`；`x == y` 输出 `=`；否则输出 `<`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    long long x, y;       // 范围跨越正负且 x 可达 2^32-1，用 long long
    cin >> x >> y;
    if (x > y) {
        cout << ">" << endl;
    } else if (x == y) {
        cout << "=" << endl;
    } else {
        cout << "<" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
