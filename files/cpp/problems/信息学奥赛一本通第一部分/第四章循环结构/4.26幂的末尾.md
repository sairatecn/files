# 幂的末尾

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定两个正整数 $a,ba, ba,b$ ，求 $aba^bab$ 的末三位数字。从高位到低位输出，中间无分隔符，不足三位在前面补零。

## 输入描述

输入一行，包含两个正整数 $a,ba, ba,b$ ，满足 $1≤a≤100,1≤b≤100001 \le a \le 100, 1 \le b \le 100001≤a≤100,1≤b≤10000$ 。

## 输出描述

输出 $aba^bab$ 的末三位数字，前导补零。

## 示例

### 用例输入 1

```text
7 2011
```

### 用例输出 1

```text
743
```

---

## 题解

### 解题思路

求 $a^b$ 的末三位数字，等价于每次乘法后对 1000 取模。用循环逐步累乘并取模即可。输出时需补零至 3 位。

### 算法分析

1. 读入 $a$ 和 $b$。
2. 定义 `result = 1`，循环 $b$ 次每次 `result = (result * a) % 1000`。
3. 输出 `result`，用 `printf("%03d")` 或 `setw(3) << setfill('0')` 补零。

### 参考代码（C++）

```cpp
// 算法思路：a^b 在 b 最大 10000 时是天文数字，任何内置整型都存不下，不能先求幂再取末三位。
// 但「末三位」本质就是对 1000 取余，而同余性质保证 (x*y) mod m = ((x mod m)*(y mod m)) mod m，
// 也就是说取模可以提前做：每乘一次 a 就立刻对 1000 取余，只保留末三位继续参与下一次乘法，
// 这样中间结果永远小于 1000，既不会溢出，最终得到的余数也正是 a^b 的末三位。
// 最后由于结果可能不足三位（如 43、7），输出时要用补零控制符补足到 3 位。
#include <iostream>
#include <iomanip>          // 提供 setfill / setw，用于输出时补前导零
using namespace std;

int main() {
    int a, b;                       // a：底数（1 <= a <= 100）；b：指数（1 <= b <= 10000）
    cin >> a >> b;                  // 读入 a 和 b
    int result = 1;                 // result：始终保存当前累乘结果的末三位，初值为 1
    // 循环 b 次，每一次代表再乘上一个 a，循环结束时就完成了 a 自乘 b 次
    for (int i = 0; i < b; i++) {
        // a % 1000 先把底数缩到三位以内（本题 a<=100 本就不超，写上更通用）；
        // 相乘后再 % 1000 砍掉高位，只留末三位。
        // 最大中间值不超过 999*999 = 998001，远小于 int 上限，因此不会溢出
        result = (result * (a % 1000)) % 1000;
    }
    // setfill('0') 指定填充字符为 '0'，setw(3) 指定输出宽度为 3，
    // 二者配合即可把 43 输出成 043、把 7 输出成 007，满足「不足三位前面补零」的要求
    cout << setfill('0') << setw(3) << result << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(b)$，$b \le 10000$。
- **空间复杂度**：$O(1)$。
