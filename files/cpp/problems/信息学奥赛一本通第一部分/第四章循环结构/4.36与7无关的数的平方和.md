# 与7无关的数的平方和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个正整数 $n$ $(n<100)$ ，求所有小于等于 $n$ 的与7无关的正整数的平方和。一个正整数，如果能被7整除，或者它的十进制表示法中某一位上的数字为7，则称其为与7相关的数。与7无关的数是指不满足上述条件的数。

## 输入描述

一个正整数 $n$ $(n<100)$ 。

## 输出描述

输出小于等于 $n$ 的所有与7无关的正整数的平方和。

## 示例

### 用例输入 1

```text
20
```

### 用例输出 1

```text
2336
```

---

## 题解

### 解题思路

遍历 1 到 $n$ 的每个数，判断它是否"与7无关"：① 不能被 7 整除；② 十进制表示中任何一位都不含数字 7。满足条件的数将其平方累加。

### 算法分析

1. 读入 $n$，定义 `sum = 0`。
2. 遍历 $i$ 从 1 到 $n$：
   - 若 $i \bmod 7 == 0$，跳过。
   - 逐位检查 $i$ 的每一位是否含 7，若含则跳过。
   - 否则 `sum += i * i`。
3. 输出 `sum`。

### 参考代码（C++）

```cpp
// 【整体思路】枚举法：把 1..n 的每个整数都拿出来做一次“与 7 无关”的检验。
// “与 7 相关”有两种情况：① 能被 7 整除（i % 7 == 0）；② 十进制某一位上的数字是 7。
// 只要这两条都不满足，这个数就是“与 7 无关”的，把它的平方累加到答案里。
// 判断“某一位是 7”的通用手法是数位拆分：反复 %10 取出个位、再 /10 去掉个位，直到数变成 0。
#include <iostream>
using namespace std;

int main() {
    int n;                                  // n：题目给定的上界，枚举范围是 1..n（n < 100）
    cin >> n;                               // 读入上界 n
    long long sum = 0;                      // sum：与 7 无关的数的平方和；用 long long 防止累加溢出，且必须初始化为 0
    for (int i = 1; i <= n; i++) {          // 外层循环：让 i 依次取遍 1,2,3,...,n，逐个检验每一个候选数
        if (i % 7 == 0) continue;           // 条件①：i 能被 7 整除 → 与 7 相关，用 continue 跳过本次循环、不累加
        bool has7 = false;                  // has7：标记变量，表示 i 的各个数位中是否出现过数字 7，初始假设没有
        int temp = i;                       // temp：i 的副本，专门用来做数位拆分（不能直接改 i，否则会破坏循环变量）
        while (temp > 0) {                  // 数位拆分循环：只要 temp 还没被除干净（>0），就继续检查它的最低位
            if (temp % 10 == 7) { has7 = true; break; }  // temp % 10 取出当前最低位；若这一位是 7，则标记并立即 break 提前结束检查
            temp /= 10;                     // 整数除以 10，去掉已经检查过的最低位，让下一位变成新的个位
        }
        if (!has7) {                        // 条件②通过：各数位都不含 7，说明 i 确实与 7 无关
            sum += (long long)i * i;        // 累加 i 的平方；先把 i 强转成 long long 再相乘，避免 int * int 先溢出后才赋值
        }
    }
    cout << sum << endl;                    // 输出所有与 7 无关的数的平方和
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \log_{10} n)$。
- **空间复杂度**：$O(1)$。
