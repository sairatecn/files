# 救援

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

救生船从大本营出发营救屋顶上的人：

- 船速度 $50$ 米/分钟。
- 每人上船 $1$ 分钟。
- 每人下船 $0.5$ 分钟。
- 每次从大本营出发，救下屋顶所有人后返回大本营。
- 求所有人到达大本营所需的总时间。

## 输入描述

- 第一行：整数 $n$ ，屋顶数。
- 接下来 $n$ 行，每行三个数：屋顶 $x$ 坐标、 $y$ 坐标（单位米）、人数。

## 输出描述

- 救援总时间（分钟），向上取整）。

## 示例

### 用例输入 1

```text
1
30 40 3
```

### 用例输出 1

```text
7
```

---

## 题解

### 解题思路

对于每个屋顶，船需要：往返行驶距离（$2 \times \sqrt{x^2+y^2}$）÷ 速度 + 上船时间（人数 × 1）+ 下船时间（人数 × 0.5）。将所有屋顶的救援时间累加后向上取整。

### 算法分析

1. 读入 $n$。
2. 对每个屋顶，计算距离 $d = \sqrt{x^2+y^2}$，往返时间 $2d/50$，上船 $p \times 1$，下船 $p \times 0.5$。
3. 累加所有时间，最后用 `ceil()` 向上取整。

### 参考代码（C++）

```cpp
// 【整体思路】按屋顶逐个累加耗时的模拟题。
// 每次救援都是"大本营 -> 屋顶 -> 大本营"的一个独立往返，各屋顶之间互不影响，
// 所以总时间就是每个屋顶救援耗时的简单累加。单个屋顶的耗时由三部分组成：
//   1) 航行时间：大本营在原点，屋顶坐标 (x, y)，单程距离 d = sqrt(x^2 + y^2)，
//      往返为 2d 米，除以船速 50 米/分钟得到分钟数；
//   2) 上船时间：屋顶上每人上船 1 分钟，共 p * 1 分钟；
//   3) 下船时间：每人下船 0.5 分钟，共 p * 0.5 分钟。
// 全部累加后是一个小数，最后按题目要求用 ceil 向上取整为整数分钟。
#include <iostream>
#include <cmath>                  // 引入数学库以使用 sqrt（开平方）和 ceil（向上取整）
using namespace std;

int main() {
    int n;                        // n：需要救援的屋顶总数
    cin >> n;                     // 读入屋顶数量
    double totalTime = 0;         // 累加器：所有屋顶救援时间的总和（单位：分钟），必须用 double 保留小数（如 0.5 分钟、距离除法的余数）
    // 逐个处理每个屋顶：i 从 0 到 n-1，共 n 次
    // 每次迭代读入一个屋顶的信息，算出该次往返救援的耗时，并累加进 totalTime
    for (int i = 0; i < n; i++) {
        double x, y;              // 该屋顶相对大本营（原点）的横、纵坐标，单位：米；用 double 便于后续平方与开方运算
        int p;                    // 该屋顶上待救的人数
        cin >> x >> y >> p;       // 读入一行三个数据：x 坐标、y 坐标、人数
        double dist = sqrt(x * x + y * y);  // 关键计算：勾股定理求大本营到屋顶的直线距离（单程，单位：米）
        // 关键累加：把本屋顶的三段时间一次性加到总时间上
        //   2.0 * dist / 50.0 —— 往返 2 倍距离除以速度 50 米/分钟，得到航行分钟数（写成 2.0/50.0 保证是浮点除法）
        //   p * 1.0           —— p 个人上船，每人 1 分钟
        //   p * 0.5           —— p 个人下船，每人 0.5 分钟
        totalTime += 2.0 * dist / 50.0 + p * 1.0 + p * 0.5;
    }
    // 输出处理：ceil 把总时间向上取整（例如 6.2 分钟也要占用 7 分钟），
    // 再强制转成 int 以整数形式输出（ceil 的返回值本身是 double）
    cout << (int)ceil(totalTime) << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
