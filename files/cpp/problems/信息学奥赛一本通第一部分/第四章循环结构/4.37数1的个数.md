# 数1的个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个十进制正整数 $n$ $(1≤n≤10000)(1 \le n \le 10000)(1≤n≤10000)$ ，将从 $1$ 到 $n$ 的所有整数写下，统计其中数字“1”出现的次数。例如，当 $n=12$ 时，写下 $1,2,3,…,121,2,3,\dots,121,2,3,…,12$ ，数字“1”出现了 $5$ 次。

## 输入描述

一个正整数 $n$ $(1≤n≤10000)(1 \le n \le 10000)(1≤n≤10000)$ 。

## 输出描述

输出从 $1$ 到 $n$ 中数字“1”的总出现次数。

## 示例

### 用例输入 1

```text
12
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

从 1 遍历到 $n$，对每个数统计其十进制表示中数字 "1" 出现的次数（逐位取余检查），将所有数的统计结果累加。

### 算法分析

1. 读入 $n$，定义 `totalCnt = 0`。
2. 遍历 $i$ 从 1 到 $n$：对 $i$ 逐位检查 `temp % 10 == 1`，计数后 `temp /= 10`。
3. 输出 `totalCnt`。

### 参考代码（C++）

```cpp
// 【整体思路】暴力枚举 + 数位拆分统计。
// 题目要统计把 1,2,3,...,n 全部写出来后数字字符 “1” 出现的总次数。
// 注意：是统计“数位上的 1”，不是统计“等于 1 的数”，例如 11 要算 2 次、12 要算 1 次。
// 做法是对每个数 i 单独做数位拆分（反复 %10 取最低位、/10 去掉最低位），
// 每遇到一位等于 1 就把总计数加 1，最后把所有数的结果汇总。
// n ≤ 10000，最多 1 万个数、每个数最多 5 位，运算量极小，可以放心暴力。
#include <iostream>
using namespace std;

int main() {
    int n;                                  // n：统计的上界，范围 1..n
    cin >> n;                               // 读入 n
    int totalCnt = 0;                       // totalCnt：数字 1 出现的总次数（累加器），必须从 0 开始
    for (int i = 1; i <= n; i++) {          // 外层循环：i 依次取 1,2,...,n，代表“正在统计的那个数”
        int temp = i;                       // temp：i 的副本，用于拆位；用副本是为了不破坏循环变量 i
        while (temp > 0) {                  // 内层循环：逐位处理 temp，直到所有数位都被除掉（temp 变为 0）
            if (temp % 10 == 1) totalCnt++; // temp % 10 得到当前最低位数字；若这一位是 1，总计数加 1
            temp /= 10;                     // 整除 10 抹掉最低位，使次低位成为新的最低位，进入下一轮
        }
    }
    cout << totalCnt << endl;               // 输出 1..n 中数字 “1” 出现的总次数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \log_{10} n)$。
- **空间复杂度**：$O(1)$。
