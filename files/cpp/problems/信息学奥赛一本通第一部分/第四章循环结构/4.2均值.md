# 均值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给出一组样本数据，包含 $n$ 个浮点数，计算其均值，精确到小数点后4位。

## 输入描述

输入有两行：

- 第一行包含一个整数 $n$ ( $n<100n < 100n<100$ )，代表样本容量；
- 第二行包含 $n$ 个绝对值不超过 1000 的浮点数，代表各个样本数据。

## 输出描述

一行，包含一个浮点数，表示均值，精确到小数点后4位。

## 示例

### 用例输入 1

```text
2
1.0 3.0
```

### 用例输出 1

```text
2.0000
```

---

## 题解

### 解题思路

与求平均年龄类似，但本题输入的是浮点数。循环读入 $n$ 个浮点数并累加，最后除以 $n$，结果保留 4 位小数。

### 算法分析

1. 读入 $n$。
2. 定义 `double sum = 0`，循环 $n$ 次累加。
3. 输出 `sum / n`，保留 4 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    double sum = 0;
    for (int i = 0; i < n; i++) {
        double x;
        cin >> x;
        sum += x;
    }
    cout << fixed << setprecision(4) << sum / n << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
