# 质因数分解

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知正整数 $n$ 是两个不同质数的乘积，求较大的那个质数。对于 60% 的数据， $6≤n≤10006 \le n \le 10006≤n≤1000$ ；对于 100% 的数据， $6≤n≤2×1096 \le n \le 2 \times 10^96≤n≤2×109$ 。

## 输入描述

一行输入一个正整数 $n$ 。

## 输出描述

输出一行，包含较大的那个质数 $p$ 。

## 示例

### 用例输入 1

```text
15
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

题目保证 $n$ 是两个不同质数的乘积。因此只需找到 $n$ 的最小质因子 $p$（从 2 开始逐个试除），则较大的质因子就是 $n / p$。由于 $p \le \sqrt{n}$，遍历到 $\sqrt{n}$ 即可。

### 算法分析

1. 读入 $n$。
2. 从 $i = 2$ 开始，若 $n \bmod i == 0$ 则 $i$ 是较小质因子，输出 $n / i$。
3. 题目保证有解，一定能找到。

### 参考代码（C++）

```cpp
// 【整体思路】题目保证 n = p × q，其中 p、q 是两个不同的质数，要求输出较大的那个。
// 关键结论：设 p < q，则 p × p < p × q = n，即较小的质因子 p 一定满足 p ≤ √n。
// 所以只要从 2 开始试除，找到的第一个能整除 n 的数 i 必然就是最小质因子 p
// （因为若 i 是合数，它的更小质因子早就先一步整除 n 并被找到了，所以第一个因子必为质数），
// 那么较大的质数就是 n / i，直接输出并结束程序。
// 循环上界写成 i * i <= n 等价于 i <= √n，用乘法比 sqrt 更精确、不会有浮点误差。
#include <iostream>
using namespace std;

int main() {
    long long n;                            // n：待分解的正整数，最大到 2×10^9，超出 int 安全范围，故用 long long
    cin >> n;                               // 读入 n
    for (long long i = 2; i * i <= n; i++) {// 试除循环：i 是候选因子，从最小的质数 2 开始，只需枚举到 √n（i*i <= n）
        if (n % i == 0) {                   // 若 n 能被 i 整除，则 i 就是 n 的最小质因子（即较小的那个质数 p）
            cout << n / i << endl;          // n / i 即为另一个质因子，也就是较大的质数 q，输出它
            return 0;                       // 答案已求出，立即结束程序，避免继续做无用的试除
        }
    }
    return 0;                               // 兜底返回；按题目约定 n 必为两质数之积，循环内一定能找到答案，此行通常不会执行
}
```

### 复杂度分析

- **时间复杂度**：$O(\sqrt{n})$。
- **空间复杂度**：$O(1)$。
