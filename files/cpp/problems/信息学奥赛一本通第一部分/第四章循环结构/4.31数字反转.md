# 数字反转

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $N$ ，将该数的各个位数字反转得到新数。新数应满足整数的常规形式，即除非原数为零，否则反转后最高位不能为零。负数保持符号。

## 输入描述

输入共 1 行，一个整数 $N$ ， $−1,000,000,000≤N≤1,000,000,000-1,000,000,000 \le N \le 1,000,000,000−1,000,000,000≤N≤1,000,000,000$ 。

## 输出描述

输出共 1 行，一个整数，表示反转后的新数。

## 示例

### 用例输入 1

```text
-380
```

### 用例输出 1

```text
-83
```

---

## 题解

### 解题思路

先处理符号（负数取绝对值并记录），然后将数字逐位反转：每次取末位 `n % 10` 拼接到结果上，再 `n /= 10`。反转后前导零自然消除（如 380 反转为 083 = 83）。

### 算法分析

1. 读入 $N$，记录符号。若 $N < 0$ 则取绝对值。
2. 定义 `rev = 0`，循环：`rev = rev * 10 + N % 10`，`N /= 10`。
3. 恢复符号后输出。

### 参考代码（C++）

```cpp
// 算法思路：分三步完成数字反转。
// ① 处理符号：先记录原数是否为负，再取绝对值，让后续的数位操作只面对非负数（避免负数取余的符号问题）。
// ② 逐位反转：反复用 n % 10 取出末位，用 rev = rev * 10 + 末位 把它“接”到结果的低位上，
//    再用 n /= 10 去掉已处理的末位；这样原数的低位依次成为新数的高位，实现反转。
//    这种做法还能自动消除前导零，例如 380 -> 083，而 rev 作为整数天然就是 83。
// ③ 恢复符号：若原数为负，把结果取相反数后输出。
// 数据范围 |N| ≤ 1e9，用 long long 存储更加保险，不会在反转过程中溢出。
#include <iostream>
using namespace std;

int main() {
    long long n;                        // n：输入的原始整数，也作为“剩余待处理的数位”，循环中不断被整除缩短
    cin >> n;                           // 读入 N
    bool negative = (n < 0);            // negative：记录原数是否为负数，先把符号信息单独保存下来
    if (negative) n = -n;               // 若为负数则取绝对值，使后面的 % 和 / 都在正数上进行，逻辑更清晰
    long long rev = 0;                  // rev：反转后的结果，从 0 开始逐位“搭建”
    while (n > 0) {                     // 循环条件：还有数位没处理完就继续；n 为 0 时（含输入本身为 0 的情况）不进入循环，rev 保持 0
        rev = rev * 10 + n % 10;        // 关键：rev * 10 把已有结果整体左移一位腾出个位，再把 n 的当前末位 n % 10 填进去
        n /= 10;                        // 去掉 n 已经被取走的末位，下一位变成新的末位
    }                                   // 退出循环时，原数的所有数位都已按相反顺序装入 rev
    if (negative) rev = -rev;           // 若原数是负数，给反转结果加回负号（符号位不参与反转）
    cout << rev << endl;                // 输出反转后的新数；前导零已在整数运算中自动消失
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\log_{10} |N|)$。
- **空间复杂度**：$O(1)$。
