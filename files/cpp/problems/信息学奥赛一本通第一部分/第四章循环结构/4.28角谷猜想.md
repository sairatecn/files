# 角谷猜想

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

角谷猜想是指对任意正整数 $n$ ，如果 $n$ 是奇数，则计算 $3n+1$ ；如果 $n$ 是偶数，则计算 $n/2$ ，重复该过程，最终总能得到 1。程序要求输出从输入整数到 1 的每一步计算过程。

## 输入描述

输入一个正整数 $n$ $(n≤2,000,000)(n \le 2,000,000)(n≤2,000,000)$ 。

## 输出描述

每一步计算过程占一行，最后一行输出 End。如果输入为 1，直接输出 End。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
5*3+1=16
16/2=8
8/2=4
4/2=2
2/2=1
End
```

---

## 题解

### 解题思路

直接模拟角谷猜想的过程：当 $n > 1$ 时，若 $n$ 为奇数则计算 $3n+1$ 并输出，若 $n$ 为偶数则计算 $n/2$ 并输出。直到 $n = 1$ 时输出 `End`。

### 算法分析

1. 读入 $n$。
2. 当 $n > 1$ 时循环：
   - 若 $n$ 为奇数：输出 `n*3+1=结果`，更新 $n = 3n+1$。
   - 若 $n$ 为偶数：输出 `n/2=结果`，更新 $n = n/2$。
3. 循环结束后输出 `End`。

### 参考代码（C++）

```cpp
// 算法思路：直接模拟角谷猜想（3n+1 猜想）的变换过程。
// 每一步根据 n 的奇偶性决定操作：奇数变成 3n+1，偶数变成 n/2，
// 并把这一步的算式按题目要求的格式打印出来；当 n 变成 1 时结束，最后输出 End。
// 由于中间值 3n+1 可能超过 int 范围（题目 n 可达 2000000，且过程中会先增大再减小），
// 这里统一使用 long long 存储，保证不会溢出。
#include <iostream>
using namespace std;

int main() {
    long long n;                                          // n：当前数值，即角谷变换过程中的“当前状态”，用 long long 防止中间结果溢出
    cin >> n;                                             // 读入初始正整数 n
    while (n > 1) {                                       // 循环条件：只要还没变成 1 就继续变换；若输入本身为 1 则一次都不进入循环，直接输出 End
        if (n % 2 != 0) {                                 // 判断奇偶：余数不为 0 说明 n 是奇数
            long long next = 3 * n + 1;                   // 奇数规则：下一个数为 3n+1（先算出来，便于同时打印“原数”和“结果”）
            cout << n << "*3+1=" << next << endl;         // 按题目格式输出这一步算式，如 5*3+1=16
            n = next;                                     // 状态转移：把 n 更新为本步计算结果，进入下一轮
        } else {                                          // 否则 n 是偶数
            long long next = n / 2;                       // 偶数规则：下一个数为 n/2（整数除法，偶数除以 2 恰好整除，无精度问题）
            cout << n << "/2=" << next << endl;           // 按题目格式输出这一步算式，如 16/2=8
            n = next;                                     // 状态转移：把 n 更新为本步计算结果
        }
    }                                                     // 循环结束时 n 一定等于 1（角谷猜想保证收敛）
    cout << "End" << endl;                                // 所有步骤输出完毕后，最后单独输出结束标志 End
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：取决于 $n$ 值，但题目保证在合理范围内收敛。
- **空间复杂度**：$O(1)$。
