# 计算星期几

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

假设今天是星期日，输入两个正整数 $a,ba, ba,b$ ，表示过 $a×ba \times ba×b$ 天之后是星期几？输出星期名称，Monday为星期一，Sunday为星期日。

## 输入描述

输入一行，包含两个正整数 $a,ba, ba,b$ ，用空格隔开，满足 $0<a≤100,0≤b≤100000 < a \le 100, 0 \le b \le 100000<a≤100,0≤b≤10000$ 。

## 输出描述

输出一个字符串，表示过 $a×ba \times ba×b$ 天之后的星期几。

## 示例

### 用例输入 1

```text
3 2000
```

### 用例输出 1

```text
Monday
```

---

## 题解

### 解题思路

今天是星期日（对应 0 或 7），过 $a \times b$ 天后是星期几只需计算 $(a \times b) \bmod 7$，然后映射到星期名称。注意 $b$ 可能很大，需要用快速幂或逐步取模避免溢出。

### 算法分析

1. 读入 $a$ 和 $b$。
2. 计算 $days = (a^b) \bmod 7$（用快速幂或循环取模）。
3. 将结果映射到星期名称：1→Monday, 2→Tuesday, ..., 0→Sunday。

### 参考代码（C++）

```cpp
// 算法思路：今天是星期日，天数每增加 7 天星期就转回一圈，所以只关心总天数对 7 的余数。
// 本题要过 a 的 b 次方天，而 a^b 会大到无法用任何整型存下，所以不能先算幂再取模。
// 依据同余性质 (x*y) mod m = ((x mod m) * (y mod m)) mod m，
// 可以「边乘边取模」：每乘一个 a 就立刻对 7 取余，全程数值都不超过 7*7=49，绝不会溢出。
// 最后把余数 0~6 通过一个字符串数组映射成星期名称（0 对应星期日）。
#include <iostream>
using namespace std;

int main() {
    int a, b;                       // a：底数（0 < a <= 100）；b：指数（0 <= b <= 10000）
    cin >> a >> b;                  // 读入 a 和 b
    // 计算 a^b mod 7
    int base = a % 7;               // base：先把底数对 7 取余，缩小到 0~6，后续乘法不会变大
    int result = 1;                 // result：累乘结果对 7 的余数，初值取 1（任何数的 0 次方为 1）
    // 循环 b 次，每次把 result 再乘一个 base，相当于把 a 的次数累加一次；
    // 每乘一次就立刻 %7，保证中间结果始终小于 7，既防溢出又不影响最终余数
    for (int i = 0; i < b; i++) {
        result = (result * base) % 7;   // 边乘边取模，等价于计算 a^(i+1) mod 7
    }
    // result == 0 表示星期日
    // days 数组把余数直接当作下标映射到星期名称：余 1 是星期一、余 2 是星期二……余 0 是星期日
    string days[] = {"Sunday", "Monday", "Tuesday", "Wednesday",
                     "Thursday", "Friday", "Saturday"};
    cout << days[result] << endl;   // 以余数为下标取出对应星期名并输出
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(b)$，$b \le 10000$，完全可接受。
- **空间复杂度**：$O(1)$。
