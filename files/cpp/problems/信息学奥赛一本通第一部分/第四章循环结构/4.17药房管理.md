# 药房管理

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

药房管理员已知每天初始库存 $m$ ，每天有 $n$ 名病人依次取药。每名病人希望取走指定数量，如果库存不足，将被拒绝。求每天被拒绝的病人数。

## 输入描述

第一行一个整数 $m$ ，表示初始药品数量。
第二行一个整数 $n$ ，表示病人数。
第三行 $n$ 个整数，每个表示病人希望取走的药品数量。

## 输出描述

一行一个整数，表示未能取到药品的病人数。

## 示例

### 用例输入 1

```text
10
5
20 6 7 8 4
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

模拟每个病人依次取药的过程。初始库存为 $m$，每个病人来取药时检查库存是否足够：若够则扣减库存，不够则被拒绝（拒绝计数 +1）。

### 算法分析

1. 读入 $m$（初始库存）和 $n$（病人数）。
2. 定义 `refused = 0`，循环 $n$ 次读入每个病人的需求量。
3. 若 `m >= need`，则 `m -= need`；否则 `refused++`。
4. 输出 `refused`。

### 参考代码（C++）

```cpp
// 【整体思路】按病人到来的先后顺序模拟发药过程（贪心式的顺序模拟）。
// 库存 m 是一个会不断减少的状态量。每来一位病人就做一次判断：
//   库存 >= 该病人的需求量 -> 发药成功，库存扣减相应数量；
//   库存 <  该病人的需求量 -> 药不够，该病人被拒绝，库存保持不变（不发部分药）。
// 注意被拒绝的病人不会消耗库存，所以后面需求量较小的病人仍有可能取到药，
// 这正是样例中"20 被拒但 6、4 能取到"的原因。最后输出被拒绝的人数。
#include <iostream>
using namespace std;

int main() {
    int m, n;                 // m：药房当天的初始库存药品数量，会随着发药不断减少
                              // n：当天前来取药的病人总数
    cin >> m >> n;            // 分两行读入初始库存和病人数
    int refused = 0;          // 计数器：记录未能取到药（被拒绝）的病人数量，初始为 0
    // 按顺序处理每一位病人：i 从 0 到 n-1，共 n 次迭代
    // 每次迭代读入一位病人的需求量并决定发药还是拒绝
    for (int i = 0; i < n; i++) {
        int need;             // need：当前这位病人希望取走的药品数量
        cin >> need;          // 读入第 i+1 位病人的需求量
        // 关键判断：库存是否足够满足这位病人的全部需求（恰好相等也算够）
        if (m >= need) {
            m -= need;        // 库存充足：发药，从库存中扣掉这位病人取走的数量
        } else {
            refused++;        // 库存不足：拒绝这位病人，拒绝人数加一；注意此时库存不变，留给后面的病人
        }
    }
    cout << refused << endl;  // 输出最终被拒绝的病人总数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
