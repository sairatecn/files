# 分苹果

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

将一堆苹果分给 $n$ 个小朋友，使每个人都能拿到苹果且每个人拿到的苹果数都不同，求最少需要多少个苹果。

## 输入描述

输入一个正整数 $n$ $(1≤n≤1000)(1 \le n \le 1000)(1≤n≤1000)$ ，表示小朋友人数。

## 输出描述

输出一个整数，表示满足条件的最少苹果个数。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
15
```

---

## 题解

### 解题思路

要使每人拿到的苹果数不同且总数最少，最优策略是第一个人拿 1 个、第二个人拿 2 个、……、第 $n$ 个人拿 $n$ 个。总数即为 $1+2+\dots+n = n(n+1)/2$。

### 算法分析

1. 读入 $n$。
2. 用循环累加 $1+2+\dots+n$（或直接公式 $n(n+1)/2$）。
3. 输出结果。

### 参考代码（C++）

```cpp
// 算法思路：每人至少拿 1 个且人人拿的数量互不相同，要让总数最少，
// 就应该让这 n 个互不相同的正整数尽可能小，即分别取 1、2、3、...、n。
// 所以答案就是 1+2+...+n（等价于等差数列求和公式 n(n+1)/2）。
// 这里用循环逐个累加来实现，直观地体现「第 i 个小朋友拿 i 个苹果」的分法。
#include <iostream>
using namespace std;

int main() {
    int n;                          // n：小朋友的人数（1 <= n <= 1000）
    cin >> n;                       // 读入人数
    int sum = 0;                    // sum：苹果总数的累加器，初始为 0
    // 循环变量 i 从 1 递增到 n，代表第 i 个小朋友分到 i 个苹果，
    // 这样 n 个人拿到的数量分别是 1,2,...,n，互不相同且总量最小
    for (int i = 1; i <= n; i++) {
        sum += i;                   // 把第 i 个小朋友的 i 个苹果累加进总数
    }
    // n 最大 1000 时 sum = 500500，远小于 int 上限，不会溢出
    cout << sum << endl;            // 输出所需的最少苹果个数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
