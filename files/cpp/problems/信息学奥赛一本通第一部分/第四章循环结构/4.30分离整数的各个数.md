# 分离整数的各个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $n$ $(1≤n≤100000000)(1 \le n \le 100000000)(1≤n≤100000000)$ ，要求从个位开始分离出它的每一位数字，并按从低位到高位的顺序依次输出。

## 输入描述

输入一个整数 $n$ ，满足 $1≤n≤1000000001 \le n \le 1000000001≤n≤100000000$ 。

## 输出描述

从个位开始按从低位到高位顺序输出每一位数字，数字之间以一个空格分隔。

## 示例

### 用例输入 1

```text
123
```

### 用例输出 1

```text
3 2 1
```

---

## 题解

### 解题思路

从个位开始分离每一位数字，就是反复对 10 取余得到最低位，再整除 10 去掉最低位，直到数变为 0。

### 算法分析

1. 读入 $n$。
2. 循环：输出 `n % 10`，`n /= 10`，中间加空格。
3. 直到 $n = 0$ 结束。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool first = true;
    while (n > 0) {
        if (!first) cout << " ";
        cout << n % 10;
        n /= 10;
        first = false;
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\log_{10} n)$，即数字的位数。
- **空间复杂度**：$O(1)$。
