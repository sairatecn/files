# 分离整数的各个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $n$ $(1≤n≤100000000)(1 \le n \le 100000000)(1≤n≤100000000)$ ，要求从个位开始分离出它的每一位数字，并按从低位到高位的顺序依次输出。

## 输入描述

输入一个整数 $n$ ，满足 $1≤n≤1000000001 \le n \le 1000000001≤n≤100000000$ 。

## 输出描述

从个位开始按从低位到高位顺序输出每一位数字，数字之间以一个空格分隔。

## 示例

### 用例输入 1

```text
123
```

### 用例输出 1

```text
3 2 1
```

---

## 题解

### 解题思路

从个位开始分离每一位数字，就是反复对 10 取余得到最低位，再整除 10 去掉最低位，直到数变为 0。

### 算法分析

1. 读入 $n$。
2. 循环：输出 `n % 10`，`n /= 10`，中间加空格。
3. 直到 $n = 0$ 结束。

### 参考代码（C++）

```cpp
// 算法思路：数位拆分的经典套路——“取余得末位，整除去末位”。
// 对 10 取余 (n % 10) 可以得到 n 的个位数字；
// 对 10 整除 (n /= 10) 相当于把已经取出的个位去掉，使原来的十位变成新的个位。
// 反复执行这两步直到 n 变为 0，取出的数字顺序天然就是“从低位到高位”，正好符合题目要求。
// 输出时用一个标志变量控制空格，保证数字之间恰好一个空格、行首行尾无多余空格。
#include <iostream>
using namespace std;

int main() {
    int n;                        // n：待拆分的整数（n ≤ 1e8，未超出 int 范围）；循环中会被不断整除缩短，充当“剩余未处理部分”
    cin >> n;                     // 读入 n
    bool first = true;            // first：标记当前要输出的是不是第一个数字，用于决定是否需要先打印分隔用的空格
    while (n > 0) {               // 循环条件：只要 n 还有未取完的数位（不为 0）就继续；每迭代一次处理并去掉一位，最多循环“位数”次
        if (!first) cout << " ";  // 非首个数字时，先输出一个空格作为分隔符（首个数字前不输出，避免行首多空格）
        cout << n % 10;           // 关键：n % 10 取出当前最低位（个位）数字并输出
        n /= 10;                  // 关键：整数除法去掉刚输出的个位，十位“下移”成为新的个位，为下一轮做准备
        first = false;            // 第一个数字已输出，之后的数字前都需要加空格
    }                             // 退出循环时 n == 0，说明所有数位都已按从低位到高位的顺序输出完毕
    cout << endl;                 // 输出换行，结束这一行
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\log_{10} n)$，即数字的位数。
- **空间复杂度**：$O(1)$。
