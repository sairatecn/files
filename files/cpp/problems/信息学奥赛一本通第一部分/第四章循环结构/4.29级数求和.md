# 级数求和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知调和级数 $Sn=1+1/2+1/3+...+1/nS_n = 1 + 1/2 + 1/3 + ... + 1/nSn​=1+1/2+1/3+...+1/n$ ，对于给定整数 $k$ $(1≤k≤15)(1 \le k \le 15)(1≤k≤15)$ ，求最小整数 $n$ 使得 $Sn>kS_n > kSn​>k$ 。

## 输入描述

输入一个整数 $k$ $(1≤k≤15)(1 \le k \le 15)(1≤k≤15)$ 。

## 输出描述

输出一个整数 $n$ ，满足 $Sn>kS_n > kSn​>k$ 的最小值。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
83
```

---

## 题解

### 解题思路

调和级数 $S_n = 1 + 1/2 + 1/3 + \dots + 1/n$ 是递增的。从 $n = 1$ 开始累加，直到 $S_n > k$ 时停止，输出当前的 $n$。

### 算法分析

1. 读入 $k$。
2. 定义 `sum = 0, n = 0`。
3. 当 `sum <= k` 时：`n++`，`sum += 1.0 / n`。
4. 输出 $n$。

### 参考代码（C++）

```cpp
// 算法思路：调和级数 S(n) = 1 + 1/2 + 1/3 + ... + 1/n 随 n 单调递增（每次都加一个正数），
// 因此“使 S(n) > k 的最小 n”可以用最朴素的逐项累加法求：
// 从 n = 0、sum = 0 开始，不断令 n 加 1 并把 1/n 累加到 sum 上，
// 一旦 sum 超过 k 就立刻停止，此时的 n 就是答案（因为它是第一个让和超过 k 的下标）。
// k ≤ 15 时 n 约为 1.8×10^6 量级，循环次数完全可以接受。
#include <iostream>
using namespace std;

int main() {
    int k;                          // k：题目给定的阈值，要求找到最小的 n 使得 S(n) > k
    cin >> k;                       // 读入 k
    double sum = 0;                 // sum：已累加的级数和 S(n)，因为每项 1/n 是小数，必须用浮点类型（double 精度足够）
    int n = 0;                      // n：当前已经累加到的项数（也是循环计数器），初始为 0 表示一项都还没加
    while (sum <= k) {              // 循环条件：只要和还“没有超过”k 就继续加下一项；注意是 <=，即等于 k 也不算超过，必须严格大于才停
        n++;                        // 先把项数推进到下一项：准备累加第 n 项
        sum += 1.0 / n;             // 累加第 n 项 1/n；这里写 1.0 而不是 1，是为了触发浮点除法，否则 1/n 会变成整数除法恒为 0
    }                               // 退出循环时 sum > k，且 n 是第一个满足条件的项数
    cout << n << endl;              // 输出最小的 n
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(e^k)$，调和级数增长极慢，但 $k \le 15$ 时 $n$ 最大约 $1.8 \times 10^6$，完全可接受。
- **空间复杂度**：$O(1)$。
