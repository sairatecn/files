# 球弹跳高度的计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

一球从高度 $h$ 落下，每次落地后反弹回原高度的一半。求第10次落地时球共经过的距离，以及第10次反弹的高度。

## 输入描述

输入一个整数 $h$ ，表示球的初始高度。

## 输出描述

第一行：第10次落地时球共经过的米数。第二行：第10次反弹的高度。保留六位小数。

## 示例

### 用例输入 1

```text
10
```

### 用例输出 1

```text
29.960938
0.009766
```

---

## 题解

### 解题思路

球从高度 $h$ 落下，第一次落地经过 $h$，然后反弹到 $h/2$ 再落下，第二次落地又经过 $h/2 \times 2$。依此类推，第 10 次落地时累加所有路程，第 10 次反弹高度为第 10 次弹起的高度。

### 算法分析

1. 第 1 次落地：经过 $h$ 米。
2. 第 $i$ 次（$i \ge 2$）落地：反弹高度为上一次的一半，上下各一次，经过 $2 \times h_i$。
3. 第 10 次反弹高度 = $h / 2^{10}$。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double h;
    cin >> h;
    double totalDist = h;  // 第1次落地
    double bounce = h / 2.0;
    for (int i = 2; i <= 10; i++) {
        totalDist += 2.0 * bounce;  // 上升+下落
        bounce /= 2.0;
    }
    cout << fixed << setprecision(6) << totalDist << endl;
    cout << fixed << setprecision(6) << bounce << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定 10 次。
- **空间复杂度**：$O(1)$。
