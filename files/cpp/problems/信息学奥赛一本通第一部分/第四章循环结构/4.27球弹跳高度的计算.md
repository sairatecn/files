# 球弹跳高度的计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

一球从高度 $h$ 落下，每次落地后反弹回原高度的一半。求第10次落地时球共经过的距离，以及第10次反弹的高度。

## 输入描述

输入一个整数 $h$ ，表示球的初始高度。

## 输出描述

第一行：第10次落地时球共经过的米数。第二行：第10次反弹的高度。保留六位小数。

## 示例

### 用例输入 1

```text
10
```

### 用例输出 1

```text
29.960938
0.009766
```

---

## 题解

### 解题思路

球从高度 $h$ 落下，第一次落地经过 $h$，然后反弹到 $h/2$ 再落下，第二次落地又经过 $h/2 \times 2$。依此类推，第 10 次落地时累加所有路程，第 10 次反弹高度为第 10 次弹起的高度。

### 算法分析

1. 第 1 次落地：经过 $h$ 米。
2. 第 $i$ 次（$i \ge 2$）落地：反弹高度为上一次的一半，上下各一次，经过 $2 \times h_i$。
3. 第 10 次反弹高度 = $h / 2^{10}$。

### 参考代码（C++）

```cpp
// 算法思路：球从高 h 处落下，第 1 次落地只走了单程 h 米；
// 之后每次都是「弹起到一半高度、再落回地面」，所以从第 2 次落地起，
// 每次落地相比上一次多走的路程是「当次反弹高度的两倍」（上去一趟 + 下来一趟）。
// 于是用一个变量 bounce 记录当前的反弹高度（每弹一次减半），
// 循环 i=2..10 累加 9 段来回路程，即可得到第 10 次落地时的总路程。
// 而每循环一次 bounce 就减半，循环结束时 bounce 恰好等于 h/2^10，即第 10 次反弹的高度。
#include <iostream>
#include <iomanip>          // 提供 fixed / setprecision，用于控制小数输出精度
using namespace std;

int main() {
    double h;                       // h：球的初始下落高度，用 double 以便做除以 2 的小数运算
    cin >> h;                       // 读入初始高度
    double totalDist = h;  // 第1次落地   // totalDist：累计经过的总路程，第 1 次落地只走了单程 h 米
    double bounce = h / 2.0;        // bounce：第 1 次落地后反弹起的高度，为原高度的一半
    // 循环变量 i 表示「第 i 次落地」，从第 2 次一直算到第 10 次，共 9 次迭代；
    // 每次迭代先把这一次落地新增的往返路程加进总数，再把反弹高度减半供下一次使用
    for (int i = 2; i <= 10; i++) {
        totalDist += 2.0 * bounce;  // 上升+下落   // 第 i 次落地新增路程 = 反弹高度的 2 倍（先弹上去再落下来）
        bounce /= 2.0;              // 反弹高度衰减一半，得到第 i 次落地后弹起的高度
    }
    // 循环退出时 bounce 已被减半 10 次（初始一次 + 循环内 9 次），即 h/2^10，正是第 10 次反弹高度
    // fixed 配合 setprecision(6) 表示小数点后固定保留 6 位
    cout << fixed << setprecision(6) << totalDist << endl;  // 第一行：第 10 次落地时经过的总米数
    cout << fixed << setprecision(6) << bounce << endl;     // 第二行：第 10 次反弹的高度
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定 10 次。
- **空间复杂度**：$O(1)$。
