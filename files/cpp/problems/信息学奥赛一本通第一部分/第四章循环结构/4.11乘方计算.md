# 乘方计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $a$ 和一个正整数 $n$ ，计算乘方 $ana^nan$ 。题目保证最终结果的绝对值不超过 $1000000$ 。

## 输入描述

输入一行，包含两个整数 $a$ 和 $n$ ，其中 $−1000000≤a≤1000000-1000000 \le a \le 1000000−1000000≤a≤1000000$ ， $1≤n≤100001 \le n \le 100001≤n≤10000$ 。

## 输出描述

输出一个整数，表示乘方 $ana^nan$ 的结果。

## 示例

### 用例输入 1

```text
2 3
```

### 用例输出 1

```text
8
```

---

## 题解

### 解题思路

计算 $a^n$，即 $a$ 自乘 $n$ 次。用循环实现累乘即可。题目保证结果绝对值不超过 $1000000$，使用 `long long` 可避免中间溢出。

### 算法分析

1. 读入 $a$ 和 $n$。
2. 定义 `long long result = 1`，循环 $n$ 次每次 `result *= a`。
3. 输出 `result`。

### 参考代码（C++）

```cpp
// 【整体思路】用循环做"累乘"来实现幂运算 a^n。
// a^n 的定义就是 n 个 a 相乘，所以设一个初值为 1 的累乘器（1 是乘法的单位元，
// 保证乘 n 次后恰好等于 n 个 a 的乘积），然后循环 n 次，每次把它乘上一个 a。
// 注意不用 pow()：pow 返回 double，大整数会有精度误差，整数幂用循环累乘更稳妥。
#include <iostream>
using namespace std;

int main() {
    long long a;           // 底数 a，范围 -1000000 ~ 1000000；用 long long 存放，避免与 result 相乘时发生 int 溢出
    int n;                 // 指数 n，正整数，范围 1 ~ 10000，表示要把 a 连乘多少次
    cin >> a >> n;         // 读入一行中的底数和指数
    long long result = 1;  // 累乘结果，初值必须是 1（若设为 0 则结果恒为 0）；用 long long 承载较大的中间结果
    // 累乘循环：i 从 0 到 n-1，共循环 n 次
    // 第 i 次迭代后 result 的值为 a 的 (i+1) 次方，循环结束时 result == a^n
    for (int i = 0; i < n; i++) {
        result *= a;       // 关键计算：在已有结果上再乘一个底数 a，等价于把指数加 1
    }
    cout << result << endl; // 输出最终的 a^n（题目保证其绝对值不超过 1000000）
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
