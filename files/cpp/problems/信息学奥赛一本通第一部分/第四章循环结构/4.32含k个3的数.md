# 含k个3的数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入两个正整数 $m$ 和 $k$ ，判断 $m$ 是否能被19整除且恰好包含 $k$ 个数字3。如果满足条件，输出 YES，否则输出 NO。

## 输入描述

输入一行，包含两个正整数 $m$ 和 $k$ ，中间用空格分隔，其中 $1<m<100000$ ， $1<k<5$ 。

## 输出描述

满足条件输出 YES，否则输出 NO。

## 示例

### 用例输入 1

```text
43833 3
```

### 用例输出 1

```text
YES
```

---

## 题解

### 解题思路

需要同时满足两个条件：① $m$ 能被 19 整除；② $m$ 的十进制表示中恰好有 $k$ 个数字 3。条件 ② 可通过逐位取余检查每一位是否为 3 来统计。

### 算法分析

1. 读入 $m$ 和 $k$。
2. 先检查 `m % 19 == 0`，若不满足直接输出 `NO`。
3. 统计 $m$ 中数字 3 的个数：循环取余 `m % 10`，若为 3 则计数 +1，`m /= 10`。
4. 若计数等于 $k$ 则输出 `YES`，否则 `NO`。

### 参考代码（C++）

```cpp
// 算法思路：题目要求同时满足两个条件才输出 YES。
// 条件①：m 能被 19 整除，直接用 m % 19 == 0 判断；不满足可以立即输出 NO 并结束，省去后面的统计。
// 条件②：m 的十进制表示中数字 3 恰好出现 k 次。
//        用数位拆分统计：反复取末位 temp % 10 判断是否等于 3，是则计数加一，
//        然后 temp /= 10 去掉这一位，直到 temp 变成 0，即遍历完 m 的每一位。
// 注意统计时使用副本 temp 而不是直接改动 m，这样 m 的原值得以保留（也更符合“不破坏输入数据”的习惯）。
#include <iostream>
using namespace std;

int main() {
    int m, k;                            // m：待判断的正整数（m < 100000）；k：要求出现的数字 3 的个数（1 < k < 5）
    cin >> m >> k;                       // 一行读入 m 和 k，中间以空格分隔
    if (m % 19 != 0) {                   // 先判断条件①：余数不为 0 说明 m 不能被 19 整除
        cout << "NO" << endl;            // 第一个条件就不满足，答案必为 NO
        return 0;                        // 提前结束程序，无需再统计数字 3 的个数
    }
    int cnt = 0, temp = m;               // cnt：统计 m 中数字 3 出现的次数，初值为 0；temp：m 的副本，用于逐位拆解而不破坏 m
    while (temp > 0) {                   // 循环条件：temp 还有未检查的数位就继续；每轮处理一位，共循环 m 的位数次
        if (temp % 10 == 3) cnt++;       // 关键：temp % 10 取出当前最低位，若这一位正好是 3 则计数加一
        temp /= 10;                      // 整除 10 去掉已检查的最低位，让上一位成为新的最低位
    }                                    // 退出循环时 temp == 0，cnt 即为 m 中数字 3 的总个数
    if (cnt == k) cout << "YES" << endl; // 两个条件都满足（能被 19 整除 且 3 的个数恰好等于 k），输出 YES
    else cout << "NO" << endl;           // 3 的个数不等于 k（多了或少了都不行），输出 NO
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\log_{10} m)$。
- **空间复杂度**：$O(1)$。
