# 人口增长计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知我国现有 $x$ 亿人口，人口以每年 $0.1%0.1\%0.1%$ 的速度增长。设增长 $n$ 年后的人口数为 $PnP_nPn​$ ，则有： $Pn=x×(1+0.001)nP_n = x \times (1 + 0.001)^nPn​=x×(1+0.001)n$ 。请计算 $n$ 年后的人口数量，并保留到小数点后四位。

## 输入描述

- 一行输入两个整数 $x$ 和 $n$ ，分别表示人口基数（单位：亿）和年数，二者以一个空格分隔。

## 输出描述

- 输出 $n$ 年后的人口数量（单位：亿），结果保留小数点后四位。

## 示例

### 用例输入 1

```text
13 10
```

### 用例输出 1

```text
13.1306
```

---

## 题解

### 解题思路

人口以每年 0.1% 的速度增长，即每年乘以 $(1 + 0.001) = 1.001$。循环 $n$ 次即可得到 $n$ 年后的人口数。

### 算法分析

1. 读入 $x$（人口基数）和 $n$（年数）。
2. 定义 `double p = x`，循环 $n$ 次每次 `p *= 1.001`。
3. 输出 $p$，保留 4 位小数。

### 参考代码（C++）

```cpp
// 【整体思路】复利式增长的模拟：P_n = x * (1 + 0.001)^n。
// 人口每年增长 0.1%，也就是每过一年人口变为上一年的 (1 + 0.001) = 1.001 倍。
// 因此用一个 double 变量保存"当前人口"，循环 n 次、每次乘以 1.001，
// 循环结束时它就等于 n 年后的人口数。最后按题目要求保留 4 位小数输出。
#include <iostream>
#include <iomanip>         // 引入 iomanip 才能使用 fixed / setprecision 控制小数输出格式
using namespace std;

int main() {
    int x, n;              // x：初始人口基数（单位：亿，整数）；n：要推算的年数
    cin >> x >> n;         // 读入一行中的人口基数和年数
    double p = x;          // p：当前人口数（单位：亿）。用 double 保存小数部分；初始时（第 0 年）人口就是 x
                           // 这里把 int 的 x 赋给 double 的 p，发生隐式类型转换，后续乘法才会按浮点数进行
    // 逐年模拟增长：i 从 0 到 n-1，共循环 n 次，代表经过 n 年
    // 第 i 次迭代结束后，p 表示第 (i+1) 年年末的人口
    for (int i = 0; i < n; i++) {
        p *= 1.001;        // 关键计算：一年增长 0.1%，即乘以 1 + 0.1/100 = 1.001
    }
    // 输出精度控制：fixed 表示用定点小数形式（而非科学计数法），
    // setprecision(4) 在 fixed 模式下表示"小数点后保留 4 位"，不足补 0
    cout << fixed << setprecision(4) << p << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
