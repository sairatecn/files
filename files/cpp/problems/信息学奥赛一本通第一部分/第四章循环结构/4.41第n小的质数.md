# 第n小的质数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个正整数 $n$ ，求第 $n$ 小的质数。 $n$ 的取值不超过 10000。

## 输入描述

一个正整数 $n$ $(1≤n≤10000)(1 \le n \le 10000)(1≤n≤10000)$ 。

## 输出描述

输出第 $n$ 小的质数。

## 示例

### 用例输入 1

```text
6
```

### 用例输出 1

```text
13
```

---

## 题解

### 解题思路

从 2 开始逐个判断是否为质数，每找到一个质数计数 +1，直到计数等于 $n$ 时输出当前数。判断质数用试除法：检查 $2$ 到 $\sqrt{x}$ 是否有因子。

### 算法分析

1. 读入 $n$。
2. 定义 `count = 0, num = 2`。
3. 循环：判断 `num` 是否为质数（试除法），若是则 `count++`；若 `count == n` 则输出 `num` 并结束。
4. `num++` 继续。

### 参考代码（C++）

```cpp
// 【整体思路】“逐个判定 + 计数”求第 n 小的质数。
// 从最小的质数 2 开始，把自然数一个一个往后试：每遇到一个质数就把计数器加 1，
// 当计数器恰好等于 n 时，当前这个数就是第 n 小的质数，输出并结束。
// 质数判定使用试除法：若 x 有大于 1 的因子，则必定存在一个不超过 √x 的因子
// （因为因子总是成对出现：x = a × b，a、b 中必有一个 ≤ √x），
// 所以只需检查 2..√x，一旦发现能整除就说明不是质数。
// n ≤ 10000，第 10000 个质数是 104729，试除法的总运算量完全可以接受。
#include <iostream>
using namespace std;

// 判断 x 是否为质数：是返回 true，不是返回 false
bool isPrime(int x) {
    if (x < 2) return false;                // 特判：0、1 以及负数都不是质数，质数最小是 2
    for (int i = 2; i * i <= x; i++) {      // 试除循环：i 为候选因子，从 2 枚举到 √x（i*i <= x 避免使用浮点开方）
        if (x % i == 0) return false;       // 找到一个真因子 i，说明 x 是合数，立即返回 false
    }
    return true;                            // 2..√x 都不能整除 x，说明 x 没有真因子，是质数
}

int main() {
    int n;                                  // n：要求第几小的质数（1 ≤ n ≤ 10000）
    cin >> n;                               // 读入 n
    int count = 0, num = 2;                 // count：已经找到的质数个数（计数器）；num：当前正在检验的自然数，从最小质数 2 起步
    while (true) {                          // 无限循环：一直往后找，直到凑够 n 个质数才在循环体内 return 退出
        if (isPrime(num)) {                 // 检验当前的 num 是否为质数
            count++;                        // 是质数，已找到的质数个数加 1，此时 num 就是第 count 小的质数
            if (count == n) {               // 计数恰好达到 n，说明 num 正是所求的第 n 小的质数
                cout << num << endl;        // 输出答案
                return 0;                   // 结束程序，跳出无限循环
            }
        }
        num++;                              // 无论 num 是否为质数，都要继续检验下一个自然数
    }
}
```

### 复杂度分析

- **时间复杂度**：$O(n \cdot \sqrt{p_n})$，其中 $p_n$ 是第 $n$ 个质数。$n \le 10000$ 时可接受。
- **空间复杂度**：$O(1)$。
