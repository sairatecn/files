# 菲波那契数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

菲波那契数列定义如下：数列的第 $1$ 项和第 $2$ 项均为 $1$ ，从第 $3$ 项开始，每一项等于前两项之和，即 $Fk=Fk−1+Fk−2F_k = F_{k-1} + F_{k-2}Fk​=Fk−1​+Fk−2​$ 。给定一个正整数 $k$ ，求菲波那契数列中的第 $k$ 项。

## 输入描述

- 一行输入一个正整数 $k$ ，表示要求的菲波那契数列项号（ $1≤k≤461 \le k \le 461≤k≤46$ ）。

## 输出描述

- 输出一个正整数，表示菲波那契数列中第 $k$ 项的值。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

菲波那契数列的定义是递推关系，直接用循环模拟即可。维护前两项，每次计算下一项并更新。$k \le 46$ 时结果不会超出 `int` 范围。

### 算法分析

1. 读入 $k$。
2. 若 $k \le 2$，直接输出 1。
3. 否则定义 `a = 1, b = 1`，从第 3 项循环到第 $k$ 项，每次计算 `c = a + b` 并更新 `a = b, b = c`。
4. 输出 `b`。

### 参考代码（C++）

```cpp
// 【整体思路】用"滚动变量"迭代递推求斐波那契数列第 k 项，避免递归重复计算。
// 数列定义：F(1)=F(2)=1，F(k)=F(k-1)+F(k-2)。
// 由于求 F(k) 只依赖紧邻的前两项，所以不必开数组保存整个数列，
// 只需两个变量 a、b 分别滚动记录"前前一项"和"前一项"，
// 每轮算出新的一项后把这两个变量整体往后挪一位即可，空间 O(1)、时间 O(k)。
#include <iostream>
using namespace std;

int main() {
    int k;                        // k：要求的项号（1 <= k <= 46）
    cin >> k;                     // 读入项号 k
    // 特判边界：第 1 项和第 2 项由定义直接给出，都是 1，此时无法进入递推循环，需要单独处理
    if (k <= 2) {
        cout << 1 << endl;        // 直接输出 1
        return 0;                 // 提前结束程序，后面的递推不再执行
    }
    long long a = 1, b = 1;       // a：当前递推位置的前前一项 F(i-2)；b：前一项 F(i-1)
                                  // 进入循环前 i=3，故 a = F(1) = 1，b = F(2) = 1
                                  // 用 long long 是为了保险，k=46 时 F(46)=1836311903 仍在 int 范围内，但 long long 更安全
    // 递推循环：i 从 3 开始，一直算到第 k 项，共迭代 k-2 次
    // 每次迭代求出第 i 项，并把窗口 (a, b) 向右滑动一格
    for (int i = 3; i <= k; i++) {
        long long c = a + b;      // 关键递推式：第 i 项 = 第 i-2 项 + 第 i-1 项
        a = b;                    // 滑动窗口第一步：原来的"前一项"变成新的"前前一项"
        b = c;                    // 滑动窗口第二步：刚算出的第 i 项变成新的"前一项"
                                  // 注意赋值顺序不能颠倒，否则 a 会被新值覆盖导致下一轮算错
    }
    cout << b << endl;            // 循环结束时 b 恰好保存着第 k 项的值，输出它
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(k)$。
- **空间复杂度**：$O(1)$。
