# 画矩形

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

根据输入的参数绘制矩形。输入四个参数：前两个为整数，分别表示矩形的高度 $H$ 和宽度 $W$ （ $3≤H≤103 \le H \le 103≤H≤10$ ， $5≤W≤105 \le W \le 105≤W≤10$ ）；第三个参数为字符 $C$ ，表示绘制矩形的符号；第四个参数为 $F$ ，1表示实心矩形，0表示空心矩形。

## 输入描述

一行输入四个参数： $H$ $W$ $C$ $F$ ，以空格隔开。

## 输出描述

根据参数绘制矩形，每行输出对应的字符行。

## 示例

### 用例输入 1

```text
7 7 @ 0
```

### 用例输出 1

```text
@@@@@@@
@     @
@     @
@     @
@     @
@     @
@@@@@@@
```

---

## 题解

### 解题思路

用嵌套循环输出矩形。若 $F=1$（实心），每行全部输出字符 $C$；若 $F=0$（空心），仅第一行、最后一行、每行的第一个和最后一个字符为 $C$，中间为空格。

### 算法分析

1. 读入 $H, W, C, F$。
2. 外层循环 $H$ 行，内层循环 $W$ 列：
   - 若 $F=1$，每格输出 $C$。
   - 若 $F=0$，首末行或首末列输出 $C$，否则输出空格。
3. 每行结束输出换行。

### 参考代码（C++）

```cpp
// 【整体思路】典型的二重循环图形题：外层循环控制“行”，内层循环控制“列”。
// 把矩形看成 H 行 × W 列的字符网格，逐个位置决定该打印字符 C 还是空格：
//   · 实心（F == 1）：所有 H×W 个格子都打印字符 C；
//   · 空心（F == 0）：只有“边框”打印 C，内部打印空格。
// 用下标从 0 开始计数时，边框的判定条件是：首行 i==0、末行 i==H-1、首列 j==0、末列 j==W-1，
// 四者满足其一即为边框；四者都不满足说明在矩形内部。
// 每输出完一整行（内层循环结束）再换行，才能形成正确的矩形形状。
#include <iostream>
using namespace std;

int main() {
    int H, W, F;                            // H：矩形高度（行数）；W：矩形宽度（列数）；F：填充标志，1 实心 / 0 空心
    char C;                                 // C：用来绘制矩形的字符，必须用 char 读取（若用 int 会读错）
    cin >> H >> W >> C >> F;                // 按题目给定顺序一次读入四个参数：H W C F
    for (int i = 0; i < H; i++) {           // 外层循环：i 表示行号，从 0 到 H-1，共输出 H 行
        for (int j = 0; j < W; j++) {       // 内层循环：j 表示列号，从 0 到 W-1，负责打印当前这一行的 W 个字符
            if (F == 1) {                   // 情况一：实心矩形，无需区分位置
                cout << C;                  // 每个格子都直接输出字符 C
            } else {                        // 情况二：F == 0，空心矩形，需要判断当前格子是否位于边框上
                if (i == 0 || i == H - 1 || j == 0 || j == W - 1)  // 首行 / 末行 / 首列 / 末列，任一成立即为边框
                    cout << C;              // 边框位置输出字符 C
                else
                    cout << ' ';            // 其余为矩形内部，输出一个空格占位，保证左右边框对齐
            }
        }
        cout << endl;                       // 一行的 W 个字符打印完毕，换行，准备输出下一行
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(H \times W)$。
- **空间复杂度**：$O(1)$。
