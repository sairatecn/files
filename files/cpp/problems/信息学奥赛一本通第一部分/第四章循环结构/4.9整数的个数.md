# 整数的个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定 $k$ ( $1<k<1001 < k < 1001<k<100$ ) 个正整数，每个整数满足 $1≤x≤101 \le x \le 101≤x≤10$ ，统计其中数字 $1$ 、 $5$ 和 $10$ 出现的次数。

## 输入描述

输入共两行：

- 第一行包含一个正整数 $k$ ；
- 第二行包含 $k$ 个正整数，每两个整数之间用一个空格分隔。

## 输出描述

输出三行：

- 第一行输出数字 $1$ 出现的次数；
- 第二行输出数字 $5$ 出现的次数；
- 第三行输出数字 $10$ 出现的次数。

## 示例

### 用例输入 1

```text
5
1 5 8 10 5
```

### 用例输出 1

```text
1
2
1
```

---

## 题解

### 解题思路

读入 $k$ 个正整数，分别统计数字 1、5、10 各出现了多少次。只需对每个数用 `if` 判断并与三个计数器比较即可。

### 算法分析

1. 读入 $k$。
2. 定义 `cnt1 = 0, cnt5 = 0, cnt10 = 0`。
3. 循环 $k$ 次，每次读入一个数，分别判断是否等于 1、5、10 并累加对应计数器。
4. 依次输出三个计数器的值。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int k;
    cin >> k;
    int cnt1 = 0, cnt5 = 0, cnt10 = 0;
    for (int i = 0; i < k; i++) {
        int x;
        cin >> x;
        if (x == 1) cnt1++;
        if (x == 5) cnt5++;
        if (x == 10) cnt10++;
    }
    cout << cnt1 << endl << cnt5 << endl << cnt10 << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(k)$。
- **空间复杂度**：$O(1)$。
