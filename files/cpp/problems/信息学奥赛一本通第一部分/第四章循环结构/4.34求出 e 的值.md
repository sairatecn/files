# 求出 e 的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

利用公式 $e=1+11!+12!+⋯+1n!e = 1 + \frac{1}{1!} + \frac{1}{2!} + \dots + \frac{1}{n!}e=1+1!1​+2!1​+⋯+n!1​$ ，计算 $e$ 的值，并保留小数点后 10 位。

## 输入描述

输入一行，包含一个整数 $n$ （ $2≤n≤152 \le n \le 152≤n≤15$ ），表示累加到 $1/n!$ 。

## 输出描述

输出一行，表示计算出的 $e$ 的值，保留小数点后 10 位。

## 示例

### 用例输入 1

```text
10
```

### 用例输出 1

```text
2.7182818011
```

---

## 题解

### 解题思路

利用泰勒展开 $e = 1 + 1/1! + 1/2! + \dots + 1/n!$。在循环中维护当前阶乘值，每次迭代将 $1/fact$ 累加到结果中。$n \le 15$ 时精度足够。

### 算法分析

1. 读入 $n$。
2. 定义 `e = 1.0, fact = 1.0`。
3. 循环 $i$ 从 1 到 $n$：`fact *= i`，`e += 1.0 / fact`。
4. 输出 $e$，保留 10 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    double e = 1.0, fact = 1.0;
    for (int i = 1; i <= n; i++) {
        fact *= i;
        e += 1.0 / fact;
    }
    cout << fixed << setprecision(10) << e << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
