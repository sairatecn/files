# 求出 e 的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

利用公式 $e=1+11!+12!+⋯+1n!e = 1 + \frac{1}{1!} + \frac{1}{2!} + \dots + \frac{1}{n!}e=1+1!1​+2!1​+⋯+n!1​$ ，计算 $e$ 的值，并保留小数点后 10 位。

## 输入描述

输入一行，包含一个整数 $n$ （ $2≤n≤152 \le n \le 152≤n≤15$ ），表示累加到 $1/n!$ 。

## 输出描述

输出一行，表示计算出的 $e$ 的值，保留小数点后 10 位。

## 示例

### 用例输入 1

```text
10
```

### 用例输出 1

```text
2.7182818011
```

---

## 题解

### 解题思路

利用泰勒展开 $e = 1 + 1/1! + 1/2! + \dots + 1/n!$。在循环中维护当前阶乘值，每次迭代将 $1/fact$ 累加到结果中。$n \le 15$ 时精度足够。

### 算法分析

1. 读入 $n$。
2. 定义 `e = 1.0, fact = 1.0`。
3. 循环 $i$ 从 1 到 $n$：`fact *= i`，`e += 1.0 / fact`。
4. 输出 $e$，保留 10 位小数。

### 参考代码（C++）

```cpp
// 算法思路：用泰勒级数 e = 1 + 1/1! + 1/2! + ... + 1/n! 近似计算自然常数 e。
// 关键同样是阶乘的递推：i! = (i-1)! * i，用 fact 滚动保存当前阶乘，
// 每轮只做一次乘法得到 i!，再把 1/i! 累加到结果 e 上，整体复杂度 O(n)。
// 累加的初始值 1.0 对应公式中的常数项 1（也可看作 1/0!）。
// 输出需要保留 10 位小数，因此使用 <iomanip> 中的 fixed 与 setprecision(10) 控制格式。
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;                                          // n：级数累加的项数上界，即最后一项为 1/n!（2 ≤ n ≤ 15）
    cin >> n;                                       // 读入 n
    double e = 1.0, fact = 1.0;                     // e：累加结果，初值 1.0 即公式的首项常数 1；fact：滚动保存的阶乘值，初值 1.0 表示 0! = 1
                                                    // 注意 fact 用 double 而非整型：一是与 1.0/fact 的浮点除法保持一致，二是阶乘增长快时不易溢出
    for (int i = 1; i <= n; i++) {                  // 循环变量 i 从 1 到 n，第 i 轮负责计算并累加第 i 项 1/i!
        fact *= i;                                  // 递推得到 i!：上一轮的 (i-1)! 再乘以 i
        e += 1.0 / fact;                            // 把本项 1/i! 加到结果中；写成 1.0 保证是浮点除法而不是整数除法
    }                                               // 循环结束后 e ≈ 1 + 1/1! + ... + 1/n!
    cout << fixed << setprecision(10) << e << endl; // fixed 表示用定点小数形式输出，setprecision(10) 指定保留 10 位小数（不足补零）
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
