# 鸡尾酒疗法

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

鸡尾酒疗法是一种高效抗逆转录病毒治疗方法。设鸡尾酒疗法的有效率为 $x$ ，新疗法的有效率为 $y$ 。若 $y−x>5%y-x>5\%y−x>5%$ ，则新疗法效果更好；若 $x−y>5%x-y>5\%x−y>5%$ ，则新疗法效果更差；否则认为效果差不多。给定 $n$ 组临床对照实验数据，其中第一组为鸡尾酒疗法，其余为改进疗法，判断每种改进疗法的效果。

## 输入描述

- 第一行一个整数 $n$ （ $1<n≤201<n\le201<n≤20$ ）。
- 接下来 $n$ 行，每行两个整数，分别表示实验总病例数和有效病例数（总病例数 $≤10000\le10000≤10000$ ）。第一行对应鸡尾酒疗法，其余对应改进疗法。

## 输出描述

- 输出 $n−1n-1n−1$ 行，每行一个字符串：better、worse 或 same，表示对应改进疗法的效果。

## 示例

### 用例输入 1

```text
5
125 99
112 89
145 99
99 97
123 98
```

### 用例输出 1

```text
same
worse
better
same
```

---

## 题解

### 解题思路

先计算鸡尾酒疗法（第 1 组）的有效率 $x = \frac{有效数}{总数} \times 100\%$。然后对后续每组计算有效率 $y$，比较 $y - x$ 与 $5\%$ 的关系来判断效果。

### 算法分析

1. 读入 $n$，先读入第 1 组的总数和有效数，计算基准有效率 $x$。
2. 循环 $n-1$ 次，每次读入一组数据，计算有效率 $y$。
3. 若 $y - x > 5$，输出 `better`；若 $x - y > 5$，输出 `worse`；否则输出 `same`。

### 参考代码（C++）

```cpp
// 【整体思路】先算出基准有效率，再逐组比较的"打擂台式"分类判断。
// 第 1 组数据是鸡尾酒疗法，把它的有效率 x 当作比较基准（只算一次）；
// 之后每读入一组改进疗法数据就算出它的有效率 y，用 y 与 x 的差值分三档判断：
//   y - x > 5%  -> better（新疗法明显更好）
//   x - y > 5%  -> worse （新疗法明显更差）
//   其余情况    -> same  （差距在 5% 以内，认为差不多）
// 有效率 = 有效病例数 / 总病例数，必须用浮点除法，否则整数相除会被截断成 0。
#include <iostream>
using namespace std;

int main() {
    int n;                        // n：实验组数（含第 1 组鸡尾酒疗法），1 < n <= 20
    cin >> n;                     // 读入组数
    int total, effective;         // total：某一组的实验总病例数；effective：该组中治疗有效的病例数
                                  // 这两个变量在循环中被反复复用，每读一组就覆盖一次
    cin >> total >> effective;    // 先单独读入第 1 组（鸡尾酒疗法）的数据，它是比较的基准
    // 关键计算：(double)effective 先把分子强制转成 double，避免 int/int 的整数除法丢掉小数部分；
    // 再乘 100.0 换算成百分数，得到基准有效率 x（单位：%）
    double x = (double)effective / total * 100.0;

    // 遍历剩下的 n-1 组改进疗法：i 从 1 到 n-1，共循环 n-1 次，每次输出一行结论
    for (int i = 1; i < n; i++) {
        cin >> total >> effective;                    // 读入第 i+1 组的总病例数与有效病例数
        double y = (double)effective / total * 100.0; // 同样方式算出这组改进疗法的有效率 y（单位：%）
        // 三分支判断：因为 x、y 已经是百分数，所以阈值 5% 直接写成数字 5
        if (y - x > 5) cout << "better" << endl;      // 比基准高出超过 5 个百分点 -> 更好
        else if (x - y > 5) cout << "worse" << endl;  // 比基准低了超过 5 个百分点 -> 更差
        else cout << "same" << endl;                  // 差值落在 [-5, 5] 区间内 -> 差不多
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
