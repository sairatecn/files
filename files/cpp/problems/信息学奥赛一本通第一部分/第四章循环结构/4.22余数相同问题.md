# 余数相同问题

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知三个正整数 $a,b,ca, b, ca,b,c$ 。寻找大于1的整数 $x$ ，使 $amodx=bmodx=cmodxa \bmod x = b \bmod x = c \bmod xamodx=bmodx=cmodx$ 。求满足条件的最小 $x$ ，题目保证有解。

## 输入描述

输入一行，包含三个正整数 $a,b,ca, b, ca,b,c$ $(≤1000000)(\le 1000000)(≤1000000)$ ，用空格隔开。

## 输出描述

输出一个整数，为满足条件的最小 $x$ 。

## 示例

### 用例输入 1

```text
300 262 205
```

### 用例输出 1

```text
19
```

---

## 题解

### 解题思路

若 $a \bmod x = b \bmod x = c \bmod x$，则 $(a-b)$ 和 $(b-c)$ 都能被 $x$ 整除，即 $x$ 是 $(a-b)$ 和 $(b-c)$ 的公因子。从 $x = 2$ 开始逐个尝试，找到第一个满足条件的即可。

### 算法分析

1. 读入 $a, b, c$。
2. 从 $x = 2$ 开始递增，检查 `a % x == b % x && b % x == c % x`。
3. 找到第一个满足条件的 $x$ 即输出。

### 参考代码（C++）

```cpp
// 算法思路：要找最小的 x(>1)，使 a%x == b%x == c%x。
// 数学上，若 a、b 对 x 的余数相同，则 x 必能整除 (a-b)；同理 x 也能整除 (b-c)，
// 所以答案一定是 |a-b| 与 |b-c| 的公因子，因此 x 不会太大。
// 这里采用最直观的「枚举法」：从 x=2 开始由小到大逐个试，
// 由于是从小往大枚举，第一个满足条件的 x 必然就是最小解，找到即可输出并结束程序。
#include <iostream>
using namespace std;

int main() {
    int a, b, c;                    // a、b、c：题目给定的三个正整数（均 <= 1000000）
    cin >> a >> b >> c;             // 读入这三个数
    // 枚举除数 x，从 2 开始（题目要求 x>1），每轮加 1；
    // 循环条件留空表示死循环，因为题目保证有解，找到答案后会在循环体内直接 return 退出
    for (int x = 2; ; x++) {
        // 判断三个数对当前 x 取余是否两两相等：
        // 只需检查 a%x == b%x 且 b%x == c%x，由等式传递性可知 a%x == c%x 也成立
        if (a % x == b % x && b % x == c % x) {
            cout << x << endl;      // 输出找到的最小 x
            return 0;               // 立即结束程序，保证输出的是最小解而不会继续枚举
        }
    }
}
```

### 复杂度分析

- **时间复杂度**：$O(x)$，$x$ 为答案值，通常很小。
- **空间复杂度**：$O(1)$。
