# 正常血压

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

监护室每小时测量一次病人的血压，若收缩压在 $90−14090-14090−140$ 之间且舒张压在 $60−9060-9060−90$ 之间(包含端点)，则为正常。求连续正常血压的最长小时数。

## 输入描述

第一行一个正整数 $n$ ，表示测量次数。
接下来的 $n$ 行，每行两个正整数 $s$ 和 $d$ ，分别表示一次测量的收缩压和舒张压。

## 输出描述

一行一个整数，表示病人连续保持正常血压的最长小时数。

## 示例

### 用例输入 1

```text
4
100 80
90 50
120 60
140 90
```

### 用例输出 1

```text
2
```

---

## 题解

### 解题思路

维护一个"当前连续正常次数"和一个"历史最大连续正常次数"。每次测量判断是否血压正常：若正常则当前计数 +1 并更新最大值；若不正常则当前计数归零。

### 算法分析

1. 读入 $n$。
2. 定义 `current = 0, maxLen = 0`。
3. 循环 $n$ 次，每次读入收缩压 $s$ 和舒张压 $d$。
4. 若 $90 \le s \le 140$ 且 $60 \le d \le 90$，则 `current++`，`maxLen = max(maxLen, current)`；否则 `current = 0`。
5. 输出 `maxLen`。

### 参考代码（C++）

```cpp
// 【整体思路】求"最长连续满足条件的段长"，经典做法是一次扫描 + 两个计数器。
// 用 current 记录"以当前这次测量为结尾的连续正常次数"，用 maxLen 打擂台记录历史最大值。
// 扫描每一次测量：
//   若血压正常 -> 连续段可以延长，current 加一，并尝试更新最大值 maxLen；
//   若血压异常 -> 连续段被打断，current 清零，从下一次测量重新开始计数。
// 因为每次正常时都及时更新了 maxLen，所以即使最长段出现在中间也不会漏掉，
// 只需一趟 O(n) 扫描，无需保存全部数据。
#include <iostream>
using namespace std;

int main() {
    int n;                          // n：总的测量次数（每小时测一次，故次数即小时数）
    cin >> n;                       // 读入测量次数
    int current = 0, maxLen = 0;    // current：当前正在延续的连续正常次数（被异常打断就归零）
                                    // maxLen：到目前为止出现过的最长连续正常次数，即最终答案
    // 按时间顺序扫描每一次测量：i 从 0 到 n-1，共 n 次
    // 每次迭代读入一组血压值，判断正常与否，并相应地延长或重置连续计数
    for (int i = 0; i < n; i++) {
        int s, d;                   // s：本次测得的收缩压（高压）；d：本次测得的舒张压（低压）
        cin >> s >> d;              // 读入一行两个整数
        // 关键判断：收缩压落在 [90, 140] 且舒张压落在 [60, 90] 才算正常，四个条件必须同时成立
        // 用 <= 和 >= 表示区间包含端点，与题目"包含端点"的要求一致
        if (s >= 90 && s <= 140 && d >= 60 && d <= 90) {
            current++;                              // 血压正常：当前连续段长度加一
            if (current > maxLen) maxLen = current; // 打擂台：若当前连续长度刷新了纪录，就更新最大值
        } else {
            current = 0;            // 血压异常：连续被中断，当前计数清零，重新从 0 开始累计
                                    // 注意这里不动 maxLen，历史最好成绩要保留下来
        }
    }
    cout << maxLen << endl;         // 输出连续保持正常血压的最长小时数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
