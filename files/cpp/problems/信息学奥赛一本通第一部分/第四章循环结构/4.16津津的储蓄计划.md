# 津津的储蓄计划

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

津津每月初得到300元零花钱，并根据预算花费。每月可将整百存入妈妈那里，年末妈妈会加上20％返还。

- 每月预算不超过手中可支配的钱，否则输出负号加月份。
- 计算到年末妈妈返还后的津津总钱数。

## 输入描述

12行，每行一个整数，表示1月到12月津津的预算。

## 输出描述

如果某个月预算超过可用钱，输出 -X（X为月份），否则输出年末总钱数。

## 示例

### 用例输入 1

```text
290
230
280
200
300
170
330
50
90
80
200
60
```

### 用例输出 1

```text
1580
```

---

## 题解

### 解题思路

模拟津津每月的收支过程。每月初津津手中有上月剩余 + 300 元零花钱。若当月预算超过可用金额则失败，输出负月份号。否则扣除预算后，将整百部分存入妈妈处，零头留在手中。年末妈妈返还存款 × 1.2，加上手中零头即为总数。

### 算法分析

1. 定义 `handMoney = 0`（手中钱）, `savedMoney = 0`（存妈妈处的钱）。
2. 循环 12 个月：每月 `handMoney += 300`，读入预算 `budget`。
3. 若 `handMoney < budget`，输出 `-月份` 并结束。
4. 否则 `handMoney -= budget`，存入 `saved = (handMoney / 100) * 100`，`savedMoney += saved`，`handMoney -= saved`。
5. 年末总数 = `savedMoney * 1.2 + handMoney`。

### 参考代码（C++）

```cpp
// 【整体思路】按月份顺序模拟一整年的收支与存钱过程。
// 需要同时跟踪两笔钱：手里的现金 handMoney、存在妈妈那里的钱 savedMoney。
// 每个月的流程固定为四步：
//   1) 月初领 300 元零花钱，加入手中现金；
//   2) 若手中现金不够本月预算，说明计划失败，立即输出 "-月份" 并结束程序；
//   3) 付掉本月预算；
//   4) 把剩余现金中的整百部分存给妈妈，零头（不足 100 的部分）继续留在手里。
// 十二个月都顺利过完后，妈妈把存款按 20% 的利息返还（即乘 1.2），
// 加上手中剩余的零头就是年末总钱数。
#include <iostream>
using namespace std;

int main() {
    int handMoney = 0, savedMoney = 0;   // handMoney：津津手中现有的现金（年初为 0）
                                         // savedMoney：累计存放在妈妈处的金额（始终是 100 的整数倍）
    // 按月循环模拟：month 从 1 到 12，代表 1 月至 12 月，共 12 次迭代
    // 之所以让 month 从 1 开始，是因为失败时要直接输出月份号
    for (int month = 1; month <= 12; month++) {
        int budget;                      // budget：本月的预算（计划花费金额）
        cin >> budget;                   // 读入当月预算
        handMoney += 300;                // 月初固定收入：妈妈给的 300 元零花钱进入手中现金
        // 关键判断：手中现金不足以支付本月预算，则本月开始"不高兴"，计划失败
        if (handMoney < budget) {
            cout << "-" << month << endl; // 按题目要求输出负号加月份号，例如 4 月失败输出 -4
            return 0;                     // 一旦失败立即结束程序，后续月份不再处理
        }
        handMoney -= budget;             // 支付本月预算，从手中现金里扣除
        // 关键计算：取出剩余现金中的整百部分。整数除法 handMoney / 100 会自动舍去零头，
        // 再乘回 100 就得到能存入的最大整百金额，例如 380 -> 3 * 100 = 300
        int save = (handMoney / 100) * 100;
        savedMoney += save;              // 这笔整百的钱交给妈妈保管，累加到存款中
        handMoney -= save;               // 手中只留下不足 100 的零头，带入下个月继续使用
    }
    // 年末结算：妈妈把存款连本带利（20% 利息，即 ×1.2）还回来，再加上手中剩余的零头。
    // savedMoney * 1.2 会先把 int 提升为 double 做浮点乘法，最后强制转回 int 以整数形式输出
    cout << (int)(savedMoney * 1.2 + handMoney) << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定 12 个月。
- **空间复杂度**：$O(1)$。
