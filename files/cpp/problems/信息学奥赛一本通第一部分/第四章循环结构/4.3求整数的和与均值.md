# 求整数的和与均值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

读入 $n$ ( $1≤n≤100001 \le n \le 100001≤n≤10000$ ) 个整数，计算它们的和与均值。

## 输入描述

输入包括多行：

- 第一行是一个整数 $n$ ，表示有 $n$ 个整数；
- 第 $2$ 行到第 $n+1$ 行，每行包含 $1$ 个整数，每个整数的绝对值均不超过 $10000$ 。

## 输出描述

输出一行，先输出所有整数的和，再输出平均值（保留到小数点后 $5$ 位），两个数之间用一个空格分隔。

## 示例

### 用例输入 1

```text
4
100
200
300
531
```

### 用例输出 1

```text
1131 282.75000
```

---

## 题解

### 解题思路

读入 $n$ 个整数，累加求和，再用和除以 $n$ 得到均值。注意整数之和可能超出 `int` 范围，应使用 `long long` 存储。均值保留 5 位小数。

### 算法分析

1. 读入 $n$。
2. 定义 `long long sum = 0`，循环 $n$ 次累加。
3. 先输出 `sum`（整数），再输出 `sum / n`（浮点，保留 5 位小数），中间空格分隔。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>   // 引入 iomanip，用于 fixed 与 setprecision 控制输出小数位数
using namespace std;

int main() {
    int n;              // n 表示整数个数
    cin >> n;           // 读入整数个数
    long long sum = 0;  // 用 long long 存储总和，防止 n 个数累加后超出 int 范围
    // 循环读入 n 个整数；i 从 0 到 n-1，共循环 n 次
    for (int i = 0; i < n; i++) {
        int x;          // x 临时存放每次读入的单个整数
        cin >> x;       // 读入当前整数
        sum += x;       // 将当前整数累加到 sum 中
    }
    // 先输出整数和 sum，再输出空格，随后输出均值；
    // (double)sum / n 做浮点除法，fixed + setprecision(5) 保留 5 位小数
    cout << sum << " " << fixed << setprecision(5) << (double)sum / n << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
