# 统计满足条件的4位数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定若干个四位数，求出其中满足条件的数的个数：

- 条件： $个位数−千位数−百位数−十位数>0个位数 - 千位数 - 百位数 - 十位数 > 0个位数−千位数−百位数−十位数>0$

## 输入描述

输入为两行：

- 第一行为四位数的个数 $n$ $(n≤100)(n \le 100)(n≤100)$
- 第二行为 $n$ 个四位数，数字间用空格分隔

## 输出描述

输出为一行，包含一个整数，表示满足条件的四位数的个数

## 示例

### 用例输入 1

```text
5
1234 1349 6119 2123 5017
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

对每个四位数，分离出千位、百位、十位、个位数字，判断是否满足"个位 - 千位 - 百位 - 十位 > 0"。分离各位数字可通过整除和取余实现。

### 算法分析

1. 读入 $n$。
2. 循环 $n$ 次，每次读入一个四位数 `num`。
3. 分离各位：`qian = num / 1000`，`bai = num / 100 % 10`，`shi = num / 10 % 10`，`ge = num % 10`。
4. 若 `ge - qian - bai - shi > 0` 则计数 +1。
5. 输出计数。

### 参考代码（C++）

```cpp
// 算法思路：逐个读入 n 个四位数，用「整除 + 取余」的方式把每个数拆成
// 千位、百位、十位、个位四个数字，再判断是否满足 个位-千位-百位-十位>0，
// 满足就把计数器加一。整个过程只需一趟循环，边读边判断，无需存下所有数据。
#include <iostream>
using namespace std;

int main() {
    int n;                          // n：待处理的四位数的个数（n <= 100）
    cin >> n;                       // 读入数据个数
    int cnt = 0;                    // cnt：计数器，记录满足条件的四位数有多少个，初始为 0
    for (int i = 0; i < n; i++) {   // 循环 n 次，i 从 0 到 n-1，每次处理一个四位数
        int num;                    // num：当前正在处理的这个四位数
        cin >> num;                 // 读入当前四位数
        // 下面四行是「数位拆分」：核心技巧是先用整除把想要的那一位挪到个位，再用 %10 取出它
        int qian = num / 1000;      // 千位：除以 1000 直接得到最高位（如 1234/1000 = 1）
        int bai = num / 100 % 10;   // 百位：先 /100 去掉低两位（1234→12），再 %10 取末位（12%10 = 2）
        int shi = num / 10 % 10;    // 十位：先 /10 去掉个位（1234→123），再 %10 取末位（123%10 = 3）
        int ge = num % 10;          // 个位：直接对 10 取余即可（1234%10 = 4）
        if (ge - qian - bai - shi > 0) cnt++;   // 条件判断：个位减去其余三位仍大于 0，则计数加一
    }
    cout << cnt << endl;            // 输出满足条件的四位数总个数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
