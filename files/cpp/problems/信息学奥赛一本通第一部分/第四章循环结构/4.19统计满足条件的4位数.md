# 统计满足条件的4位数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定若干个四位数，求出其中满足条件的数的个数：

- 条件： $个位数−千位数−百位数−十位数>0个位数 - 千位数 - 百位数 - 十位数 > 0个位数−千位数−百位数−十位数>0$

## 输入描述

输入为两行：

- 第一行为四位数的个数 $n$ $(n≤100)(n \le 100)(n≤100)$
- 第二行为 $n$ 个四位数，数字间用空格分隔

## 输出描述

输出为一行，包含一个整数，表示满足条件的四位数的个数

## 示例

### 用例输入 1

```text
5
1234 1349 6119 2123 5017
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

对每个四位数，分离出千位、百位、十位、个位数字，判断是否满足"个位 - 千位 - 百位 - 十位 > 0"。分离各位数字可通过整除和取余实现。

### 算法分析

1. 读入 $n$。
2. 循环 $n$ 次，每次读入一个四位数 `num`。
3. 分离各位：`qian = num / 1000`，`bai = num / 100 % 10`，`shi = num / 10 % 10`，`ge = num % 10`。
4. 若 `ge - qian - bai - shi > 0` 则计数 +1。
5. 输出计数。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;
        int qian = num / 1000;
        int bai = num / 100 % 10;
        int shi = num / 10 % 10;
        int ge = num % 10;
        if (ge - qian - bai - shi > 0) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
