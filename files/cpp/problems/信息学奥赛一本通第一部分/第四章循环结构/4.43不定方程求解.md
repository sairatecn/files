# 不定方程求解

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定正整数 $a,b,ca, b, ca,b,c$ ，求不定方程 $ax+by=cax + by = cax+by=c$ 的所有非负整数解 $(x,y)(x, y)(x,y)$ 的个数。

## 输入描述

一行输入三个正整数 $a,b,ca, b, ca,b,c$ ，用空格隔开，且 $1≤a,b,c≤10001 \le a,b,c \le 10001≤a,b,c≤1000$ 。

## 输出描述

输出一个整数，表示不定方程的非负整数解个数。

## 示例

### 用例输入 1

```text
2 3 18
```

### 用例输出 1

```text
4
```

---

## 题解

### 解题思路

方程 $ax + by = c$ 的非负整数解：枚举 $x$ 从 0 到 $c/a$，对每个 $x$ 计算 $c - ax$，若能被 $b$ 整除且商非负，则找到一组解。

### 算法分析

1. 读入 $a, b, c$。
2. 定义 `count = 0`，循环 $x$ 从 0 到 $c/a$。
3. 计算 `rem = c - a * x`，若 `rem >= 0` 且 `rem % b == 0` 则 `count++`。
4. 输出 `count`。

### 参考代码（C++）

```cpp
// 【整体思路】枚举其中一个未知数，另一个由方程直接确定。
// 方程 ax + by = c 有两个未知数，直接解不定方程较麻烦；但注意 x、y 都要求是非负整数，
// 由 ax ≤ c 可知 x 的取值范围只有 0 ≤ x ≤ c/a，是一段很短的区间（a、c ≤ 1000）。
// 因此枚举每一个可能的 x，剩下的部分 rem = c - ax 就是 by 的值：
//   · 若 rem 能被 b 整除，则 y = rem / b 是整数，且由 rem ≥ 0 保证 y ≥ 0，构成一组合法解；
//   · 否则该 x 无对应的整数 y，跳过。
// 循环条件 a * x <= c 已经保证了 rem ≥ 0，所以循环体内不必再判断 rem 的符号。
#include <iostream>
using namespace std;

int main() {
    int a, b, c;                            // a、b：方程 ax + by = c 中两个未知数的系数；c：等式右边的常数
    cin >> a >> b >> c;                     // 一行读入三个正整数 a、b、c
    int count = 0;                          // count：满足条件的非负整数解 (x, y) 的组数，计数器初始为 0
    for (int x = 0; a * x <= c; x++) {      // 枚举循环：x 从 0 开始递增；当 a*x 超过 c 时 rem 会变负，y 不可能非负，故以 a*x <= c 为上界
        int rem = c - a * x;                // rem：把 ax 移到右边后剩余的值，即 by 应当等于的数；由循环条件保证 rem >= 0
        if (rem % b == 0) {                 // 整除判断：rem 能被 b 整除，说明 y = rem / b 是整数，又因 rem >= 0 故 y >= 0，是一组合法解
            count++;                        // 找到一组非负整数解 (x, rem / b)，解的个数加 1
        }
    }
    cout << count << endl;                  // 输出非负整数解的总组数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(c/a)$，$c \le 1000$，完全可接受。
- **空间复杂度**：$O(1)$。
