# 金币

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

国王将金币作为工资发放给骑士。第1天骑士获得1枚金币；第2、3天每天获得2枚金币；第4~6天每天获得3枚金币；第7~10天每天获得4枚金币……依此类推。输入天数 $n$ ，求骑士在前 $n$ 天内总共获得多少金币。

## 输入描述

一个整数 $n$ $(1≤n≤10000)(1 \le n \le 10000)(1≤n≤10000)$ ，表示天数。

## 输出描述

骑士获得的金币总数。

## 示例

### 用例输入 1

```text
10
```

### 用例输出 1

```text
30
```

---

## 题解

### 解题思路

金币发放的规律是：第 1 组发 1 天每天 1 枚，第 2 组发 2 天每天 2 枚，第 3 组发 3 天每天 3 枚，依此类推。模拟发放过程，逐天计算金币数并累加，直到 $n$ 天结束。

### 算法分析

1. 读入 $n$。
2. 定义 `day = 0, coins = 0, reward = 1`。
3. 当 `day < n` 时：当前组发 `reward` 天，每天发 `reward` 枚金币。
   - 循环 `reward` 次：若 `day < n` 则 `coins += reward, day++`。
4. `reward++`，进入下一组。
5. 输出 `coins`。

### 参考代码（C++）

```cpp
// 【整体思路】按“分组发放”的规律直接模拟。
// 发放规律：第 1 组连续 1 天，每天 1 枚；第 2 组连续 2 天，每天 2 枚；
// 第 3 组连续 3 天，每天 3 枚……即第 k 组持续 k 天，每天发 k 枚金币。
// 于是用外层 while 一组一组地推进，用内层 for 在组内逐天发放并累加金币，
// 一旦已发放的天数达到 n 就立刻停止（最后一组可能只发了一部分天数，所以内层循环要额外判断 day < n）。
// 因为 1+2+...+k ≈ n，组数 k 约为 √(2n) 量级，n ≤ 10000 时循环次数很少。
#include <iostream>
using namespace std;

int main() {
    int n;                                  // n：总天数，需要统计前 n 天累计获得的金币
    cin >> n;                               // 读入天数 n
    int day = 0, coins = 0, reward = 1;     // day：已经发放完的天数；coins：金币总数（累加器）；reward：当前组每天发放的金币数，同时也等于该组的持续天数
    while (day < n) {                       // 外层循环：只要还没发满 n 天，就继续处理下一组（第 reward 组）
        for (int i = 0; i < reward && day < n; i++) {  // 内层循环：本组共发 reward 天（i 从 0 到 reward-1）；同时用 day < n 保证不超过总天数，最后一组可能提前中断
            coins += reward;                // 这一天发放 reward 枚金币，累加进总数
            day++;                          // 已发放天数加 1
        }
        reward++;                           // 本组发完，进入下一组：每天的金币数和该组天数同时加 1
    }
    cout << coins << endl;                  // 输出前 n 天获得的金币总数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\sqrt{n})$，因为组数 $k$ 满足 $k(k+1)/2 \approx n$。
- **空间复杂度**：$O(1)$。
