# 与指定数字相同的数的个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个长度为 $N$ 的整数序列，统计其中与指定数字 $m$ 相同的元素个数。

## 输入描述

输入共两行：

- 第一行包含两个整数 $N$ 和 $m$ ，表示整数序列的长度（ $N≤100N \le 100N≤100$ ）和指定的数字，中间用一个空格分隔；
- 第二行包含 $N$ 个整数，整数之间以一个空格分隔。

## 输出描述

输出一行，表示序列中与 $m$ 相同的数的个数。

## 示例

### 用例输入 1

```text
3 2
2 3 2
```

### 用例输出 1

```text
2
```

---

## 题解

### 解题思路

给定序列长度 $N$ 和目标值 $m$，遍历序列统计等于 $m$ 的元素个数即可。

### 算法分析

1. 读入 $N$ 和 $m$。
2. 定义 `cnt = 0`，循环 $N$ 次读入元素，若等于 $m$ 则 `cnt++`。
3. 输出 `cnt`。

### 参考代码（C++）

```cpp
// 【整体思路】边读边统计的"计数型"循环。
// 本题只需知道序列中有多少个数等于 m，并不需要把整个序列保存下来，
// 所以不用开数组：每读入一个数就立刻和 m 比较，相等就把计数器加一。
// 这样空间只需要 O(1)，时间为一次线性扫描 O(N)。
#include <iostream>
using namespace std;

int main() {
    int n, m;              // n：序列中整数的个数（题目保证 n <= 100）；m：要统计的目标数字
    cin >> n >> m;         // 读入第一行的两个整数：序列长度 n 和目标值 m
    int cnt = 0;           // 计数器，记录"与 m 相同的数"出现了多少次，开始时一个都没找到，所以初始化为 0
    // 循环读入第二行的 N 个整数：i 从 0 递增到 n-1，共执行 n 次
    // 每次迭代完成"读入一个数 -> 判断是否等于 m -> 决定是否计数"这三件事
    for (int i = 0; i < n; i++) {
        int x;             // x：临时变量，只保存当前这一次读入的那个整数，下一轮会被覆盖
        cin >> x;          // 读入序列中的第 i+1 个整数
        if (x == m) cnt++; // 关键判断：当前数与目标值 m 完全相等时，计数器自增 1
    }
    cout << cnt << endl;   // 循环结束后 cnt 就是答案：序列中等于 m 的元素总个数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(N)$。
- **空间复杂度**：$O(1)$。
