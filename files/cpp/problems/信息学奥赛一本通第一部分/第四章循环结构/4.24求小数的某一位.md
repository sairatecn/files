# 求小数的某一位

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定三个正整数 $a,b,na, b, na,b,n$ ，求分数 $ab\frac{a}{b}ba​$ 化为小数后，小数点后第 $n$ 位的数字。

## 输入描述

输入三个正整数 $a,b,na, b, na,b,n$ ，用空格隔开，满足 $0<a<b<100,1≤n≤100000 < a < b < 100, 1 \le n \le 100000<a<b<100,1≤n≤10000$ 。

## 输出描述

输出一个数字，为小数点后第 $n$ 位。

## 示例

### 用例输入 1

```text
1 2 1
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

模拟手工除法过程。先对 $a$ 取余得到 $a \bmod b$（整数部分不影响小数位），然后重复 $n$ 次：将余数乘以 10，再除以 $b$ 得到当前小数位，更新余数。第 $n$ 次的商即为所求。

### 算法分析

1. 读入 $a, b, n$。
2. `a = a % b`（去掉整数部分）。
3. 循环 $n$ 次：`a *= 10`，`digit = a / b`，`a = a % b`。
4. 输出 `digit`。

### 参考代码（C++）

```cpp
// 算法思路：n 最大到 10000 位，double 只有约 15 位有效数字，直接算 a/b 再取位一定不够精度，
// 因此必须用「整数模拟竖式除法」的办法，全程只用整数运算，不产生任何精度误差。
// 手工除法的规律是：把余数补一个 0（即乘 10）再去除以 b，得到的商就是下一位小数，
// 剩下的余数继续参与下一轮。重复 n 次，第 n 次得到的商就是小数点后第 n 位。
#include <iostream>
using namespace std;

int main() {
    int a, b, n;                    // a：分子；b：分母；n：要求的是小数点后第几位
    cin >> a >> b >> n;             // 读入这三个正整数（0 < a < b < 100，1 <= n <= 10000）
    // 先取余去掉整数部分，只保留真正参与小数运算的余数；
    // 整数部分对小数位没有任何影响（本题 a<b 时结果仍是 a，但这样写更通用）
    a = a % b;
    int digit = 0;                  // digit：每轮竖式除法得到的商，即当前这一位小数
    // 循环 n 次，i 从 0 到 n-1，第 i 轮算出的是小数点后第 i+1 位，
    // 循环结束时 digit 中保存的正是第 n 位
    for (int i = 0; i < n; i++) {
        a *= 10;                    // 余数末尾补 0（竖式除法中的「落位」操作）
        digit = a / b;              // 整数除法求商，得到当前这一位小数（必为 0~9）
        a = a % b;                  // 取余得到新的余数，留给下一轮继续除
        // 注意：因为 a < b < 100，所以 a*10 < 1000，全程不会超出 int 范围
    }
    cout << digit << endl;          // 输出小数点后第 n 位数字
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
