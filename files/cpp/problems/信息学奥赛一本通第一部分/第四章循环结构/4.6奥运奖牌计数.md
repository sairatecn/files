# 奥运奖牌计数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在 $2008$ 年北京奥运会中，A 国运动员参与了 $n$ 天的决赛项目，统计其获得的金牌、银牌、铜牌总数以及总奖牌数。

## 输入描述

输入共 $n+1$ 行：

- 第 $1$ 行为一个整数 $n$ ( $1≤n≤171 \le n \le 171≤n≤17$ )，表示参与决赛项目的天数；
- 其后 $n$ 行，每行包含 $3$ 个整数，分别表示该国某一天获得的金牌、银牌、铜牌数目，整数之间以一个空格分隔。

## 输出描述

输出一行，包含 $4$ 个整数，分别为金牌总数、银牌总数、铜牌总数以及总奖牌数，整数之间以一个空格分隔。

## 示例

### 用例输入 1

```text
3
1 0 3
3 1 0
0 3 0
```

### 用例输出 1

```text
4 4 3 11
```

---

## 题解

### 解题思路

本题是一道简单的累加统计题。给定 $n$ 天中每天获得的金牌、银牌、铜牌数量，需要分别累加三种奖牌的总数，并计算总奖牌数（三者之和）。

### 算法分析

1. 读入天数 $n$。
2. 定义三个累加变量 `gold`、`silver`、`bronze`，初始值均为 $0$。
3. 循环 $n$ 次，每次读入当天的金、银、铜牌数，分别累加到对应变量中。
4. 循环结束后，输出 `gold`、`silver`、`bronze` 以及三者之和 `gold + silver + bronze`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;                          // n 表示参与决赛项目的天数
    cin >> n;                       // 读入天数

    // gold/silver/bronze 分别累计金、银、铜牌总数，初始均为 0
    int gold = 0, silver = 0, bronze = 0;
    // 循环 n 天，逐天读入并处理；i 从 0 到 n-1
    for (int i = 0; i < n; i++) {
        int g, s, b;                // 当天获得的金、银、铜牌数
        cin >> g >> s >> b;         // 读入当天三种奖牌数量
        gold += g;                  // 把当天金牌数累加到金牌总数
        silver += s;                // 把当天银牌数累加到银牌总数
        bronze += b;                // 把当天铜牌数累加到铜牌总数
    }

    // 依次输出金、银、铜牌总数，以及三者之和（总奖牌数），用空格分隔
    cout << gold << " " << silver << " " << bronze << " "
         << gold + silver + bronze << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，循环 $n$ 次完成累加。
- **空间复杂度**：$O(1)$，仅使用常数级别的额外变量。
