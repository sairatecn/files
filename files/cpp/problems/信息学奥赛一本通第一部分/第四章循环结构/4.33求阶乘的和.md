# 求阶乘的和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定正整数 $n$ ，求不大于 $n$ 的所有正整数阶乘的和，即计算 $1!+2!+⋯+n!1!+2!+\dots+n!1!+2!+⋯+n!$ 。

## 输入描述

输入一行，包含一个正整数 $n$ ，其中 $1<n<12$ 。

## 输出描述

输出一行，表示阶乘的和。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
153
```

---

## 题解

### 解题思路

计算 $1! + 2! + \dots + n!$。注意阶乘增长极快，但 $n < 12$，$11! = 39916800$，累加和不会超出 `long long` 范围。每次迭代可利用前一项的阶乘结果，避免重复计算。

### 算法分析

1. 读入 $n$。
2. 定义 `sum = 0, fact = 1`。
3. 循环 $i$ 从 1 到 $n$：`fact *= i`，`sum += fact`。
4. 输出 `sum`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum = 0, fact = 1;
    for (int i = 1; i <= n; i++) {
        fact *= i;
        sum += fact;
    }
    cout << sum << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
