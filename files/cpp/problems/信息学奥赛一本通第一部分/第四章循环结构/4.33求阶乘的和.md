# 求阶乘的和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定正整数 $n$ ，求不大于 $n$ 的所有正整数阶乘的和，即计算 $1!+2!+⋯+n!1!+2!+\dots+n!1!+2!+⋯+n!$ 。

## 输入描述

输入一行，包含一个正整数 $n$ ，其中 $1<n<12$ 。

## 输出描述

输出一行，表示阶乘的和。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
153
```

---

## 题解

### 解题思路

计算 $1! + 2! + \dots + n!$。注意阶乘增长极快，但 $n < 12$，$11! = 39916800$，累加和不会超出 `long long` 范围。每次迭代可利用前一项的阶乘结果，避免重复计算。

### 算法分析

1. 读入 $n$。
2. 定义 `sum = 0, fact = 1`。
3. 循环 $i$ 从 1 到 $n$：`fact *= i`，`sum += fact`。
4. 输出 `sum`。

### 参考代码（C++）

```cpp
// 算法思路：求 1! + 2! + ... + n!。
// 朴素做法是对每个 i 都从头乘一遍算出 i!，那样是 O(n^2) 的重复劳动；
// 这里利用递推关系 i! = (i-1)! * i：用变量 fact 保存“上一项的阶乘值”，
// 每轮只需再乘一个 i 就得到当前项 i!，然后把它累加进 sum，整体只需 O(n)。
// 由于 n < 12，最大 11! = 39916800，累加和约为 4.3×10^7，虽然 int 也放得下，
// 但用 long long 更保险，可避免 n 稍大时的溢出风险。
#include <iostream>
using namespace std;

int main() {
    int n;                              // n：题目给定的上界，需要求 1! 到 n! 的和（1 < n < 12）
    cin >> n;                           // 读入 n
    long long sum = 0, fact = 1;        // sum：阶乘之和的累加器，初值为 0；fact：滚动保存当前的阶乘值，初值为 1 表示 0! = 1
    for (int i = 1; i <= n; i++) {      // 循环变量 i 从 1 递增到 n，第 i 轮负责生成并累加第 i 项 i!
        fact *= i;                      // 递推：由上一轮的 (i-1)! 乘 i 得到本轮的 i!，避免重复从头计算阶乘
        sum += fact;                    // 把本轮算出的 i! 累加到总和中
    }                                   // 循环结束后 sum 即为 1! + 2! + ... + n!
    cout << sum << endl;                // 输出阶乘之和
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
