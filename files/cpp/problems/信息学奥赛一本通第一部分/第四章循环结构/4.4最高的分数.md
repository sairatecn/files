# 最高的分数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定参加《计算概论》期中考试的 $n$ 名学生成绩，求其中的最高分数。

## 输入描述

输入共两行：

- 第一行是一个整数 $n$ ( $1≤n<1001 \le n < 1001≤n<100$ )，表示参加考试的人数；
- 第二行包含 $n$ 个整数，表示每位学生的成绩，相邻两个数之间用一个空格分隔，成绩范围为 $0$ 到 $100$ 。

## 输出描述

输出一个整数，表示所有学生成绩中的最高分。

## 示例

### 用例输入 1

```text
5
85 78 90 99 60
```

### 用例输出 1

```text
99
```

---

## 题解

### 解题思路

在一组成绩中找最大值，是经典的"打擂台"算法。设定一个初始极小值，遍历所有成绩，每次与当前最大值比较并更新。

### 算法分析

1. 读入 $n$。
2. 定义 `maxScore = -1`，循环 $n$ 次读入成绩，若大于 `maxScore` 则更新。
3. 输出 `maxScore`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxScore = -1;
    for (int i = 0; i < n; i++) {
        int score;
        cin >> score;
        if (score > maxScore) maxScore = score;
    }
    cout << maxScore << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，仅需一次遍历。
- **空间复杂度**：$O(1)$。
