# 奇数求和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

计算非负整数 $m$ 到 $n$ （包括 $m$ 和 $n$ ）之间所有奇数的和，其中 $0≤m≤n≤3000 \le m \le n \le 3000≤m≤n≤300$ 。

## 输入描述

输入一行，包含两个非负整数 $m$ 和 $n$ ，两个数之间以一个空格分隔，满足 $0≤m≤n≤3000 \le m \le n \le 3000≤m≤n≤300$ 。

## 输出描述

输出一行，包含一个整数，表示从 $m$ 到 $n$ （包括 $m$ 和 $n$ ）之间所有奇数的和。

## 示例

### 用例输入 1

```text
7 15
```

### 用例输出 1

```text
55
```

---

## 题解

### 解题思路

本题要求计算区间 $[m, n]$ 内所有奇数的和。最直接的方法是遍历该区间中的每一个整数，判断其是否为奇数，若是则累加到结果中。判断奇数的方式为 `i % 2 != 0`。

### 算法分析

1. 读入两个非负整数 $m$ 和 $n$。
2. 初始化累加变量 `sum = 0`。
3. 从 $m$ 遍历到 $n$（包含两端），对每个数 $i$：若 `i % 2 != 0`，则 `sum += i`。
4. 输出 `sum`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int m, n;           // m、n 为区间的左右端点，求 [m, n] 内所有奇数之和
    cin >> m >> n;      // 读入区间起止

    int sum = 0;        // sum 累加满足条件的奇数，初始为 0
    // 遍历区间 [m, n] 中的每一个整数；i 从 m 到 n（含两端）
    for (int i = m; i <= n; i++) {
        // 用取模判断奇偶：i % 2 != 0 表示该数为奇数
        if (i % 2 != 0) {
            sum += i;   // 是奇数则累加到 sum
        }
    }

    cout << sum << endl;    // 输出区间内所有奇数之和
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n - m)$，最多遍历 $300$ 个整数，效率很高。
- **空间复杂度**：$O(1)$，仅使用常数级别的额外空间。
