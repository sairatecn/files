# 数字统计

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个范围 $[L,R][L, R][L,R]$ 的所有整数，统计数字 ‘2’ 出现的总次数。例如，对于范围 $[2,22]$ ，数字 ‘2’ 出现了 6 次。

## 输入描述

一行包含两个正整数 $L$ 和 $R$ $(1≤L≤R≤10000)(1 \le L \le R \le 10000)(1≤L≤R≤10000)$ ，之间用一个空格隔开。

## 输出描述

输出数字 ‘2’ 在范围 $[L,R][L, R][L,R]$ 内出现的次数。

## 示例

### 用例输入 1

```text
2 22
```

### 用例输出 1

```text
6
```

---

## 题解

### 解题思路

与"数1的个数"类似，只是统计范围变为 $[L, R]$，统计目标为数字 "2"。遍历 $L$ 到 $R$ 的每个数，逐位检查是否为 2。

### 算法分析

1. 读入 $L$ 和 $R$，定义 `cnt = 0`。
2. 遍历 $i$ 从 $L$ 到 $R$：对 $i$ 逐位检查 `temp % 10 == 2`。
3. 输出 `cnt`。

### 参考代码（C++）

```cpp
// 【整体思路】区间枚举 + 数位拆分统计，与“数 1 的个数”是同一个套路。
// 区别有两点：枚举范围从 [1, n] 变成给定区间 [L, R]；统计目标从数字 1 变成数字 2。
// 对区间内的每个整数做数位拆分（反复 %10 取最低位、/10 去掉最低位），
// 每碰到一位等于 2 就计数加 1，累计出整个区间内 “2” 出现的总次数。
// R ≤ 10000，最多枚举 1 万个数、每个数至多 5 位，暴力完全够用。
#include <iostream>
using namespace std;

int main() {
    int L, R;                               // L、R：统计区间的左右端点，闭区间 [L, R]，保证 L ≤ R
    cin >> L >> R;                          // 一行读入两个整数 L 和 R（cin 会自动跳过中间的空格）
    int cnt = 0;                            // cnt：数字 2 出现的总次数（累加器），初始为 0
    for (int i = L; i <= R; i++) {          // 外层循环：i 从 L 递增到 R，逐个处理区间中的每个整数（注意是 <=，右端点也要统计）
        int temp = i;                       // temp：i 的副本，用于逐位拆解，避免直接修改循环变量 i
        while (temp > 0) {                  // 内层循环：不断剥离 temp 的最低位，直到 temp 被除成 0，即所有数位都检查完
            if (temp % 10 == 2) cnt++;      // temp % 10 取出当前最低位；若该位恰为 2，计数加 1（同一个数里可能出现多次，如 22 计 2 次）
            temp /= 10;                     // 整除 10 去掉刚检查过的最低位，进入更高一位
        }
    }
    cout << cnt << endl;                    // 输出区间 [L, R] 内数字 “2” 出现的总次数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O((R-L+1) \cdot \log_{10} R)$。
- **空间复杂度**：$O(1)$。
