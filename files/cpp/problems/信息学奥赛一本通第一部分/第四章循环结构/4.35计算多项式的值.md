# 计算多项式的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知多项式 $P(x)=xn+xn−1+⋯+x2+x+1P(x) = x^n + x^{n-1} + \dots + x^2 + x + 1P(x)=xn+xn−1+⋯+x2+x+1$ ，给定一个实数 $x$ 和整数 $n$ ，计算 $P(x)$ 的值，结果保留两位小数。

## 输入描述

输入一行，包含一个实数 $x$ 和一个正整数 $n$ （ $n≤106n \le 10^6n≤106$ ），用单个空格分隔。

## 输出描述

输出多项式 $P(x)$ 的值，保留小数点后两位。

## 示例

### 用例输入 1

```text
2.0 4
```

### 用例输出 1

```text
31.00
```

---

## 题解

### 解题思路

多项式 $P(x) = x^n + x^{n-1} + \dots + x + 1$ 可用秦九韶算法（Horner 方法）高效计算：$P(x) = (\dots((x+1)\cdot x + 1)\cdot x + 1)\dots)$。这样每次迭代只需一次乘法和一次加法，避免了重复计算幂次。

### 算法分析

1. 读入 $x$ 和 $n$。
2. 定义 `result = 1`（常数项），循环 $n$ 次：`result = result * x + 1`。
3. 输出 `result`，保留 2 位小数。

### 参考代码（C++）

```cpp
// 算法思路：计算 P(x) = x^n + x^(n-1) + ... + x^2 + x + 1。
// 若对每一项都单独求幂，复杂度是 O(n^2)（或需额外的快速幂），效率低且累积误差大。
// 这里采用秦九韶算法（Horner 方法）把多项式改写成层层嵌套的形式：
//     P(x) = ((...((1 * x + 1) * x + 1) ... ) * x + 1)
// 即从最高次项的系数 1 出发，每次“乘 x 再加下一项系数 1”，
// 由于本题所有系数都是 1，循环体固定为 result = result * x + 1。
// 迭代 n 次后，最初的那个 1 恰好被乘了 n 次 x（对应 x^n），中途加入的 1 依次对应 x^(n-1) ... x^1、x^0。
// 每轮只需一次乘法和一次加法，总复杂度 O(n)，n ≤ 1e6 也能轻松通过。
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x;                                      // x：多项式的自变量，是实数，必须用浮点类型存储
    int n;                                         // n：多项式的最高次数（n ≤ 1e6），决定循环迭代的次数
    cin >> x >> n;                                 // 一行读入 x 和 n，中间以空格分隔
    double result = 1;                             // result：秦九韶迭代的累积值，初值 1 即最高次项 x^n 的系数
    for (int i = 0; i < n; i++) {                  // 循环恰好执行 n 次（i 从 0 到 n-1）：每次“降一次幂”，把下一项的系数 1 并入
        result = result * x + 1;                   // 关键的秦九韶递推：先乘 x（使已有各项次数整体加一），再加上当前这一项的系数 1
    }                                              // 循环结束后 result 就是 x^n + x^(n-1) + ... + x + 1 的值
    cout << fixed << setprecision(2) << result << endl; // fixed 定点输出，setprecision(2) 保留两位小数，满足题目输出格式要求
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
