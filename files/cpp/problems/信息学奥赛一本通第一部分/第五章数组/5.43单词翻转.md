# 单词翻转

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个句子（不超过500个字符），将句子中的每一个单词翻转后输出，单词之间的空格需与原文一致。

## 输入描述

一行字符串，长度不超过500，单词之间以空格隔开。

## 输出描述

输出翻转每个单词后的字符串，保留原有空格。

## 示例

### 用例输入 1

```text
hello world
```

### 用例输出 1

```text
olleh dlrow
```

---

## 题解

### 解题思路

题目要求只翻转每个单词内部，而单词之间的空格数量与位置必须原样保留。逐字符扫描整行：用 cur 累积当前单词，遇到空格时先把 cur 整体 reverse 输出，再原样输出这个空格，最后清空 cur 继续。

### 算法分析

1. 用 `getline` 读入整行（可能有多个连续空格，不能只靠 cin）。
2. 遍历每个字符：若为空格，则 `reverse(cur)` 后输出并输出该空格；否则把字符追加到 cur。
3. 循环结束后若 cur 非空，说明句子末尾没有空格，需要再翻转并输出最后一个单词。
4. 由于每个空格都是遇到即输出，所以多个连续空格也会被原样保留。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    string cur;                    // 当前单词
    for (char c : s) {
        if (c == ' ') {
            reverse(cur.begin(), cur.end());  // 翻转当前单词
            cout << cur << " ";               // 输出单词和这个空格
            cur.clear();
        } else {
            cur += c;
        }
    }
    reverse(cur.begin(), cur.end());          // 翻转最后一个单词
    cout << cur << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为句子长度。
- **空间复杂度**：$O(n)$。
