# 最高分数的学生姓名

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入学生的人数 N（ $1≤N≤1001 \le N \le 1001≤N≤100$ ），然后输入每位学生的分数和姓名，输出第一个获得最高分数的学生姓名。分数是非负整数且 $≤100\le 100≤100$ ，姓名为连续字符串，长度 $≤20\le 20≤20$ 。

## 输入描述

第一行输入整数 $N$ ，接下来 $N$ 行每行格式：分数 姓名。

## 输出描述

输出第一个获得最高分的学生姓名。

## 示例

### 用例输入 1

```text
5
87 lilei
99 hanmeimei
97 lily
96 lucy
77 jim
```

### 用例输出 1

```text
hanmeimei
```

---

## 题解

### 解题思路

数据按输入顺序给出，题目要求输出第一个获得最高分的学生。只需边读边维护当前最高分及其姓名：每读入一名学生，若分数比当前最高分更大，就更新最高分和姓名。由于只在分数严格更大时才更新，并列最高分时保留的是先输入的那位，正好满足"第一个"。

### 算法分析

1. 读入学生人数 N。
2. 循环 N 次，每次读入分数 score 和姓名 name。
3. 若 `score > maxScore`，则更新 maxScore 和 maxName。初始时把 maxScore 设为 -1，保证第一位学生必然被选中（分数是非负整数）。
4. 使用严格大于而非大于等于，确保并列最高分时输出第一个。
5. 循环结束后输出 maxName。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    int maxScore = -1;            // 分数是非负整数，-1 保证第一次必然更新
    string maxName;
    for (int i = 0; i < n; i++) {
        int score;
        string name;
        cin >> score >> name;
        if (score > maxScore) {   // 严格大于：并列时保留第一个最高分
            maxScore = score;
            maxName = name;
        }
    }
    cout << maxName << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(N)$，其中 $N$ 为学生人数。
- **空间复杂度**：$O(1)$。
