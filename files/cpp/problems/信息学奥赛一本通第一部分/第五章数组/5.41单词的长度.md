# 单词的长度

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一行单词序列，相邻单词由1个或多个空格分隔。标点符号算作单词的一部分。输出每个单词的长度，长度之间用逗号分隔。

## 输入描述

一行单词序列，最少1个单词，最多300个单词，总长度 $≤1000\le 1000≤1000$ ，单词之间用至少1个空格分隔。

## 输出描述

依次输出对应单词的长度，长度之间用逗号分隔。

## 示例

### 用例输入 1

```text
She was born in 1990-01-02  and  from Beijing city.
```

### 用例输出 1

```text
3,3,4,2,10,3,4,7,5
```

---

## 题解

### 解题思路

单词之间可能隔 1 个或多个空格，因此不能简单按单个空格切分。利用 istringstream 的 `>>` 会自动跳过连续空格的特性，可以把整行字符串按空白拆分成一个个单词，再依次输出每个单词的长度。

### 算法分析

1. 用 `getline(cin, s)` 读入整行。
2. 把 s 放入 `istringstream sin(s)`，用 `sin >> word` 反复提取单词，空格会被自动跳过。
3. 用一个标记 first 控制逗号：第一个单词前不输出逗号，从第二个单词开始每个前面输出一个逗号。
4. 对每个单词输出 `word.size()`，最后换行。标点（如句点）属于单词的一部分，会自然带上，无需特殊处理。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    istringstream sin(s);
    string word;
    bool first = true;

    while (sin >> word) {
        if (!first) cout << ",";      // 除第一个单词外，前面加逗号
        cout << word.size();
        first = false;
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串总长度。
- **空间复杂度**：$O(n)$。
