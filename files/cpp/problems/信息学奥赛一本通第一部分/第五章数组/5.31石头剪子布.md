# 石头剪子布

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

根据石头剪子布游戏规则判断每一局的胜负结果：

- 石头（Rock）胜剪子（Scissors）；
- 剪子（Scissors）胜布（Paper）；
- 布（Paper）胜石头（Rock）。
若双方选择相同，则判定为平局。

## 输入描述

- 第一行是一个整数 $N$ ，表示进行游戏的次数， $1≤N≤1001 \le N \le 1001≤N≤100$ 。
- 接下来 $N$ 行，每行包含两个字符串 $S1,S2S_1, S_2S1​,S2​$ ，分别表示 Player1 和 Player2 的选择，字符串取值为 ${Rock,Scissors,Paper}\\{Rock, Scissors, Paper\\}{Rock,Scissors,Paper}$ （大小写敏感），中间以空格分隔。

## 输出描述

- 输出 $N$ 行，每行输出一局的结果：若 Player1 获胜输出 $Player1$ ，若 Player2 获胜输出 $Player2$ ，若平局输出 $Tie$ 。

## 示例

### 用例输入 1

```text
3
Rock Scissors
Paper Paper
Rock Paper
```

### 用例输出 1

```text
Player1
Tie
Player2

## 题解

### 解题思路

这是典型的条件判断问题。把三种出法的胜负关系枚举出来即可：相同则平局；石头胜剪子、剪子胜布、布胜石头。用字符串比较后按规则判断 Player1 是否获胜即可。

### 算法分析

1. 读入局数 $N$。
2. 每局用 `cin` 读入两个字符串 `s1`、`s2`（都不含空格）。
3. 若 `s1 == s2`，输出 `Tie`；否则判断 Player1 获胜的三种情况：
   - `s1 == "Rock" && s2 == "Scissors"`
   - `s1 == "Scissors" && s2 == "Paper"`
   - `s1 == "Paper" && s2 == "Rock"`
   满足任一种输出 `Player1`，否则输出 `Player2`。
4. 易错点：字符串大小写敏感，必须与题面给出的 `Rock`、`Scissors`、`Paper` 完全一致；Player2 获胜的情况直接作为"其余情况"处理即可，无需重复枚举。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    string s1, s2;
    for (int i = 0; i < n; i++) {
        cin >> s1 >> s2;
        if (s1 == s2) {
            cout << "Tie" << endl;
        } else if ((s1 == "Rock" && s2 == "Scissors") ||
                   (s1 == "Scissors" && s2 == "Paper") ||
                   (s1 == "Paper" && s2 == "Rock")) {
            cout << "Player1" << endl;
        } else {
            cout << "Player2" << endl;
        }
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(N)$，每局只做常数次比较。
- **空间复杂度**：$O(1)$，仅用少量变量。
