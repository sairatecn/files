# 基因相关性

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定两条**长度相同** 的 DNA 序列，定义相同位置上的两个碱基为一个碱基对。若该碱基对中的两个碱基相同，则称为**相同碱基对** 。计算相同碱基对数量占总碱基对数量的比例，若该比例**大于等于给定阈值** ，则判定两条 DNA 序列是相关的，否则不相关。

## 输入描述

- 第一行是一个浮点数，表示判定相关性的阈值；
- 接下来两行是两条 DNA 序列，仅由字符 ${A,T,C,G}\\{A, T, C, G\\}{A,T,C,G}$ 组成，且长度不超过 $500$ 。

## 输出描述

- 若两条 DNA 序列相关，输出 $yes$ ；否则输出 $no$ 。

## 示例

### 用例输入 1

```text
0.85
ATCGCCGTAAGTAACGGTTTTAAATAGGCC
ATCGCCGGAAGTAACGGTCTTAAATAGGCC
```

### 用例输出 1

```text
yes
```

---

## 题解

### 解题思路

两条 DNA 序列长度相同，只需逐位比较：统计相同位置上碱基相等的个数，再用它除以总长度得到相同比例，最后与给定阈值比较。比较过程可以用一个简单的循环完成，属于"字符串逐位判断"的经典入门题。

### 算法分析

1. 读入阈值浮点数 `x`，再读入两条长度相同的 DNA 序列 `s1`、`s2`。
2. 用循环逐位比较：若 `s1[i] == s2[i]`，相同计数 `same++`。
3. 相同比例 `ratio = 1.0 * same / len`，注意把 `same` 转成浮点数再除，避免整数除法丢失小数。
4. 若 `ratio >= x` 输出 `yes`，否则输出 `no`。本题判断是"大于等于"，边界相等时也算相关。
5. 易错点：读取阈值时必须用浮点类型（如 `double`）；序列总长度用 `s1.length()` 取得即可，题目保证两串长度相等。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double x;
    cin >> x;
    string s1, s2;
    cin >> s1 >> s2;

    int len = s1.length();
    int same = 0;
    for (int i = 0; i < len; i++) {
        if (s1[i] == s2[i]) same++;   // 相同位置碱基一致
    }
    double ratio = 1.0 * same / len;  // 转成浮点数再相除
    if (ratio >= x) {
        cout << "yes" << endl;
    } else {
        cout << "no" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（一次线性比较，$n$ 为序列长度）
- **空间复杂度**：$O(1)$（仅存两条字符串，未用额外大数组）
