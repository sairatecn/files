# 整理药名

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

将医生手写的药品名整理成规范格式：

- 如果单词首字符是字母，则大写。
- 其余字母小写。
- 数字和 ‘-’ 保持原样。

## 输入描述

第一行一个整数 $n$ ，表示有 $n$ 个药品名 ( $n≤100n \le 100n≤100$ )。
接下来 $n$ 行，每行一个单词（长度 $≤20\le 20≤20$ ），由字母、数字和 ‘-’ 组成。

## 输出描述

输出 $n$ 行，每行对应输入的药品名的规范写法。

## 示例

### 用例输入 1

```text
4
AspiRin
cisapride
2-PENICILLIN
Cefradine-6
```

### 用例输出 1

```text
Aspirin
Cisapride
2-penicillin
Cefradine-6

---

## 题解

### 解题思路

对每个单词独立处理：首字符若是字母则转为大写，其余位置若为字母则全部转为小写；数字和 `-` 原样保留。逐个单词读入、处理、输出即可。

### 算法分析

1. 读入 $n$，对每个单词用 `cin >> s` 读入（单词不含空格）。
2. 处理首字符：若为小写字母则转大写（`s[0] - 32`），若本身是大写字母、数字或 `-` 则不动。
3. 处理其余字符：若为大写字母则转小写（`s[i] + 32`），小写字母、数字和 `-` 不动。
4. 直接修改 `s` 后输出。
5. 易错点：当首字符是数字或 `-`（例如 `2-PENICILLIN`）时，首字符不能被改成字母，只需把后面的大写字母变小写；`-32`（转大写）和 `+32`（转小写）不要搞混。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    string s;
    for (int k = 0; k < n; k++) {
        cin >> s;
        int len = s.size();

        // 首字符：若是小写字母则转大写
        if (s[0] >= 'a' && s[0] <= 'z')
            s[0] = s[0] - 32;

        // 其余字符：大写字母全部转小写
        for (int i = 1; i < len; i++) {
            if (s[i] >= 'A' && s[i] <= 'Z')
                s[i] = s[i] + 32;
        }

        cout << s << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\sum |s|)$，每个字符仅处理一次。
- **空间复杂度**：$O(|s|)$，只需一个单词长度的存储。
