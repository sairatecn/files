# 不与最大数相同的数字之和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数序列，求除去序列中最大数之外其余数字的和。

## 输入描述

- 第一行输入一个整数 $N$ ，表示序列中元素个数（ $1≤N≤1001\le N\le1001≤N≤100$ ）。
- 第二行输入 $N$ 个整数，数值范围在 $−1000000-1000000−1000000$ 到 $1000000$ ，以空格分隔。

## 输出描述

输出一个整数，表示除去最大数之外其余数字之和。

## 示例

### 用例输入 1

```text
3
1 2 3
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

先扫描一遍整个序列找出最大值，再扫描一遍把所有**不等于**最大值的数累加。注意最大值可能出现多次，所有等于最大值的数都应被排除。

### 算法分析

1. 读入 $N$ 个数存入数组，同时记录最大值 `mx`。
2. 再次遍历数组，若 `a[i] != mx` 则累加到 `sum`。
3. 输出总和。

易错点：最大值有多个时，全部不能计入；数据可能为负数，建议用 `long long` 保存累加结果。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, a[105];
    cin >> n;

    int mx = -1000001;  // 根据数据范围初始化
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] > mx) mx = a[i];  // 记录最大值
    }

    long long sum = 0;  // 总和，用 long long 防止溢出
    for (int i = 1; i <= n; i++) {
        if (a[i] != mx) sum += a[i];  // 跳过所有最大值
    }
    cout << sum << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(N)$，需要两次线性扫描。
- **空间复杂度**：$O(N)$，用一个数组存储序列。
