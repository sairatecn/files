# 加密的病历单

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个加密字符串，解密方法如下：

- 字母表循环左移 3 位（例如 dec -> abz）
- 字符串逆序存储（abcd -> dcba）
- 大小写反转（abXY -> ABxy）
输入字符串仅包含大小写字母，长度 $<50< 50<50$ 。

## 输入描述

一行加密字符串，长度 $<50< 50<50$ ，只包含大小写字母。

## 输出描述

输出解密后的字符串。

## 示例

### 用例输入 1

```text
GSOOWFASOq
```

### 用例输出 1

```text
Trvdizrrvj
```

---

## 题解

### 解题思路

加密依次做了三步：字母循环左移 3 位、逆序、大小写反转。解密要按相反顺序做回去：先大小写反转，再逆序，最后字母循环**右移** 3 位（即加密时左移 3 位的逆操作）。

### 算法分析

1. 用 `cin` 读入密文字符串 `s`（只含字母，不含空格）。
2. 第一步：大小写反转——大写变小写、小写变大写。
3. 第二步：逆序——用 `reverse(s.begin(), s.end())` 或双指针交换。
4. 第三步：循环右移 3 位——对每个字母加 3，超过 `z` 或 `Z` 时环绕回 `a` 或 `A`。用模运算 `'a' + (c - 'a' + 3) % 26` 最稳妥。
5. 易错点：三步顺序不能颠倒；环绕时大小写要分开计算，例如 `c + 3 = 'f'` 正常，而 `x + 3 = '{'` 需要环绕成 `a`。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    // 1. 大小写反转
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] >= 'a' && s[i] <= 'z')
            s[i] = s[i] - 'a' + 'A';
        else
            s[i] = s[i] - 'A' + 'a';
    }

    // 2. 字符串逆序
    reverse(s.begin(), s.end());

    // 3. 每个字母循环右移 3 位
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] >= 'a' && s[i] <= 'z')
            s[i] = 'a' + (s[i] - 'a' + 3) % 26;
        else
            s[i] = 'A' + (s[i] - 'A' + 3) % 26;
    }

    cout << s << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为字符串长度，共三次线性扫描。
- **空间复杂度**：$O(n)$，存储字符串。
