# 矩阵转置

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个 $n×mn \times mn×m$ 的矩阵 $A$ ，输出其转置矩阵 $ATA^TAT$ 。转置后矩阵的第 $i$ 行第 $j$ 列元素等于原矩阵的第 $j$ 行第 $i$ 列元素。

## 输入描述

- 第一行包含两个整数 $n,mn, mn,m$ ，表示矩阵 $A$ 的行数和列数， $1≤n,m≤1001 \le n,m \le 1001≤n,m≤100$ 。
- 接下来 $n$ 行，每行 $m$ 个整数，表示矩阵 $A$ 的元素。

## 输出描述

输出 $m$ 行，每行 $n$ 个整数，表示矩阵 $A$ 的转置矩阵 $ATA^TAT$ 。

## 示例

### 用例输入 1

```text
3 3
1 2 3
4 5 6
7 8 9
```

### 用例输出 1

```text
1 4 7
2 5 8
3 6 9
```

---

## 题解

### 解题思路

转置的本质是行列互换：原矩阵第 $i$ 行第 $j$ 列的元素，在转置矩阵中位于第 $j$ 行第 $i$ 列。先把原矩阵完整读入二维数组，再按"先列后行"的顺序输出，就自然得到了转置结果。

### 算法分析

1. 读入 $n, m$ 以及 $n$ 行、每行 $m$ 个元素，存入二维数组 `a[n][m]`。
2. 输出时外层循环用列下标 $j$（从 0 到 $m-1$），内层循环用行下标 $i$（从 0 到 $n-1$），输出 `a[i][j]`，每行之间用空格隔开，每输出完一列换行。
3. 注意结果矩阵是 $m$ 行 $n$ 列：外层列数、内层行数不要写反，否则输出的形状与题目要求不符。
4. 每个元素后面跟空格或末尾换行都可接受，本题对末尾空格没有要求。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int a[105][105];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    // 转置：外层按列 j 输出，内层按行 i 输出
    for (int j = 0; j < m; j++) {
        for (int i = 0; i < n; i++) {
            cout << a[i][j] << " ";
        }
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \times m)$（每个元素读写一次）
- **空间复杂度**：$O(n \times m)$（存储整个矩阵）
