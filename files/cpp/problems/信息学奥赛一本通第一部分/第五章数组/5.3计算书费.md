# 计算书费

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知 $10$ 种图书的单价，分别为：

- 《计算概论》 $28.9$ 元/本
- 《数据结构与算法》 $32.7$ 元/本
- 《数字逻辑》 $45.6$ 元/本
- 《C++程序设计教程》 $78$ 元/本
- 《人工智能》 $35$ 元/本
- 《计算机体系结构》 $86.2$ 元/本
- 《编译原理》 $27.8$ 元/本
- 《操作系统》 $43$ 元/本
- 《计算机网络》 $56$ 元/本
- 《JAVA程序设计》 $65$ 元/本
给定每种图书购买的数量，计算应付的总费用。

## 输入描述

一行输入 $10$ 个整数，分别表示上述 $10$ 种图书的购买数量（ $0≤ni≤1000 \le n_i \le 1000≤ni​≤100$ ），相邻整数之间用一个空格分隔。

## 输出描述

输出一个浮点数，表示应付的总费用，结果保留到小数点后一位。

## 示例

### 用例输入 1

```text
1 5 8 10 5 1 1 2 3 4
```

### 用例输出 1

```text
2140.2
```

---

## 题解

### 解题思路

把 $10$ 种书的单价按题面顺序存入数组，再读入对应的购买数量，用循环累加 `单价 × 数量` 得到总费用。由于单价有小数，用 `double` 保存，最后保留一位小数输出。

### 算法分析

1. 定义单价数组 `price[10]`，顺序与题面完全一致。
2. 循环 $10$ 次：每次读入一种书的购买数量，累加 `sum += price[i] * cnt`。
3. 用 `fixed << setprecision(1)` 使输出保留一位小数。

易错点：单价数组的下标要与输入数量一一对应；输出要保留一位小数。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 10 种图书的单价（按题面顺序）
    double price[10] = {28.9, 32.7, 45.6, 78, 35, 86.2, 27.8, 43, 56, 65};
    double sum = 0;

    for (int i = 0; i < 10; i++) {
        int cnt;
        cin >> cnt;                 // 读入该种书的购买数量
        sum += price[i] * cnt;      // 累加这一种书的花费
    }

    cout << fixed << setprecision(1) << sum << endl;  // 保留一位小数输出
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，图书种类固定为 $10$。
- **空间复杂度**：$O(1)$，只用一个长度固定的单价数组。
