# 字符串p型编码

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个仅由数字字符 ‘0’-‘9’ 构成的字符串 $str$ ，输出其 p 型编码串。p 型编码按连续相同数字的数量和数字顺序编码，例如 ‘122344111’ -> ‘1122132431’。

## 输入描述

一行字符串 $str$ ，长度 $≤1000\le 1000≤1000$ ，仅包含数字字符 ‘0’-‘9’。

## 输出描述

输出对应的 p 型编码串。

## 示例

### 用例输入 1

```text
122344111
```

### 用例输出 1

```text
1122132431
```

---

## 题解

### 解题思路

p 型编码就是经典的"游程编码"（Run-Length Encoding）：从前往后扫描，把连续相同的数字记为一组，输出"该组数字的个数 + 该数字本身"。例如 `122344111` 被分成 `1`、`22`、`3`、`44`、`111` 五组，编码为 `11 22 13 24 31`。

### 算法分析

1. 读入字符串 s。
2. 用下标 i 指向当前组的起点，用 j 从 i 开始向后移动，统计与 `s[i]` 相同的连续字符个数。
3. 循环结束后 `j - i` 就是连续个数，输出 `j - i` 和字符 `s[i]`（先数量后字符）。
4. 令 `i = j` 跳到下一组，重复直到字符串末尾。
5. 由于每次 i 都会前进至少 1 位，循环必然终止，无需担心死循环或越界。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.size();
    for (int i = 0; i < n; ) {
        int j = i;
        while (j < n && s[j] == s[i]) j++;   // 统计连续相同字符个数
        cout << j - i << s[i];               // 输出 数量 + 字符
        i = j;                               // 跳到下一组
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串长度。
- **空间复杂度**：$O(1)$。
