# 白细胞计数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定 n 份白细胞样本，去掉最大值和最小值后计算剩余样本的平均值及最大误差。

## 输入描述

- 第一行输入正整数 $n$ ，表示样本数（ $2<n≤3002<n\le3002<n≤300$ ）。
- 接下来 $n$ 行，每行一个浮点数，表示白细胞数量（单位 $109/L10^9/L109/L$ ）。

## 输出描述

输出两个浮点数，分别为剩余样本的平均值和最大误差，保留两位小数，中间用空格分隔。

## 示例

### 用例输入 1

```text
5
12.0
13.0
11.0
9.0
10.0
```

### 用例输出 1

```text
11.00 1.00
```

---

## 题解

### 解题思路

先找出 $n$ 份样本中的最大值和最小值所在的下标，把它们"去掉"后求剩余样本的平均值，再求剩余每个样本与该平均值差值的绝对值的最大值（即最大误差）。

### 算法分析

1. 读入 $n$ 和 $n$ 个浮点数，同时记录最大值下标 `imax`、最小值下标 `imin`。
2. 把除 `imax`、`imin` 之外的样本求和，除以 $n-2$ 得到平均值 `avg`。
3. 遍历剩余样本，用 `fabs(a[i] - avg)` 求与平均值的绝对差，取最大值。
4. 保留两位小数输出平均值和最大误差。

易错点：要用 `fabs` 求浮点数的绝对值；"去掉最大值和最小值"指的是去掉各自的一个（按下标跳过），而不是把所有等于最大/最小值的都去掉。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    double a[305];
    cin >> n;

    int imax = 1, imin = 1;  // 最大值、最小值所在下标
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] > a[imax]) imax = i;
        if (a[i] < a[imin]) imin = i;
    }

    double sum = 0;
    for (int i = 1; i <= n; i++) {
        if (i != imax && i != imin) sum += a[i];  // 去掉最大和最小各一个
    }
    double avg = sum / (n - 2);  // 剩余样本的平均值

    double maxErr = 0;
    for (int i = 1; i <= n; i++) {
        if (i != imax && i != imin) {
            double diff = fabs(a[i] - avg);  // 与平均值的绝对差
            if (diff > maxErr) maxErr = diff;
        }
    }

    cout << fixed << setprecision(2) << avg << " " << maxErr << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，只需常数次线性扫描。
- **空间复杂度**：$O(n)$，用一个数组存储样本。
