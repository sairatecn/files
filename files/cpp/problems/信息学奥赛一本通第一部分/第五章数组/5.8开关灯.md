# 开关灯

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

有 $N$ 盏灯，编号为 $1$ 到 $N$ ，初始时全部处于开启状态。有 $M$ 个人依次进行操作：

- 第 $1$ 个人将所有灯关闭；
- 第 $2$ 个人将编号为 $2$ 的倍数的灯打开；
- 从第 $3$ 个人开始，每个人将编号为其编号倍数的灯做相反处理（开变关，关变开）。

在第 $M$ 个人操作结束后，统计哪些灯是关闭状态。

## 输入描述

输入两个正整数 $N$ 和 $M$ ，以一个空格隔开（ $1≤N≤5000,1≤M≤N1\le N\le5000,\ 1\le M\le N1≤N≤5000,1≤M≤N$ ）。

## 输出描述

按从小到大的顺序输出所有处于关闭状态的灯的编号，编号之间用英文逗号 , 分隔。

## 示例

### 用例输入 1

```text
10 10
```

### 用例输出 1

```text
1,4,9
```

---

## 题解

### 解题思路

用数组模拟每盏灯的状态（$1$ 表示开，$0$ 表示关）。第 $1$ 个人把所有灯关闭，第 $2$ 个人把编号为 $2$ 的倍数的灯打开，从第 $3$ 个人开始每个人对编号为其编号倍数的灯做取反操作。全部模拟完后按编号从小到大输出关着的灯。

### 算法分析

1. 初始化 $N$ 盏灯全部为开（值为 $1$）。
2. 对第 $p=1,2,\dots,M$ 个人：
   - 遍历其编号的倍数 $i = p, 2p, 3p, \dots$；
   - $p=1$ 时置为关，$p=2$ 时置为开，$p \ge 3$ 时执行取反 `a[i] = 1 - a[i]`。
3. 按编号从小到大输出状态为关的灯的编号，用英文逗号分隔。

易错点：输出格式是英文逗号分隔且不加空格；注意 $M$ 可能等于 $1$（只有第 $1$ 个人操作，所有灯全关）。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m, a[5005];
    cin >> n >> m;

    for (int i = 1; i <= n; i++) a[i] = 1;  // 初始全部开启

    for (int p = 1; p <= m; p++) {
        for (int i = p; i <= n; i += p) {   // 编号为 p 的倍数的灯
            if (p == 1) a[i] = 0;           // 第 1 个人：全部关闭
            else if (p == 2) a[i] = 1;      // 第 2 个人：打开 2 的倍数
            else a[i] = 1 - a[i];           // 其他人：取反操作
        }
    }

    bool first = true;
    for (int i = 1; i <= n; i++) {
        if (a[i] == 0) {                    // 灯处于关闭状态
            if (!first) cout << ",";        // 编号之间用逗号分隔
            cout << i;
            first = false;
        }
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(NM)$，每个人都要遍历一遍自己编号的倍数。
- **空间复杂度**：$O(N)$，用一个长度为 $N$ 的数组记录灯的状态。
