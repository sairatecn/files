# 整数去重

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个含有 $n$ 个整数的序列，对序列进行去重操作，只保留每个数字第一次出现的位置。

## 输入描述

第一行输入正整数 $n$ ，第二行输入 $n$ 个整数，空格分隔。

## 输出描述

输出去重后的整数序列，按照原顺序，整数间用空格分隔。

## 示例

### 用例输入 1

```text
5
10 12 93 12 75
```

### 用例输出 1

```text
10 12 93 75
```

---

## 题解

### 解题思路

题目要求只保留每个数字第一次出现的位置，即遍历原序列时，对没见过的数字输出，对已出现过的数字跳过。可以用一个集合（`set`）记录"已经出现过哪些数字"，遍历时查询即可判断。

### 算法分析

1. 读入 $n$，定义一个 `set<int>`（或范围允许时用 `bool` 标记数组）记录已经出现过的数字。
2. 依次读入每个数 $x$：若集合中不存在 $x$，则输出 $x$ 并把它插入集合；若已存在则跳过。
3. 易错点：输出格式要求整数间用空格分隔，第一个数字前不能有空格，行末不要有多余空格，可用一个 `first` 标记控制。
4. 边界情况：所有数字都相同，则只输出一个数；$n=1$ 时只输出一个数。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<int> seen;      // 记录已经出现过的数字
    bool first = true;  // 标记当前是否是第一个输出的数字

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (seen.count(x)) continue; // 已经出现过，跳过
        seen.insert(x);              // 标记为已出现
        if (!first) cout << " ";     // 数字之间用空格分隔
        cout << x;
        first = false;
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \log n)$（`set` 的插入与查询为 $O(\log n)$）
- **空间复杂度**：$O(n)$（集合最多存 $n$ 个互不相同的数字）
