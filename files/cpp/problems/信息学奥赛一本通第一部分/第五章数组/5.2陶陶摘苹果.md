# 陶陶摘苹果

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

院子里有一棵苹果树，上面结有 $10$ 个苹果。已知每个苹果到地面的高度，以及陶陶把手伸直时能够达到的最大高度。陶陶有一个 $30cm30\text{cm}30cm$ 高的板凳，当她直接够不到苹果时可以站在板凳上。若陶陶的手（考虑是否站在板凳上）能够碰到苹果，则认为该苹果可以被摘到。请计算陶陶能够摘到的苹果数量。

## 输入描述

- 第一行输入 $10$ 个整数，表示 $10$ 个苹果到地面的高度（单位： $cm\text{cm}cm$ ， $100≤hi≤200100 \le h_i \le 200100≤hi​≤200$ ）。
- 第二行输入一个整数 $h$ ，表示陶陶把手伸直时能够达到的最大高度（单位： $cm\text{cm}cm$ ， $100≤h≤120100 \le h \le 120100≤h≤120$ ）。

## 输出描述

输出一个整数，表示陶陶能够摘到的苹果的数目。

## 示例

### 用例输入 1

```text
100 200 150 140 129 134 167 198 200 111
110
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

把 $10$ 个苹果的高度存入数组。陶陶可以站在 $30\text{cm}$ 高的板凳上，所以能摘到苹果的条件是：苹果高度 $\le$ 手伸直高度 $+30$。遍历数组逐个判断并计数即可。

### 算法分析

1. 读入 $10$ 个苹果高度存入数组 $a$。
2. 读入陶陶手伸直时的最大高度 $h$。
3. 遍历数组，若 $a[i] \le h+30$，则能摘到，计数加 $1$。
4. 输出计数结果。

易错点：别忘了把板凳高度 $30$ 加上；高度是整数，用 `int` 即可。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[15], h;
    int cnt = 0;  // 能摘到的苹果个数

    for (int i = 1; i <= 10; i++) cin >> a[i];  // 读入 10 个苹果高度
    cin >> h;                                   // 读入手伸直时的高度

    for (int i = 1; i <= 10; i++) {
        if (a[i] <= h + 30) cnt++;  // 可以站上 30cm 的板凳
    }
    cout << cnt << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，苹果数量固定为 $10$。
- **空间复杂度**：$O(1)$，只用一个长度为 $10$ 的数组。
