# 与指定数字相同的数的个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个长度为 $n$ 的整数序列，以及一个指定整数 $m$ ，统计序列中与 $m$ 相同的整数个数。

## 输入描述

- 第一行输入一个整数 $n$ ，表示序列长度（ $n≤100n \le 100n≤100$ ）。
- 第二行输入 $n$ 个整数，整数之间以空格分隔。
- 第三行输入一个整数 $m$ ，表示指定的数字。

## 输出描述

输出一个整数，表示序列中与 $m$ 相同的数的个数。

## 示例

### 用例输入 1

```text
3
2 3 2
2
```

### 用例输出 1

```text
2
```

---

## 题解

### 解题思路

把 $n$ 个整数存入数组，再依次与指定数字 $m$ 比较，用计数器统计相等的个数。这是最基础的"数组 + 顺序扫描"问题。

### 算法分析

1. 读入 $n$，用循环把 $n$ 个数读入数组 $a[1]\sim a[n]$。
2. 读入目标数字 $m$。
3. 从前往后遍历数组，若 $a[i]==m$ 则计数器加 $1$。
4. 输出计数器的值。

易错点：注意输入顺序是先读 $n$ 个数，再读 $m$，不要读反。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m, a[105];
    int cnt = 0;  // 统计与 m 相同的个数

    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];  // 读入整个序列
    cin >> m;                                  // 读入指定的数字

    for (int i = 1; i <= n; i++) {
        if (a[i] == m) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，只需一次线性扫描。
- **空间复杂度**：$O(n)$，用一个数组存储 $n$ 个元素。
