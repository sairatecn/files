# 验证子串

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入两个字符串 $s1s_1s1​$ 和 $s2s_2s2​$ ，验证其中一个是否为另一个的子串：

- 若 $s1s_1s1​$ 是 $s2s_2s2​$ 的子串，输出 (s1) is substring of (s2)
- 若 $s2s_2s2​$ 是 $s1s_1s1​$ 的子串，输出 (s2) is substring of (s1)
- 否则输出 No substring.

## 输入描述

两行，每行一个字符串，长度 $≤200\le 200≤200$ ，不含空格。

## 输出描述

根据子串关系输出对应的提示信息。

## 示例

### 用例输入 1

```text
abc
dddncabca
```

### 用例输出 1

```text
abc is substring of dddncabca
```

---

## 题解

### 解题思路

判断一个字符串是否为另一个字符串的子串，最直接的办法是用 string 自带的 find() 函数：在长串中查找短串，返回值等于 string::npos 说明没找到。按题目要求先判断 s1 是否为 s2 的子串，再判断 s2 是否为 s1 的子串，都不满足则输出 "No substring."。

### 算法分析

1. 用 cin 读入两个不含空格的字符串 s1、s2。
2. 调用 `s2.find(s1)`，若返回值不等于 `string::npos`，说明 s1 是 s2 的子串，输出 `s1 is substring of s2`。
3. 否则调用 `s1.find(s2)`，若找到则输出 `s2 is substring of s1`。
4. 两种情况都不成立时输出 `No substring.`（注意大小写和句点）。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    // 判断 s1 是否为 s2 的子串
    if (s2.find(s1) != string::npos) {
        cout << s1 << " is substring of " << s2 << endl;
    }
    // 判断 s2 是否为 s1 的子串
    else if (s1.find(s2) != string::npos) {
        cout << s2 << " is substring of " << s1 << endl;
    } else {
        cout << "No substring." << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \times m)$，其中 $n$、$m$ 为两个字符串的长度（find 最坏情形）。
- **空间复杂度**：$O(1)$。
