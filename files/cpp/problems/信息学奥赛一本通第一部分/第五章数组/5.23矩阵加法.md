# 矩阵加法

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定两个 $n×mn \times mn×m$ 的整数矩阵 $A$ 和 $B$ ，请计算并输出它们的和矩阵 $A+B$ ，其中对应位置的元素相加。

## 输入描述

- 第一行输入两个整数 $n,mn, mn,m$ ，表示矩阵的行数和列数（ $1≤n,m≤1001 \le n,m \le 1001≤n,m≤100$ ）。
- 接下来 $n$ 行，每行 $m$ 个整数，表示矩阵 $A$ 。
- 再接下来 $n$ 行，每行 $m$ 个整数，表示矩阵 $B$ 。
- 相邻两个整数之间用单个空格分隔，每个元素的取值范围为 $[1,1000]$ 。

## 输出描述

- 输出 $n$ 行，每行 $m$ 个整数，表示矩阵 $A+B$ 。
- 相邻两个整数之间用单个空格分隔。

## 示例

### 用例输入 1

```text
3 3
1 2 3
1 2 3
1 2 3
1 2 3
4 5 6
7 8 9
```

### 用例输出 1

```text
2 4 6
5 7 9
8 10 12
```

---

## 题解

### 解题思路

矩阵加法就是把两个矩阵对应位置的元素相加。分别读入矩阵 $A$ 和矩阵 $B$，再按同样位置输出 `a[i][j] + b[i][j]` 即可，不需要复杂的建模。

### 算法分析

1. 读入 $n,m$，表示矩阵有 $n$ 行 $m$ 列。
2. 读入矩阵 $A$ 存入数组 `a`，再读入矩阵 $B$ 存入数组 `b`，下标从 1 开始。
3. 双重循环逐格计算并输出 `a[i][j] + b[i][j]`，每行元素之间用一个空格分隔，行末换行。
4. 易错点：注意行、列顺序是"先 $n$ 后 $m$"；元素取值范围为 $[1,1000]$，两数相加最大不超过 2000，用 `int` 足够。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[105][105], b[105][105];

int main() {
    int n, m;
    cin >> n >> m;

    // 读入矩阵 A
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];

    // 读入矩阵 B
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> b[i][j];

    // 对应位置元素相加并输出
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cout << a[i][j] + b[i][j];
            if (j < m) cout << " "; // 行内元素用空格分隔
        }
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \times m)$
- **空间复杂度**：$O(n \times m)$（存储两个矩阵）
