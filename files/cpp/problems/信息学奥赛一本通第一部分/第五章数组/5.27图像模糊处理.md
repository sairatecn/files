# 图像模糊处理

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个 $n×mn \times mn×m$ 的图像灰度矩阵，对其进行模糊化处理，规则如下：

- 图像四周最外侧的像素点灰度值保持不变；
- 对于内部像素点，其新灰度值等于该像素点及其**上、下、左、右** 四个相邻像素点原灰度值的平均值，并**舍入到最接近的整数** 。

## 输入描述

- 第一行包含两个整数 $n,m$ ，表示图像的行数和列数， $1≤n,m≤1001 \le n,m \le 1001≤n,m≤100$ 。
- 接下来 $n$ 行，每行 $m$ 个整数，表示图像各像素点的灰度值，范围为 $0∼2550 \sim 2550∼255$ 。

## 输出描述

- 输出 $n$ 行，每行 $m$ 个整数，表示模糊处理后的图像灰度矩阵，相邻整数以空格分隔。

## 示例

### 用例输入 1

```text
4 5
100 0 100 0 50
50 100 200 0 0
50 50 100 100 200
100 100 50 50 100
```

### 用例输出 1

```text
100 0 100 0 50
50 80 100 60 0
50 80 100 90 200
100 100 50 50 100
```
