# 计算鞍点

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个 $5×55 \times 55×5$ 的整数矩阵。已知矩阵中**每一行只有一个最大值，每一列只有一个最小值** 。鞍点指矩阵中的某个元素，它既是所在行的最大值，又是所在列的最小值。请找出该矩阵的鞍点。

## 输入描述

- 输入包含 $5$ 行，每行 $5$ 个整数，表示一个 $5×55 \times 55×5$ 的矩阵。

## 输出描述

- 如果存在鞍点，输出三个整数：鞍点所在的行号、列号及其值（行列编号从 $1$ 开始）。
- 如果不存在鞍点，输出字符串 not found。

## 示例

### 用例输入 1

```text
11 3 5 6 9
12 4 7 8 10
10 5 6 9 11
8 6 4 7 2
15 10 11 20 25
```

### 用例输出 1

```text
4 1 8
```

---

## 题解

### 解题思路

鞍点是一个"既是所在行的最大值，又是所在列的最小值"的元素。可以先预处理出每一行的最大值 `rowMax[i]` 和每一列的最小值 `colMin[j]`，再遍历矩阵，检查哪个元素同时满足这两个条件。

### 算法分析

1. 读入 $5 \times 5$ 矩阵，行号、列号从 1 开始。
2. 预处理：`rowMax[i]` 初始化为极小值，逐行比较求出每行最大值；`colMin[j]` 初始化为极大值，逐列比较求出每列最小值。
3. 遍历所有元素，若 `a[i][j] == rowMax[i]` 且 `a[i][j] == colMin[j]`，则该位置是鞍点，输出行号、列号、值后结束。
4. 若全部遍历完都没有找到，输出 `not found`。
5. 易错点：题面保证每行最大值、每列最小值唯一，所以找到的第一个满足条件的就是答案；注意输出顺序是"行号 列号 值"。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[6][6];
int rowMax[6], colMin[6];

int main() {
    // 读入矩阵
    for (int i = 1; i <= 5; i++)
        for (int j = 1; j <= 5; j++)
            cin >> a[i][j];

    // 初始化：行最大值用极小值，列最小值用极大值
    for (int i = 1; i <= 5; i++) rowMax[i] = -2000000000;
    for (int j = 1; j <= 5; j++) colMin[j] = 2000000000;

    // 求每一行的最大值
    for (int i = 1; i <= 5; i++)
        for (int j = 1; j <= 5; j++)
            rowMax[i] = max(rowMax[i], a[i][j]);

    // 求每一列的最小值
    for (int j = 1; j <= 5; j++)
        for (int i = 1; i <= 5; i++)
            colMin[j] = min(colMin[j], a[i][j]);

    // 寻找鞍点：既是行最大值又是列最小值
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            if (a[i][j] == rowMax[i] && a[i][j] == colMin[j]) {
                cout << i << " " << j << " " << a[i][j] << endl;
                return 0;
            }
        }
    }

    cout << "not found" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$（矩阵规模固定为 $5 \times 5$）
- **空间复杂度**：$O(1)$（固定大小的数组）
