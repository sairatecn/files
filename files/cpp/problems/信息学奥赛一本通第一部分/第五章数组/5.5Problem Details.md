# Problem Details

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

某医院需要统计某项疾病在不同年龄段的分布情况。给定 $n$ 位已患病病人的患病年龄，按照以下四个年龄段进行统计：

- $0∼180\sim180∼18$
- $19∼3519\sim3519∼35$
- $36∼6036\sim6036∼60$
- $61$ 以上（含 $61$ ）

分别计算各年龄段患病人数占总患病人数的比例。

## 输入描述

- 第一行输入一个整数 $n$ ，表示过往病人的数量（ $0<n≤1000<n\le1000<n≤100$ ）。
- 第二行输入 $n$ 个整数，表示每个病人患病时的年龄，整数之间用空格分隔。

## 输出描述

按照 $0∼180\sim180∼18$ 、 $19∼3519\sim3519∼35$ 、 $36∼6036\sim6036∼60$ 、 $61$ 以上四个年龄段顺序输出结果。每行输出一个百分比，精确到小数点后两位，并以 % 结尾。

## 示例

### 用例输入 1

```text
10
1 11 21 31 41 51 61 71 81 91
```

### 用例输出 1

```text
20.00%
20.00%
20.00%
40.00%
```

## 题解

### 解题思路

本题为"年龄与疾病"统计问题。读入 $n$ 个年龄，按四个年龄段用四个计数器统计人数，最后用各段人数除以总人数 $n$ 得到比例并转成百分比输出。

### 算法分析

1. 读入总人数 $n$。
2. 依次读入每个年龄，按区间判断归属：
   - $0\sim18$ 计入 `c1`；$19\sim35$ 计入 `c2`；$36\sim60$ 计入 `c3`；$61$ 及以上计入 `c4`。
3. 计算各段百分比：`100.0 * c[i] / n`。
4. 每行输出一个百分比，保留两位小数，末尾带 `%`。

易错点：年龄段边界不能写错（$18$、$35$、$60$ 属于前一段）；百分比的除法要先乘以 $100.0$，避免整数除法丢失小数。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, age;
    int c1 = 0, c2 = 0, c3 = 0, c4 = 0;  // 四个年龄段的人数

    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> age;
        if (age <= 18) c1++;       // 0~18
        else if (age <= 35) c2++;  // 19~35
        else if (age <= 60) c3++;  // 36~60
        else c4++;                 // 61 及以上
    }

    cout << fixed << setprecision(2);  // 保留两位小数
    cout << 100.0 * c1 / n << "%" << endl;
    cout << 100.0 * c2 / n << "%" << endl;
    cout << 100.0 * c3 / n << "%" << endl;
    cout << 100.0 * c4 / n << "%" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，只需一次线性扫描。
- **空间复杂度**：$O(1)$，只用几个计数器。
