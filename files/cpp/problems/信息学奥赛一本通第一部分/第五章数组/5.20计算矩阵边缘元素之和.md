# 计算矩阵边缘元素之和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数矩阵，计算位于矩阵边缘的元素之和。所谓矩阵边缘元素，是指**第一行、最后一行、第一列以及最后一列** 中的所有元素。

## 输入描述

- 第一行输入两个整数 $m,nm, nm,n$ ，分别表示矩阵的行数和列数，二者以一个空格分隔，其中 $m<100,n<100m < 100, n < 100m<100,n<100$ 。
- 接下来输入 $m$ 行数据，每行包含 $n$ 个整数，整数之间以一个空格分隔。

## 输出描述

- 输出一个整数，表示该矩阵所有边缘元素的和。

## 示例

### 用例输入 1

```text
3 3
3 4 1
3 7 1
2 0 1
```

### 用例输出 1

```text
15
```

---

## 题解

### 解题思路

边缘元素就是第一行、最后一行、第一列和最后一列上的所有元素。可以遍历矩阵的每一个格子，只要它位于第一行、最后一行、第一列或最后一列，就累加到答案中。这样每个边缘格子恰好被加一次，四个角落不会重复计算。

### 算法分析

1. 读入行数 $m$、列数 $n$ 以及整个矩阵，下标从 1 开始。
2. 双重循环遍历所有元素 `a[i][j]`，若满足 `i == 1 || i == m || j == 1 || j == n` 则累加进 `sum`。
3. 输出 `sum`。
4. 易错点：当 $m=1$ 或 $n=1$ 时，整行或整列都是边缘。用"逐格判断"的方式累加不会重复计算角落，比"四边相加再减角落"更稳妥。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[105][105];

int main() {
    int m, n;
    cin >> m >> n;

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            cin >> a[i][j];

    int sum = 0;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            // 位于第一行、最后一行、第一列或最后一列即为边缘元素
            if (i == 1 || i == m || j == 1 || j == n)
                sum += a[i][j];
        }
    }

    cout << sum << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(m \times n)$
- **空间复杂度**：$O(m \times n)$（存储矩阵）
