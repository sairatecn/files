# 数组逆序重存放

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个长度为 $n$ 的整数数组，将数组中的元素按逆序重新存放。例如原顺序为 $8,6,5,4,1$ ，逆序后为 $1,4,5,6,8$ 。

## 输入描述

- 第一行输入一个整数 $n$ ，表示数组中元素的个数（ $1<n<100$ ）。
- 第二行输入 $n$ 个整数，每两个整数之间用一个空格分隔。

## 输出描述

输出逆序后的数组元素，每两个整数之间用一个空格分隔。

## 示例

### 用例输入 1

```text
5
8 6 5 4 1
```

### 用例输出 1

```text
1 4 5 6 8
```

---

## 题解

### 解题思路

读入数组后，只需要从最后一个元素开始倒着输出，就相当于把数组逆序"重存放"了，无需真正交换元素。

### 算法分析

1. 读入 $n$，把 $n$ 个数读入数组 $a[1]\sim a[n]$。
2. 用循环从 $i=n$ 到 $i=1$ 逆序输出。
3. 元素之间用一个空格分隔，注意控制好空格：除第一个输出的元素外，其余每个元素前加一个空格。

易错点：输出时元素之间是空格分隔，末尾不要多余空格，最后要换行。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, a[105];
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];  // 读入数组

    for (int i = n; i >= 1; i--) {             // 从后往前输出
        if (i < n) cout << " ";                // 元素之间加空格
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，只需一次遍历输出。
- **空间复杂度**：$O(n)$，用一个数组存储 $n$ 个元素。
