# 校门外的树

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在长度为 $L$ 的马路上，将其视为数轴区间 $[0,L]$ ，每个整数点都种有一棵树。给定若干需要施工的区间，区间端点均为整数，且可能存在重合。所有位于这些区间（含端点）内的树都会被移走。要求计算最终剩余的树的数量。
每个施工区间由两个整数端点表示，但不保证输入时端点的大小关系，即可能出现起始点大于终止点的情况

## 输入描述

- 第一行包含两个整数 $L$ 和 $M$ （ $1≤L≤10000,1≤M≤1001\le L\le10000,\ 1\le M\le1001≤L≤10000,1≤M≤100$ ）。
- 接下来 $M$ 行，每行两个整数，表示一个施工区间的起始点和终止点坐标。

## 输出描述

输出一个整数，表示移走所有施工区间内的树之后，马路上剩余的树的数量。

## 示例

### 用例输入 1

```text
500 3
150 300
100 200
470 471
```

### 用例输出 1

```text
298
```

---

## 题解

### 解题思路

数轴上 $0\sim L$ 每个整数点都有一棵树，共 $L+1$ 棵。用一个标记数组表示每棵树是否还存在，把每个施工区间（含端点）内的树全部标记为移走，最后统计仍存在的树的数量。

### 算法分析

1. 读入 $L$、$M$，初始化 $a[0]\sim a[L]$ 全部为 $1$（表示树还在）。
2. 读入 $M$ 个区间：若起点大于终点，先用 `swap` 交换保证 $u \le v$。
3. 把区间 $[u,v]$ 内所有位置标记为 $0$（树被移走）。
4. 统计数组中值为 $1$ 的个数并输出。

易错点：区间含端点，循环要写成 $u\sim v$（含 $v$）；注意是 $L+1$ 棵树而不是 $L$ 棵；输入不保证起点小于终点。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int L, M, a[10005];
    cin >> L >> M;

    for (int i = 0; i <= L; i++) a[i] = 1;  // 初始时每棵树都在

    for (int k = 1; k <= M; k++) {
        int u, v;
        cin >> u >> v;
        if (u > v) swap(u, v);              // 保证 u <= v
        for (int i = u; i <= v; i++) {
            a[i] = 0;                       // 施工区间内的树被移走
        }
    }

    int cnt = 0;
    for (int i = 0; i <= L; i++) {
        if (a[i] == 1) cnt++;               // 统计剩下的树
    }
    cout << cnt << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(L \cdot M)$，最坏情况下每个区间都要遍历长度 $L$ 的区间。
- **空间复杂度**：$O(L)$，用一个长度 $L+1$ 的标记数组。
