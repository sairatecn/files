# 合法C标识符查

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个不包含空白符的字符串 $s$ ，判断它是否是 C 语言合法的标识符。要求如下：

- 字符串只包含字母、数字和下划线 _。
- 不能以数字开头。
- 保证不是 C 语言的保留字。

## 输入描述

一行字符串 $s$ ，不包含空白符，长度 $≤20\le 20≤20$ 。

## 输出描述

若 $s$ 是合法的 C 标识符，输出 yes，否则输出 no。

## 示例

### 用例输入 1

```text
RKPEGX9R;TWyYcp
```

### 用例输出 1

```text
no
```

---

## 题解

### 解题思路

C 语言标识符的判定规则是：只能由字母、数字、下划线组成，且不能以数字开头。本质上是"按规则逐字符检查"，只要任一字符非法，整个字符串就不合法。可以把规则拆成两部分：首字符单独判断，其余字符统一判断。

### 算法分析

1. 读入字符串 `s`（题目保证不含空白符、不是保留字，这两点无需再判断）。
2. 先检查首字符：必须是字母（`a~z` 或 `A~Z`）或下划线 `_`，否则直接输出 `no`。
3. 再遍历其余每个字符：必须是字母、数字或下划线，若出现其他字符（如分号、括号等）输出 `no`。
4. 全部字符都通过检查后输出 `yes`。
5. 易错点：首字符不能是数字，这一条必须单独判断；判断时既要用大写字母也要用小写字母，不要漏掉任一分支。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 判断是否字母
bool isLetter(char c) {
    return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z');
}
// 判断是否数字
bool isDigit(char c) {
    return c >= '0' && c <= '9';
}

int main() {
    string s;
    cin >> s;

    // 首字符必须是字母或下划线
    if (!(isLetter(s[0]) || s[0] == '_')) {
        cout << "no" << endl;
        return 0;
    }
    // 其余字符必须是字母、数字或下划线
    for (size_t i = 1; i < s.size(); i++) {
        if (!(isLetter(s[i]) || isDigit(s[i]) || s[i] == '_')) {
            cout << "no" << endl;
            return 0;
        }
    }
    cout << "yes" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（$n$ 为字符串长度，只需一趟扫描）
- **空间复杂度**：$O(1)$（只用一个字符串，无额外大数组）
