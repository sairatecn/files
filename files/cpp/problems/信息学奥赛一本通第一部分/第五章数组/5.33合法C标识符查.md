# 合法C标识符查

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个不包含空白符的字符串 $s$ ，判断它是否是 C 语言合法的标识符。要求如下：

- 字符串只包含字母、数字和下划线 _。
- 不能以数字开头。
- 保证不是 C 语言的保留字。

## 输入描述

一行字符串 $s$ ，不包含空白符，长度 $≤20\le 20≤20$ 。

## 输出描述

若 $s$ 是合法的 C 标识符，输出 yes，否则输出 no。

## 示例

### 用例输入 1

```text
RKPEGX9R;TWyYcp
```

### 用例输出 1

```text
no
```
