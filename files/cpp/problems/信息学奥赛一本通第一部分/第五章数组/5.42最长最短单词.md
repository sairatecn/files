# 最长最短单词

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一行句子（不超过200个单词，每个单词长度不超过100），只包含字母、空格和逗号。单词由至少一个连续的字母构成，空格和逗号作为单词间隔。输出第1个最长的单词和第1个最短的单词。

## 输入描述

一行句子，单词由字母构成，空格和逗号分隔单词，总长度 $≤200∗100\le 200*100≤200∗100$ 。

## 输出描述

第1行：第一个最长的单词。
第2行：第一个最短的单词。

## 示例

### 用例输入 1

```text
I am studying Programming language C in Peking University
```

### 用例输出 1

```text
Programming
I
```

---

## 题解

### 解题思路

句子中只有连续字母构成单词，空格和逗号只是分隔符。逐字符扫描句子，把连续字母累积成当前单词，遇到空格或逗号时就"结算"这个单词，更新最长单词和最短单词。

### 算法分析

1. 用 `getline` 读入整行句子。
2. 遍历每个字符：若是字母（`isalpha`），拼接到当前单词 cur；否则说明单词结束，调用结算函数处理 cur。
3. 结算时若 cur 非空：第一次直接同时作为最长和最短；之后用严格大于（`>`）更新最长、严格小于（`<`）更新最短，保证取到的是"第一个"最长/最短单词。
4. 循环结束后若 cur 非空，还要再结算一次（句子末尾没有分隔符）。
5. 分行输出最长单词和最短单词。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    string cur;                 // 当前正在累积的单词
    string longest = "", shortest = "";
    bool first = true;

    // 结算一个单词：更新最长、最短
    auto update = [&]() {
        if (cur.empty()) return;
        if (first) {
            longest = shortest = cur;
            first = false;
        } else {
            if (cur.size() > longest.size()) longest = cur;
            if (cur.size() < shortest.size()) shortest = cur;
        }
        cur.clear();
    };

    for (char c : s) {
        if (isalpha(c)) {
            cur += c;           // 字母属于单词
        } else {                // 空格或逗号是分隔符
            update();
        }
    }
    update();                   // 处理句子末尾的最后一个单词

    cout << longest << endl;
    cout << shortest << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为句子总长度。
- **空间复杂度**：$O(1)$。
