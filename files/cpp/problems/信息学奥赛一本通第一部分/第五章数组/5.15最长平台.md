# 最长平台

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知一个从小到大排序的数组，一个平台（Plateau）是连续值相同的元素序列，且不能再延伸。求数组中最长平台的长度。

## 输入描述

第一行输入整数 $n$ ，第二行输入 $n$ 个按升序排列的整数，空格分隔。

## 输出描述

输出数组中最长平台的长度。

## 示例

### 用例输入 1

```text
10
1 2 2 3 3 3 4 5 5 6
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

数组已按升序排列，所以相同值的元素一定连续靠在一起，平台就是"值连续相等的子段"。只需从左到右扫一遍，边扫边维护"当前平台长度"，一旦遇到新值就重新计数，并随时更新历史最大值。

### 算法分析

1. 读入 $n$ 和数组 $a$。
2. 令 `curLen = 1` 表示当前正在统计的平台长度，`maxLen = 1` 记录最长平台长度（数组非空时至少为 1）。
3. 从第 2 个元素（下标 1）开始循环：若 `a[i] == a[i-1]`，说明还在同一个平台上，`curLen++`；否则新平台开始，`curLen = 1`。
4. 每步都用 `maxLen = max(maxLen, curLen)` 更新答案，最后输出 `maxLen`。
5. 易错点：每次换新值时一定要把 `curLen` 重置为 1；`maxLen` 的初始值不能是 0（否则 n 只有 1 个数时答案为 0，出错）。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int maxLen = 1;  // 最长平台长度
    int curLen = 1;  // 当前平台长度
    for (int i = 1; i < n; i++) {
        if (a[i] == a[i - 1]) {
            curLen++;          // 与上一个元素相同，平台延长
        } else {
            curLen = 1;        // 遇到新元素，重新开始一个平台
        }
        maxLen = max(maxLen, curLen);
    }
    cout << maxLen << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（只需一趟扫描）
- **空间复杂度**：$O(n)$（存储整个数组）
