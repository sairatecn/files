# Problem Details

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个字符串，判断该字符串是否为回文。回文是指顺读和倒读都一样的字符串。

## 输入描述

一行字符串，长度 $≤100\le 100≤100$ ，不包含空白字符。

## 输出描述

如果字符串是回文，输出 yes；否则输出 no。

## 示例

### 用例输入 1

```text
abcdedcba
```

### 用例输出 1

```text
yes
```

---

## 题解

### 解题思路

回文即顺读和倒读完全一致的字符串。用双指针从两端向中间逐字符比较：左边指针 i 从 0 开始，右边指针 j 从末尾开始，只要出现一处 `s[i] != s[j]` 就说明不是回文。全部相同则是回文。

### 算法分析

1. 读入字符串 s（不含空白字符，用 cin 即可）。
2. 设置 i = 0、j = s.size() - 1，当 i < j 时比较 `s[i]` 与 `s[j]`。
3. 一旦发现不同，置 ok = false 并退出循环。
4. 循环结束后若 ok 仍为 true，输出 `yes`；否则输出 `no`（注意全部小写）。
5. 边界情况：长度为 0 或 1 的字符串天然是回文，循环不会进入，直接输出 yes。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.size();
    bool ok = true;
    for (int i = 0, j = n - 1; i < j; i++, j--) {
        if (s[i] != s[j]) {
            ok = false;
            break;
        }
    }
    cout << (ok ? "yes" : "no") << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串长度。
- **空间复杂度**：$O(1)$。
