# 最大值和最小值的差

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数序列，求序列中最大值与最小值的差值。

## 输入描述

- 第一行输入一个整数 $M$ ，表示序列中元素个数（ $1≤M≤100001\le M\le100001≤M≤10000$ ）。
- 第二行输入 $M$ 个整数，以空格分隔，每个整数的绝对值不超过 $10000$ 。

## 输出描述

输出一个整数，表示最大值和最小值的差。

## 示例

### 用例输入 1

```text
5
2 5 7 4 2
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

遍历整个序列，一边比较一边更新最大值和最小值，最后输出它们的差。不需要提前把所有数存下来，边读边更新即可。

### 算法分析

1. 初始化最大值 `mx` 为一个很小的数、最小值 `mn` 为一个很大的数。
2. 逐个读入元素，更新 `mx = max(mx, a)`、`mn = min(mn, a)`。
3. 输出 `mx - mn`。

易错点：初始值必须选得足够小/大。本题数值绝对值不超过 $10000$，所以初始化为 $-10001$ 和 $10001$ 即可保证第一个数能覆盖。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int m, x;
    int mx = -10001, mn = 10001;  // 根据数据范围初始化
    cin >> m;

    for (int i = 1; i <= m; i++) {
        cin >> x;
        if (x > mx) mx = x;  // 更新最大值
        if (x < mn) mn = x;  // 更新最小值
    }
    cout << mx - mn << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(m)$，只需一次线性扫描。
- **空间复杂度**：$O(1)$，边读边更新，无需额外数组。
