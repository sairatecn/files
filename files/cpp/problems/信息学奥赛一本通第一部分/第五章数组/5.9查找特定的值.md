# 查找特定的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在一个下标从 $1$ 开始的整数序列中，查找给定的值 $x$ ，并输出其**第一次出现的位置** 。若不存在该值，则输出 $−1-1−1$ 。

## 输入描述

- 第一行输入一个正整数 $n$ ，表示序列中元素个数（ $1≤n≤100001\le n\le100001≤n≤10000$ ）。
- 第二行输入 $n$ 个整数，表示序列的各个元素，相邻整数之间用一个空格分隔，每个整数的绝对值不超过 $10000$ 。
- 第三行输入一个整数 $x$ ，表示需要查找的特定值，其绝对值不超过 $10000$ 。

## 输出描述

若序列中存在 $x$ ，输出 $x$ 第一次出现的下标；否则输出 $−1-1−1$ 。

## 示例

### 用例输入 1

```text
5
2 3 6 7 3
3
```

### 用例输出 1

```text
2
```

---

## 题解

### 解题思路

下标从 $1$ 开始的序列，从前往后逐个比较，找到第一个等于 $x$ 的元素就立即输出它的下标；如果整个序列都没有，则输出 $-1$。

### 算法分析

1. 读入 $n$ 和序列，再读入要查找的值 $x$。
2. 从 $i=1$ 到 $n$ 依次比较，找到第一个 $a[i]==x$ 的位置。
3. 找到则输出该下标，否则输出 $-1$。

易错点：要求的是第一次出现的位置，找到后必须立即停止（`break`），不能继续往后找。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, x, a[10005];
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];  // 读入序列
    cin >> x;                                  // 读入要查找的值

    int pos = -1;  // 初始化为 -1，表示没找到
    for (int i = 1; i <= n; i++) {
        if (a[i] == x) {
            pos = i;   // 记录第一次出现的位置
            break;     // 找到后立即退出
        }
    }
    cout << pos << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，最坏情况下需要扫描整个序列。
- **空间复杂度**：$O(n)$，用一个数组存储序列。
