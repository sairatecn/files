# 图像旋转

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个 $n×mn \times mn×m$ 的黑白图像矩阵，将该图像**顺时针旋转 $90∘90^\circ90∘$** 后输出旋转后的结果。

## 输入描述

- 第一行包含两个整数 $n,m$ ，表示图像的行数和列数， $1≤n,m≤1001 \le n,m \le 1001≤n,m≤100$ 。
- 接下来 $n$ 行，每行 $m$ 个整数，表示图像的像素灰度值，范围为 $0∼2550 \sim 2550∼255$ 。

## 输出描述

- 输出旋转后的图像，共 $m$ 行，每行 $n$ 个整数，相邻整数之间以空格分隔。

## 示例

### 用例输入 1

```text
3 3
1 2 3
4 5 6
7 8 9
```

### 用例输出 1

```text
7 4 1
8 5 2
9 6 3

---

## 题解

### 解题思路

顺时针旋转 $90^\circ$ 后，新图像的第 $i$ 行、第 $j$ 列元素恰好来自原图像的第 $n-1-j$ 行、第 $i$ 列（即把原图像的每一列从下往上取出来按顺序排成行）。因此不需要真的"转动"矩阵，只需按新的下标顺序输出原矩阵即可。

### 算法分析

1. 用二维数组 `a[105][105]` 读入 $n$ 行 $m$ 列的矩阵。
2. 观察规律：旋转后新矩阵有 $m$ 行、$n$ 列，其中 `b[i][j] = a[n-1-j][i]`。
3. 双重循环按该公式输出，注意行列范围要交换：外层 $0 \sim m-1$，内层 $0 \sim n-1$。
4. 易错点：不要写成 `a[j][n-1-i]`，那是逆时针旋转；输出时行数应为 $m$ 而不是 $n$。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[105][105];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    // 旋转后共 m 行 n 列
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++)
            cout << a[n - 1 - j][i] << ' ';  // 从下往上取原矩阵第 i 列
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n \times m)$，只需两次遍历矩阵。
- **空间复杂度**：$O(n \times m)$，用于存储原矩阵。
