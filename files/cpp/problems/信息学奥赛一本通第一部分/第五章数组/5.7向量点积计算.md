# 向量点积计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定两个 $n$ 维向量 $a=(a1,a2,…,an)a=(a_1,a_2,\dots,a_n)a=(a1​,a2​,…,an​)$ 与 $b=(b1,b2,…,bn)b=(b_1,b_2,\dots,b_n)b=(b1​,b2​,…,bn​)$ ，计算它们的点积：
$a⋅b=∑i=1naibia\cdot b=\sum_{i=1}^{n} a_i b_ia⋅b=∑i=1n​ai​bi​$ 。

## 输入描述

- 第一行输入一个整数 $n$ （ $1≤n≤10001\le n\le10001≤n≤1000$ ）。
- 第二行输入 $n$ 个整数 $a1,a2,…,ana_1,a_2,\dots,a_na1​,a2​,…,an​$ 。
- 第三行输入 $n$ 个整数 $b1,b2,…,bnb_1,b_2,\dots,b_nb1​,b2​,…,bn​$ 。
- 相邻整数之间用一个空格分隔，每个整数的绝对值不超过 $1000$ 。

## 输出描述

输出一个整数，表示两个向量的点积结果。

## 示例

### 用例输入 1

```text
3
1 4 6
2 1 5
```

### 用例输出 1

```text
36
```

## 题解

### 解题思路

向量点积就是两个向量对应位置相乘再求和，即 $a\cdot b = \sum_{i=1}^{n} a_i b_i$。把两个向量分别存入两个数组，用循环累加对应元素之积即可。

### 算法分析

1. 读入维数 $n$，然后读入两个数组 $a$、$b$。
2. 用循环累加 `sum += a[i] * b[i]`。
3. 输出点积结果。

易错点：每个整数绝对值不超过 $1000$，$n$ 最大 $1000$，累加和可能接近 $10^9$，用 `long long` 更稳妥。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, a[1005], b[1005];
    long long sum = 0;  // 防止溢出

    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];  // 读入向量 a
    for (int i = 1; i <= n; i++) cin >> b[i];  // 读入向量 b

    for (int i = 1; i <= n; i++) {
        sum += (long long)a[i] * b[i];  // 对应位置相乘后累加
    }
    cout << sum << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，只需一次线性扫描。
- **空间复杂度**：$O(n)$，需要两个长度为 $n$ 的数组。
