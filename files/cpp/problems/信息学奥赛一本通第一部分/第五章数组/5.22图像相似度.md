# 图像相似度

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给出两幅大小相同的黑白图像，用 $0$ - $1$ 矩阵表示。若两幅图像在相同位置上的像素点颜色相同，则称它们在该位置具有相同的像素点。图像相似度定义为**相同像素点数占总像素点数的百分比** 。

## 输入描述

- 第一行输入两个整数 $m,nm, nm,n$ ，表示图像的行数和列数（ $1≤m,n≤1001 \le m,n \le 1001≤m,n≤100$ ）。
- 接下来 $m$ 行，每行 $n$ 个整数 $0$ 或 $1$ ，表示第一幅图像。
- 再接下来 $m$ 行，每行 $n$ 个整数 $0$ 或 $1$ ，表示第二幅图像。
- 相邻两个数之间用单个空格分隔。

## 输出描述

- 输出一个实数，表示两幅图像的相似度（百分比形式），结果精确到小数点后两位。

## 示例

### 用例输入 1

```text
3 3
1 0 1
0 0 1
1 1 0
1 1 0
0 0 1
0 0 1
```

### 用例输出 1

```text
44.44
```
