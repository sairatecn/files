# 图像相似度

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给出两幅大小相同的黑白图像，用 $0$ - $1$ 矩阵表示。若两幅图像在相同位置上的像素点颜色相同，则称它们在该位置具有相同的像素点。图像相似度定义为**相同像素点数占总像素点数的百分比** 。

## 输入描述

- 第一行输入两个整数 $m,nm, nm,n$ ，表示图像的行数和列数（ $1≤m,n≤1001 \le m,n \le 1001≤m,n≤100$ ）。
- 接下来 $m$ 行，每行 $n$ 个整数 $0$ 或 $1$ ，表示第一幅图像。
- 再接下来 $m$ 行，每行 $n$ 个整数 $0$ 或 $1$ ，表示第二幅图像。
- 相邻两个数之间用单个空格分隔。

## 输出描述

- 输出一个实数，表示两幅图像的相似度（百分比形式），结果精确到小数点后两位。

## 示例

### 用例输入 1

```text
3 3
1 0 1
0 0 1
1 1 0
1 1 0
0 0 1
0 0 1
```

### 用例输出 1

```text
44.44
```

---

## 题解

### 解题思路

相似度等于"相同位置像素点相同的个数"占"总像素点数"的百分比。读入两幅 $0$-$1$ 矩阵后逐格比较，统计相同个数，再用浮点数算出百分比，保留两位小数输出。

### 算法分析

1. 读入 $m,n$ 以及第一幅图像矩阵 `a[i][j]`、第二幅图像矩阵 `b[i][j]`。
2. 双重循环逐格比较，若 `a[i][j] == b[i][j]`，则 `same` 加 1。
3. 总像素点数为 $m \times n$，相似度 = $\frac{same}{m \times n} \times 100\%$。
4. 用 `100.0 * same / (m * n)` 计算（注意写成 `100.0` 而不是 `100`，否则整数除法会丢失精度），用 `printf("%.2f", ...)` 保留两位小数输出。
5. 易错点：结果要求四舍五入精确到小数点后两位，使用 `%.2f` 即可；不要忘记乘以 100。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[105][105], b[105][105];

int main() {
    int m, n;
    cin >> m >> n;

    // 读入第一幅图像
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            cin >> a[i][j];

    // 读入第二幅图像
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            cin >> b[i][j];

    int same = 0; // 相同像素点的个数
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (a[i][j] == b[i][j]) same++;

    // 相似度 = 相同像素点 / 总像素点 * 100%
    double percent = 100.0 * same / (m * n);
    printf("%.2f\n", percent);

    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(m \times n)$
- **空间复杂度**：$O(m \times n)$（存储两幅图像）
