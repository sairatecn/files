# 直方图

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个非负整数数组，统计每个整数 $0$ 到 $FmaxF_{max}Fmax​$ （数组最大值）出现的次数。

## 输入描述

第一行输入整数 $n$ （ $1≤n≤100001\le n\le100001≤n≤10000$ ），第二行输入 $n$ 个非负整数，空格分隔。

## 输出描述

按顺序输出每个整数出现次数，每行一个数，从 $0$ 到数组最大值 $FmaxF_{max}Fmax​$ ，未出现的输出 $0$ 。

## 示例

### 用例输入 1

```text
5
1 1 2 3 1
```

### 用例输出 1

```text
0
3
1
1
```

---

## 题解

### 解题思路

题目要求统计从 0 到数组最大值之间每个整数出现的次数。先用一个计数数组记录每个数字的出现次数，同时记录最大值，最后从 0 循环到最大值依次输出即可。

### 算法分析

1. 读入 $n$，循环读入每个数 $x$，用 `cnt[x]++` 记录次数，并用 `mx` 记录当前最大值。
2. 从 0 循环到 `mx`，依次输出 `cnt[i]`，每个数占一行；没出现过的数计数为 0，直接输出 0 即可。
3. 易错点：计数数组要开得足够大（本题 $n \le 10000$，开到 100005 即可）；当所有数都为 0 时，`mx` 为 0，只输出一行 0，循环也要能正确处理。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int cnt[100005]; // 计数数组，统计每个数字出现的次数

int main() {
    int n;
    cin >> n;

    int mx = 0; // 记录数组中的最大值
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        cnt[x]++;        // 该数字出现次数加 1
        mx = max(mx, x); // 更新最大值
    }

    // 从 0 到最大值依次输出每个数出现的次数
    for (int i = 0; i <= mx; i++) {
        cout << cnt[i] << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n + F_{max})$，其中 $F_{max}$ 为数组最大值
- **空间复杂度**：$O(F_{max})$，即计数数组的大小
