# 铺地毯

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在一个矩形区域铺设 $n$ 张矩形地毯，后铺的地毯覆盖前面的。给定一个点 $(x,y)(x, y)(x,y)$ ，求覆盖该点的最上层地毯编号，如果没有覆盖则输出 $−1-1−1$ 。
![image.png](https://hoj.hugemaker.com.cn/api/public/img/a1ad0d1656d34c84bc548b00241a6ca7.png)

## 输入描述

第一行输入整数 $n$ ，接下来的 $n$ 行每行四个整数 $abgka\ b\ g\ kabgk$ 表示地毯左下角坐标及宽高，最后一行两个整数 $xyx\ yxy$ 表示查询点坐标。

## 输出描述

输出覆盖点 $(x,y)(x, y)(x,y)$ 的最上层地毯编号，若没有覆盖输出 $−1-1−1$ 。

## 示例

### 用例输入 1

```text
3
1 0 2 3
0 2 3 3
2 1 3 3
2 2
```

### 用例输出 1

```text
3
```

## 题解

### 解题思路

后铺的地毯会覆盖先铺的，所以询问点 $(x,y)$ 上最上层的地毯，就是"从最后铺的一张往前找，第一个覆盖该点的地毯"。因此只需把每张地毯的左下角坐标和宽、高存下来，然后倒序判断即可，不需要真的逐格填充。

### 算法分析

1. 用数组 $a,b,g,k$ 分别存每张地毯左下角的横、纵坐标以及宽、高。
2. 读入询问点坐标 $x,y$。
3. 从 $i=n$ 到 $1$ 倒序遍历每张地毯，判断点是否在覆盖范围内：
   第 $i$ 张地毯覆盖的区域为 $x \in [a_i, a_i+g_i]$，$y \in [b_i, b_i+k_i]$（边界也算覆盖）。
4. 第一个满足条件的地毯编号就是答案，输出后直接结束；若全部不满足，输出 $-1$。
5. 易错点：判断时要用"左闭右闭"区间，把边界点也算作被覆盖。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[10005], b[10005], g[10005], k[10005];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i] >> b[i] >> g[i] >> k[i];
    }

    int x, y;
    cin >> x >> y;

    // 从最上层（最后铺的）开始往前找，第一个覆盖的就是答案
    for (int i = n; i >= 1; i--) {
        if (x >= a[i] && x <= a[i] + g[i] &&
            y >= b[i] && y <= b[i] + k[i]) {
            cout << i << endl;
            return 0;
        }
    }

    cout << -1 << endl; // 没有任何地毯覆盖该点
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（倒序扫描一次）
- **空间复杂度**：$O(n)$（四个数组存储 $n$ 张地毯）
