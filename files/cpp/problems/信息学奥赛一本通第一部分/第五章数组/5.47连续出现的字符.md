# 连续出现的字符

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个字符串，找到第一个连续出现至少 $k$ 次的字符。

## 输入描述

第一行：整数 $k$ ( $1≤k≤10001 \le k \le 10001≤k≤1000$ )；第二行：字符串，长度 $1∼25001 \sim 25001∼2500$ ，不包含空白符。

## 输出描述

若存在连续出现至少 $k$ 次的字符，输出该字符；否则输出 No。

## 示例

### 用例输入 1

```text
3
abcccaaab
```

### 用例输出 1

```text
c
```

---

## 题解

### 解题思路

要判断"连续出现至少 $k$ 次"，只需从左到右扫描字符串，记录当前字符以及它连续出现的次数。一旦某个字符的连续次数达到 $k$，它就是答案，立即输出。这是经典的"扫描统计连续段"问题。

### 算法分析

1. 读入整数 `k` 和字符串 `s`。
2. 用变量 `cur` 记录当前正在统计的字符、`cnt` 记录它已连续出现的次数。
3. 遍历每个字符 `c`：若 `c == cur`，连续次数 `cnt++`；否则切换为 `c`，并重置 `cnt = 1`。
4. 每步都判断 `cnt >= k`，成立则输出该字符并结束程序。
5. 全部扫描完仍没有满足条件的字符，输出 `No`。
6. 易错点：注意 $k=1$ 时第一个字符就应满足条件，所以"切换后重置为 1"的判断必须在每一轮都做，不能漏掉第一个字符；输出为 `No`（大写 N 小写 o），大小写不要写错。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int k;
    string s;
    cin >> k >> s;

    char cur = '\0';  // 当前连续段的字符
    int cnt = 0;      // 当前字符连续出现的次数
    for (char c : s) {
        if (c == cur) {
            cnt++;          // 与上一个字符相同，连续次数 +1
        } else {
            cur = c;        // 新字符，重新开始一个连续段
            cnt = 1;
        }
        if (cnt >= k) {     // 已连续出现至少 k 次
            cout << c << endl;
            return 0;
        }
    }
    cout << "No" << endl;   // 没有满足条件的字符
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（一趟线性扫描，$n$ 为字符串长度）
- **空间复杂度**：$O(1)$（只用几个变量，无额外大数组）
