# 不高兴的津津

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

津津上初中，每天上学并参加额外课程。如果一天上课总时间超过 8 小时，津津会不高兴。给定一周每天的上学时间和额外课程时间，判断津津是否会不高兴，若会，输出最不高兴的一天（周一至周日分别为 1~7），若不会不高兴则输出 0。若多天不高兴程度相同，输出时间最靠前的一天。

## 输入描述

七行数据，每行包含两个小于 10 的非负整数，用空格分隔。第一列为上学时间，第二列为额外课程时间，依次表示周一到周日。

## 输出描述

输出一个整数：0 表示不会不高兴，1~7 表示最不高兴的那一天。

## 示例

### 用例输入 1

```text
5 3
6 2
7 2
5 3
5 4
0 4
0 6
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

每天上课总时间 = 上学时间 + 额外课程时间。只有总时间**超过** $8$ 小时才会不高兴。依次读入 $7$ 天的数据，记录总时间最大的那天的编号；若有多天总时间相同，取编号靠前的一天。

### 算法分析

1. 初始化 `maxSum = 8`（记录到目前为止的最大总时间），`ans = 0`（答案天数）。
2. 循环 $7$ 天，读入上学时间和额外课程时间，求出当天总和 $s$。
3. 若 $s > maxSum$，更新 `maxSum = s`、`ans = i`。
4. 输出 `ans`；若没有一天超过 $8$ 小时，`ans` 保持 $0$。

易错点：必须严格大于 $8$ 才算不高兴；题目要求"多天相同取靠前"，所以更新条件用 `>` 而不是 `>=`，这样相等时不更新，保留更早的一天。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int maxSum = 8;  // 超过 8 小时才不高兴
    int ans = 0;     // 记录最不高兴的一天，0 表示没有

    for (int i = 1; i <= 7; i++) {
        int a, b;
        cin >> a >> b;
        int s = a + b;              // 当天总时间
        if (s > maxSum) {           // 严格大于，保证同分取靠前
            maxSum = s;
            ans = i;
        }
    }
    cout << ans << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定只有 $7$ 天。
- **空间复杂度**：$O(1)$，只用几个变量，无需数组。
