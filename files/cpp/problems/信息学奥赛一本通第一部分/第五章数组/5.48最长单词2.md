# 最长单词2

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个以’.'结尾的简单英文句子（长度不超过500），单词之间用空格分隔，没有缩写形式和其它特殊形式。输出句子中最长的单词，如果有多个，则输出第一个。

## 输入描述

一行简单英文句子，以’.'结尾。

## 输出描述

句子中最长的单词。

## 示例

### 用例输入 1

```text
I am a student of Peking University.
```

### 用例输出 1

```text
University
```

---

## 题解

### 解题思路

句子以 '.' 结尾，最后一个单词会带着句点，例如 `University.`。按空格拆分单词后，把每个单词末尾的句点去掉，再比较长度即可。用严格大于更新最长单词，保证并列时输出第一个。

### 算法分析

1. 用 `getline` 读入整行句子。
2. 用 `istringstream` 按空格逐个提取单词。
3. 对每个单词，若最后一个字符是 '.'，用 `pop_back()` 去掉句点。
4. 若该单词长度大于当前最长单词的长度，则更新最长单词（严格大于保证取第一个）。
5. 循环结束后输出最长单词。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    istringstream sin(s);
    string word;
    string longest = "";
    while (sin >> word) {
        if (word.back() == '.') word.pop_back();  // 去掉末尾句点
        if (word.size() > longest.size()) {
            longest = word;                       // 严格大于：取第一个最长单词
        }
    }
    cout << longest << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为句子长度。
- **空间复杂度**：$O(n)$。
