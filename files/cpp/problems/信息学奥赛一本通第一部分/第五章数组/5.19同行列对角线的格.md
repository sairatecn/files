# 同行列对角线的格

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在一个 $n×nn \times nn×n$ 的棋盘中（行列均从 $1$ 开始编号），给定一个格子 $(i,j)(i, j)(i,j)$ ，请输出与该格子 **同行、同列、同一对角线** 的所有格子位置。需要分别输出：

- 同一行
- 同一列
- 从左上到右下的对角线
- 从左下到右上的对角线

![image.png](/api/public/img/cb406b9f7fa546318f43af0cba3bfab5.png)

## 输入描述

- 一行输入三个自然数 $n,i,jn, i, jn,i,j$ ，相邻两个数之间用单个空格隔开。
- 其中 $1≤i≤n,1≤j≤n,1≤n≤101 \le i \le n, 1 \le j \le n, 1 \le n \le 101≤i≤n,1≤j≤n,1≤n≤10$ 。

## 输出描述

- 共输出 $4$ 行：
- 第 $1$ 行：从左到右输出同一行格子位置；
- 第 $2$ 行：从上到下输出同一列格子位置；
- 第 $3$ 行：从左上到右下输出同一对角线格子位置；
- 第 $4$ 行：从左下到右上输出同一对角线格子位置。
- 每个格子位置格式为 $(x,y)$ ，采用英文标点，中间无空格，相邻位置用单个空格分隔。

## 示例

### 用例输入 1

```text
4 2 3
```

### 用例输出 1

```text
(2,1) (2,2) (2,3) (2,4)
(1,3) (2,3) (3,3) (4,3)
(1,2) (2,3) (3,4)
(4,1) (3,2) (2,3) (1,4)
```

## 题解

### 解题思路

棋盘格子用坐标 $(x,y)$ 表示。同一行满足行号相同，同一列满足列号相同；左上到右下的主对角线满足 $x-y$ 为常数，左下到右上的副对角线满足 $x+y$ 为常数。分别按对应方向从边界出发遍历并输出即可。

### 算法分析

1. **同一行**：固定行号 $i$，列号从 1 到 $n$ 依次输出 $(i, j)$。
2. **同一列**：固定列号 $j$，行号从 1 到 $n$ 依次输出 $(i, j)$。
3. **主对角线（左上→右下）**：从 $(i,j)$ 沿左上方向（$x--, y--$）走到棋盘边界，确定起点，再从起点沿右下方向（$x++, y++$）依次输出，直到越界。
4. **副对角线（左下→右上）**：从 $(i,j)$ 沿左下方向（$x++, y--$）走到棋盘边界，确定起点，再从起点沿右上方向（$x--, y++$）依次输出，直到越界。
5. 易错点：输出格式为 `(x,y)` 英文括号、中间无空格，相邻位置用单个空格分隔，行尾不能有多余空格；走对角线的起点和终点都要保证在棋盘内。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, i, j;
    cin >> n >> i >> j;

    // 第 1 行：同一行，从左到右
    for (int c = 1; c <= n; c++)
        cout << "(" << i << "," << c << ")" << (c == n ? "\n" : " ");

    // 第 2 行：同一列，从上到下
    for (int r = 1; r <= n; r++)
        cout << "(" << r << "," << j << ")" << (r == n ? "\n" : " ");

    // 第 3 行：左上到右下的对角线，先沿左上走到边界确定起点
    int x = i, y = j;
    while (x > 1 && y > 1) { x--; y--; }
    for (; x <= n && y <= n; x++, y++)
        cout << "(" << x << "," << y << ")" << (x == n || y == n ? "\n" : " ");

    // 第 4 行：左下到右上的对角线，先沿左下走到边界确定起点
    x = i; y = j;
    while (x < n && y > 1) { x++; y--; }
    for (; x >= 1 && y <= n; x--, y++)
        cout << "(" << x << "," << y << ")" << (x == 1 || y == n ? "\n" : " ");

    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（每条直线/对角线最多遍历 $n$ 个格子）
- **空间复杂度**：$O(1)$（只用了常数个变量）
