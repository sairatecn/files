# 密码翻译

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

对给定字符串进行简单加密：

- 对于字母 a-y 或 A-Y，替换为其后继字母。
- 对于 z 替换为 a，Z 替换为 A。
- 其他非字母字符保持不变。

## 输入描述

一行字符串，长度 $<80< 80<80$ 个字符。

## 输出描述

输出加密后的字符串。

## 示例

### 用例输入 1

```text
Hello! How are you!
```

### 用例输出 1

```text
Ifmmp! Ipx bsf zpv!
```

---

## 题解

### 解题思路

这是凯撒密码的简单版本：每个字母向后移动一位，`z` 和 `Z` 环绕回 `a` 和 `A`，非字母字符原样保留。逐字符分类处理即可。

### 算法分析

1. 字符串可能包含空格，用 `getline(cin, s)` 读入一整行。
2. 对每个字符分类处理：
   - 小写字母 `a` 到 `y`：`s[i] + 1`；
   - `z` 变成 `a`（环绕）；
   - 大写字母 `A` 到 `Y`：`s[i] + 1`；
   - `Z` 变成 `A`（环绕）；
   - 其他字符保持不变。
3. 输出处理后的字符串。
4. 易错点：`z` 直接加 1 会变成 `{`，`Z` 会变成 `[`，所以必须单独处理环绕；判断时要区分大小写，不能把 `z` 放进大写分支。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);  // 可能包含空格

    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] >= 'a' && s[i] <= 'y')
            s[i] = s[i] + 1;    // 小写字母前进一位
        else if (s[i] == 'z')
            s[i] = 'a';         // z 环绕到 a
        else if (s[i] >= 'A' && s[i] <= 'Y')
            s[i] = s[i] + 1;    // 大写字母前进一位
        else if (s[i] == 'Z')
            s[i] = 'A';         // Z 环绕到 A
        // 其余非字母字符保持不变
    }
    cout << s << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为字符串长度，只需一次遍历。
- **空间复杂度**：$O(n)$，存储字符串。
