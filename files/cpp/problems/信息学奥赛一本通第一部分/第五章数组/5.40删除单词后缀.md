# 删除单词后缀

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个单词，如果该单词以 er、ly 或 ing 后缀结尾，则删除该后缀；否则不进行任何操作。题目保证删除后缀后的单词长度不为 0。

## 输入描述

一行单词，单词中不包含空格，长度 $≤32\le 32≤32$ 。

## 输出描述

输出处理后的单词。

## 示例

### 用例输入 1

```text
referer
```

### 用例输出 1

```text
refer
```

---

## 题解

### 解题思路

本题只要求删除单词末尾的固定后缀（er、ly、ing），可以先判断字符串长度是否足够，再用 substr 取出末尾几个字符与后缀比较。若匹配，就用 resize 直接去掉相应长度的字符。

### 算法分析

1. 用 cin 读入单词 s，长度为 n。
2. 若 `n >= 2` 且末尾两个字符为 "er"，则 `s.resize(n - 2)` 删除后缀。
3. 否则若 `n >= 2` 且末尾两个字符为 "ly"，同样删除后缀。
4. 否则若 `n >= 3` 且末尾三个字符为 "ing"，删除后缀。
5. 先判断长度再取子串，可避免越界；题目保证删除后长度不为 0，无需担心空串。最后输出 s。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();

    // 检查后缀 er
    if (n >= 2 && s.substr(n - 2) == "er") {
        s.resize(n - 2);
    }
    // 检查后缀 ly
    else if (n >= 2 && s.substr(n - 2) == "ly") {
        s.resize(n - 2);
    }
    // 检查后缀 ing
    else if (n >= 3 && s.substr(n - 3) == "ing") {
        s.resize(n - 3);
    }

    cout << s << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为单词长度。
- **空间复杂度**：$O(1)$。
