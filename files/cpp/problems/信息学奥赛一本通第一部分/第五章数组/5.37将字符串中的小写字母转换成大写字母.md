# 将字符串中的小写字母转换成大写字母

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个字符串，将其中所有的小写字母转换成大写字母，其它字符保持不变。

## 输入描述

一行字符串，长度不超过100，可能包含空格。

## 输出描述

输出转换为大写字母后的字符串。

## 示例

### 用例输入 1

```text
helloworld123Ha
```

### 用例输出 1

```text
HELLOWORLD123HA
```

---

## 题解

### 解题思路

逐字符扫描字符串，遇到小写字母就转为大写，其他字符原样保留。字符串可能含空格，需要用 `getline` 读入整行。

### 算法分析

1. 用 `getline(cin, s)` 读入一行字符串（可含空格）。
2. 遍历每个字符，若在 `'a'` 到 `'z'` 之间，则 `s[i] -= 32`（大小写字母 ASCII 码相差 32）。
3. 输出处理后的字符串。
4. 易错点：不要用 `cin >> s` 读入，遇到空格会截断；只对字母做转换，数字、空格等非字母字符保持原样。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);  // 可能包含空格

    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] >= 'a' && s[i] <= 'z')
            s[i] = s[i] - 32;  // 小写字母转大写
    }
    cout << s << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为字符串长度，只需一次遍历。
- **空间复杂度**：$O(n)$，存储字符串。
