# 找第一个只出现一次的字符

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个只包含**小写字母** 的字符串，请找出其中**第一个仅出现一次的字符** ；如果不存在这样的字符，则输出 $no$ 。

## 输入描述

- 一个字符串，仅包含小写字母，字符串长度小于 $100000$ 。

## 输出描述

- 输出第一个仅出现一次的字符；若不存在，则输出 $no$ 。

## 示例

### 用例输入 1

```text
abcabd
```

### 用例输出 1

```text
c
```

---

## 题解

### 解题思路

"第一个只出现一次的字符"需要知道每个字符在整个字符串中出现的总次数。字符串只含小写字母（共 26 种），可以用一个长度为 26 的计数数组先统计频次，再按原字符串顺序找到第一个频次为 1 的字符。

### 算法分析

1. 读入字符串 `s`。
2. 用 `cnt[26]` 记录每个小写字母的出现次数：遍历一遍 `s`，对每个字符执行 `cnt[s[i]-'a']++`。
3. 再按原顺序遍历一次 `s`，遇到第一个 `cnt[s[i]-'a'] == 1` 的字符立即输出并结束程序。
4. 若遍历完仍没有找到，输出 `no`。
5. 易错点：字符下标要减去 `'a'` 才能对应到计数数组；第二趟必须按原字符串顺序扫描，而不是按字母顺序，否则找到的就不是"第一个"。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    int cnt[26] = {0};              // 统计每个小写字母出现次数
    for (char c : s) {
        cnt[c - 'a']++;
    }
    for (char c : s) {              // 按原顺序找第一个出现 1 次的字符
        if (cnt[c - 'a'] == 1) {
            cout << c << endl;
            return 0;
        }
    }
    cout << "no" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$（两趟线性扫描，$n$ 为字符串长度）
- **空间复杂度**：$O(1)$（只用一个长度 26 的计数数组）
