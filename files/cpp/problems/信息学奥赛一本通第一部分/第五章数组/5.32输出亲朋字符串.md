# 输出亲朋字符串

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定字符串 $s$ ，构造其对应的亲朋字符串 $s1s_1s1​$ 。规则如下：

- 第 $i$ 个亲朋字符等于 $sis_isi​$ 与 $si+1s_{i+1}si+1​$ 的 ASCII 值之和所对应的字符（ $1≤i<∣s∣1 \le i < |s|1≤i<∣s∣$ ）。
- 最后一个亲朋字符由 $s∣s∣s_{|s|}s∣s∣​$ 与 $s1s_1s1​$ 的 ASCII 值之和得到。

## 输入描述

输入一行字符串 $s$ ，长度满足 $2≤∣s∣≤1002 \le |s| \le 1002≤∣s∣≤100$ ，且每个字符的 ASCII 值不大于 $63$ 。

## 输出描述

输出一行，为变换后的亲朋字符串。

## 示例

### 用例输入 1

```text
1234
```

### 用例输出 1

```text
cege
```

---

## 题解

### 解题思路

直接按规则模拟：把相邻两个字符的 ASCII 值相加，把和对应的字符作为新的字符输出。第 $i$ 个新字符由 $s[i]$ 与 $s[i+1]$ 得到，最后一个由 $s[n-1]$ 与 $s[0]$ 得到（首尾相接）。

### 算法分析

1. 用 `string` 读入字符串 `s`，记长度为 `n`。
2. 对 $i$ 从 0 到 $n-2$，输出字符 `s[i] + s[i+1]`；最后一个输出 `s[n-1] + s[0]`。
3. 字符相加时 `char` 会自动提升为 `int`，相加后转回 `char` 输出即可；题目保证每个字符 ASCII 值不大于 63，因此两字符之和不超过 126，不会溢出。
4. 易错点：最后一个字符的"下一个"是第一个字符，应写 `s[n-1] + s[0]`，不能写 `s[n]`（那是字符串结束符）。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);  // 读入一行
    int n = s.size();

    for (int i = 0; i < n - 1; i++)
        cout << char(s[i] + s[i + 1]);  // 相邻字符 ASCII 值之和
    cout << char(s[n - 1] + s[0]) << endl;  // 首尾相连
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为字符串长度，只需一次遍历。
- **空间复杂度**：$O(n)$，存储原字符串。
