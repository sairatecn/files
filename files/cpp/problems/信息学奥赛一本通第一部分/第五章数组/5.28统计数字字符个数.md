# 统计数字字符个数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一行字符串，统计其中**数字字符** （ $0$ – $9$ ）的个数。

## 输入描述

- 一行字符串，字符串总长度不超过 $255$ 。

## 输出描述

- 输出一行，一个整数，表示字符串中数字字符的个数。

## 示例

### 用例输入 1

```text
Peking University is set up at 1898.
```

### 用例输出 1

```text
4
```

---

## 题解

### 解题思路

逐字符检查字符串，只要字符在 `'0'` 到 `'9'` 之间就计数加一。由于字符串中可能包含空格，需要用 `getline` 读入整行而不是 `cin`。

### 算法分析

1. 用 `getline(cin, s)` 读入一整行字符串（自动保留空格）。
2. 遍历 `s` 的每个字符，判断是否满足 `s[i] >= '0' && s[i] <= '9'`，成立则计数器加一。
3. 输出计数结果。
4. 易错点：不能用 `cin >> s` 读入，遇到空格会截断导致统计不全；字符比较要写为 `'0'`、`'9'` 字符形式，不要写成数字 0 和 9。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);  // 读入整行，可能包含空格

    int cnt = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] >= '0' && s[i] <= '9')
            cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为字符串长度。
- **空间复杂度**：$O(n)$，存储字符串。
