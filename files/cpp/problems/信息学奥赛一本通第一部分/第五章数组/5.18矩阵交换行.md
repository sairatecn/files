# 矩阵交换行

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个 $5×55 \times 55×5$ 的矩阵（数学上，一个 $r×cr \times cr×c$ 的矩阵是由 $r$ 行 $c$ 列元素排列成的矩形阵列），将第 $n$ 行与第 $m$ 行进行交换，并输出交换后的矩阵。

## 输入描述

- 共 $6$ 行输入：
- 前 $5$ 行为矩阵的每一行元素，元素之间以一个空格分隔。
- 第 $6$ 行包含两个整数 $m,nm, nm,n$ ，表示需要交换的两行编号（ $1≤m,n≤51 \le m,n \le 51≤m,n≤5$ ）。

## 输出描述

- 输出交换行之后的矩阵。
- 矩阵的每一行占一行，行内元素之间以一个空格分隔。

## 示例

### 用例输入 1

```text
1 2 2 1 2
5 6 7 8 3
9 3 0 5 3
7 2 1 4 6
3 0 8 2 4
1 5
```

### 用例输出 1

```text
3 0 8 2 4
5 6 7 8 3
9 3 0 5 3
7 2 1 4 6
1 2 2 1 2
```

## 题解

### 解题思路

题目给出一个 $5 \times 5$ 的矩阵，要求交换第 $n$ 行与第 $m$ 行。直接用双重循环读入矩阵，再用一次循环把两行对应的元素逐个 `swap` 交换，最后输出整个矩阵即可。

### 算法分析

1. 读入 $5 \times 5$ 矩阵，存入二维数组 `a[i][j]`，行号、列号都从 1 开始编号。
2. 读入两个行号 $m,n$。
3. 用循环 `for (j = 1; j <= 5; j++)` 依次交换 `a[m][j]` 与 `a[n][j]`。
4. 按行输出矩阵，每行元素之间用一个空格分隔，行末换行。
5. 易错点：行号从 1 开始，与数组下标一一对应；若 $m=n$，交换后矩阵不变，代码也能正确处理；输出时注意控制空格，避免行尾多空格。

### 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[6][6]; // 5x5 矩阵，下标从 1 开始

int main() {
    // 读入矩阵
    for (int i = 1; i <= 5; i++)
        for (int j = 1; j <= 5; j++)
            cin >> a[i][j];

    int m, n;
    cin >> m >> n; // 需要交换的两行

    // 逐个交换第 m 行与第 n 行的元素
    for (int j = 1; j <= 5; j++) {
        swap(a[m][j], a[n][j]);
    }

    // 输出交换后的矩阵
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            cout << a[i][j];
            if (j < 5) cout << " "; // 行内元素用空格分隔
        }
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$（矩阵规模固定为 $5 \times 5$）
- **空间复杂度**：$O(1)$（固定大小的二维数组）
