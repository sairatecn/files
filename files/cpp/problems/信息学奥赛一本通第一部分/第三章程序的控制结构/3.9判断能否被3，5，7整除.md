# 判断能否被3，5，7整除

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数，判断它能否被3，5，7整除，并输出以下信息：
1、能同时被3，5，7整除，输出’3 5 7’；
2、只能被其中两个数整除，输出两个数，小的在前，中间空格；
3、只能被其中一个数整除，输出这个除数；
4、不能被任何数整除，输出小写字符’n’。

## 输入描述

输入一行，包括一个整数 n（-1,000,000 < n < 1,000,000）。

## 输出描述

输出一行，按照描述要求给出整数被3，5，7整除的情况。

## 示例

### 用例输入 1

```text
105
```

### 用例输出 1

```text
3 5 7
```
## 题解

### 解题思路

分别判断 `n` 能否被 3、5、7 整除，按“整除的个数”分四种情况输出。当有多个除数整除时，需要按**从小到大**的顺序、用空格连接输出，并注意不要有末尾多余空格。

### 算法分析

1. 计算三个布尔值 `d3 = (n%3==0)`、`d5 = (n%5==0)`、`d7 = (n%7==0)`，并统计整除个数 `cnt`。
2. `cnt == 3` 输出 `3 5 7`；`cnt == 2` 输出其中两个（小的在前）；`cnt == 1` 输出那一个除数；`cnt == 0` 输出 `n`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool d3 = (n % 3 == 0);  // 能否被 3 整除
    bool d5 = (n % 5 == 0);  // 能否被 5 整除
    bool d7 = (n % 7 == 0);  // 能否被 7 整除
    int cnt = d3 + d5 + d7;  // 统计整除的个数

    if (cnt == 3) {
        cout << "3 5 7" << endl;
    } else if (cnt == 2) {
        // 按从小到大顺序输出，用前导空格避免末尾多余空格
        if (d3) cout << "3";
        if (d5) { if (d3) cout << " "; cout << "5"; }
        if (d7) { if (d3 || d5) cout << " "; cout << "7"; }
        cout << endl;
    } else if (cnt == 1) {
        if (d3) cout << "3" << endl;
        else if (d5) cout << "5" << endl;
        else cout << "7" << endl;
    } else {
        cout << "n" << endl;  // 都不能整除
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
