# 计算邮资

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

根据邮件的重量和用户是否选择加急计算邮费。
重量在1000克以内(包括1000克)，基本费8元。
超过1000克的部分，每500克加收超重费4元，不足500克部分按500克计算；
如果用户选择加急，多收5元。

## 输入描述

输入一行，包含整数和一个字符，以一个空格分开，分别表示重量（单位为克）和是否加急。字符’y’表示加急，'n’表示不加急。

## 输出描述

输出一行，包含一个整数，表示邮费。

## 示例

### 用例输入 1

```text
1200 y
```

### 用例输出 1

```text
17
```
## 题解

### 解题思路

邮资由三部分组成：基础费 8 元；超过 1000 克的部分按“每 500 克 4 元、不足 500 克按 500 克算”加收（即向上取整）；加急再多收 5 元。向上取整可用整数技巧 `(over + 499) / 500` 实现。

### 算法分析

1. 读入重量 `w`（整数）和字符 `c`（`'y'` 加急 / `'n'` 不加急）。
2. `cost = 8`；若 `w > 1000`，则 `cost += ((w - 1000 + 499) / 500) * 4`（计算超重段数）。
3. 若 `c == 'y'`，`cost += 5`。
4. 输出 `cost`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int w;
    char c;
    cin >> w >> c;                 // 如 "1200 y"
    int cost = 8;                  // 1000 克以内基础费
    if (w > 1000) {
        int over = w - 1000;       // 超出 1000 克的部分
        int extra = (over + 499) / 500 * 4;  // 向上取整计算超重费用
        cost += extra;
    }
    if (c == 'y') cost += 5;       // 加急多收 5 元
    cout << cost << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
