# 骑车与走路

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

在清华校园里，没有自行车，上课办事会很不方便。但实际上，并非去办任何事情都是骑车快，因为骑车总要找车、开锁、停车、锁车等，这要耽误一些时间。假设找到自行车，开锁并骑上自行车的时间为27秒；停车锁车的时间为23秒；步行每秒行走1.2米，骑车每秒行走3.0米。请判断走不同的距离去办事，是骑车快还是走路快。如果骑车快，输出’Bike’；如果走路快，输出’Walk’；如果一样快，输出’All’。

## 输入描述

输入一行，包含一个整数 d，表示一次办事要行走的距离，单位为米。

## 输出描述

输出一行，如果骑车快，输出’Bike’；如果走路快，输出’Walk’；如果一样快，输出’All’。

## 示例

### 用例输入 1

```text
100
```

### 用例输出 1

```text
All
```
## 题解

### 解题思路

比较“骑车”与“走路”两种方式的耗时，取更短者：
- 步行耗时 = `d / 1.2` 秒（步行速度 1.2 米/秒）；
- 骑车耗时 = 固定开销 27（找车开锁）+ 23（停车锁车）= 50 秒，再加上骑行时间 `d / 3.0` 秒（骑车速度 3.0 米/秒）。

比较二者大小：骑车更短输出 `Bike`，步行更短输出 `Walk`，相等输出 `All`。由于用浮点数计算，判断“相等”时用一个极小误差容限 `1e-9`，避免精度误差导致误判。

### 算法分析

1. 读入距离 `d`。
2. 计算 `walk = d / 1.2`，`bike = 50 + d / 3.0`。
3. 若 `|bike - walk| < 1e-9` 输出 `All`；否则若 `bike < walk` 输出 `Bike`；否则输出 `Walk`。

### 参考代码（C++）

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double d;
    cin >> d;
    double walk = d / 1.2;            // 步行耗时（秒）
    double bike = 50 + d / 3.0;       // 骑车固定 50 秒 + 骑行耗时
    if (fabs(bike - walk) < 1e-9) {  // 两者几乎相等
        cout << "All" << endl;
    } else if (bike < walk) {        // 骑车更快
        cout << "Bike" << endl;
    } else {                         // 走路更快
        cout << "Walk" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
