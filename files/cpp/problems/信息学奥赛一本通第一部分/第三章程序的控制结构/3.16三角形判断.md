# 三角形判断

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定三个正整数，分别表示三条线段的长度，判断这三条线段能否构成一个三角形。

## 输入描述

一行，包含三个正整数，分别表示三条线段的长度，数与数之间以一个空格分开。

## 输出描述

如果能构成三角形，则输出“yes”，否则输出“no”。

## 示例

### 用例输入 1

```text
3 4 5
```

### 用例输出 1

```text
yes
```
## 题解

### 解题思路

三条线段能构成三角形的充要条件是：**任意两边之和大于第三边**（等价于“两短边之和大于最长边”）。只要有一个不等式不成立就不能构成三角形。

### 算法分析

1. 读入三条边长 `a`、`b`、`c`。
2. 若 `a + b > c && a + c > b && b + c > a` 输出 `yes`，否则输出 `no`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    // 任意两边之和大于第三边才能构成三角形
    if (a + b > c && a + c > b && b + c > a) {
        cout << "yes" << endl;
    } else {
        cout << "no" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
