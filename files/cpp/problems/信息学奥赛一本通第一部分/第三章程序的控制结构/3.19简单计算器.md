# 简单计算器

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

一个最简单的计算器，支持 $+,−,∗,/+,-,*,/+,−,∗,/$ 四种运算。输入输出为整数，数据和结果不会超过int表示范围。
注意：

1. 如果出现除数为0，输出’Divided by zero!’
2. 如果出现无效操作符(非+,-,*,/)，输出’Invalid operator!’

## 输入描述

输入一行，包含两个整数和一个操作符，用空格分开。例如：1 2 +

## 输出描述

输出一行，一个整数或错误提示信息。

## 示例

### 用例输入 1

```text
1 2 +
```

### 用例输出 1

```text
3
```
## 题解

### 解题思路

先校验输入是否合法，再执行计算，分两类错误：
1. 操作符不是 `+ - * /` 之一 → 输出 `Invalid operator!`；
2. 操作符是 `/` 且除数为 0 → 输出 `Divided by zero!`。

注意这两类错误互不交叉：除号 `/` 本身合法，所以先判断操作符合法性，再判断“除零”即可。两类都不是时才按对应运算符计算并输出整数结果（题目保证数据与结果不超 `int` 范围）。

### 算法分析

1. 读入整数 `a`、`b` 和字符 `op`。
2. 若 `op` 不属于 `{+, -, *, /}`，输出 `Invalid operator!`。
3. 否则若 `op == '/'` 且 `b == 0`，输出 `Divided by zero!`。
4. 否则按 `op` 计算 `a op b` 并输出结果。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    char op;
    cin >> a >> b >> op;

    // 1) 先判断操作符是否合法
    if (op != '+' && op != '-' && op != '*' && op != '/') {
        cout << "Invalid operator!" << endl;
    }
    // 2) 再判断除零（此时 op 一定是合法运算符）
    else if (op == '/' && b == 0) {
        cout << "Divided by zero!" << endl;
    }
    // 3) 正常计算
    else {
        int r;
        if (op == '+') r = a + b;
        else if (op == '-') r = a - b;
        else if (op == '*') r = a * b;
        else r = a / b;          // 整数除法
        cout << r << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
