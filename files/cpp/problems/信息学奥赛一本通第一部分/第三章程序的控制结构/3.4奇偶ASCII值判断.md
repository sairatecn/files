# 奇偶ASCII值判断

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个字符，判断其 ASCII 值是否为奇数：

- 若 ASCII 值为奇数，输出 YES；
- 若 ASCII 值为偶数，输出 NO。

## 输入描述

一行包含一个字符。

## 输出描述

根据 ASCII 值输出对应字符串 YES 或 NO。

## 示例

### 用例输入 1

```text
A
```

### 用例输出 1

```text
YES
```
## 题解

### 解题思路

字符在参与算术运算（如取余 `%`）时会自动提升为它的 ASCII 整数值。因此只需读入字符 `c`，判断 `c % 2` 的奇偶性即可知道其 ASCII 值是奇数还是偶数。

### 算法分析

1. 读入字符 `c`。
2. 若 `c % 2 != 0`（ASCII 值为奇数）输出 `YES`，否则输出 `NO`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    if (c % 2 != 0) {  // c 自动提升为 int，即其 ASCII 值
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
