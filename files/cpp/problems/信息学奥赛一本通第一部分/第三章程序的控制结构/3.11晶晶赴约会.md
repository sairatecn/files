# 晶晶赴约会

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

晶晶的朋友贝贝约晶晶下周一起去看展览，但晶晶每周的1、3、5有课必须上课，请帮晶晶判断她能否接受贝贝的邀请，如果能输出YES；如果不能则输出NO。注意YES和NO都是大写字母！

## 输入描述

输入有一行，贝贝邀请晶晶去看展览的日期，用数字1到7表示从星期一到星期日。

## 输出描述

输出一行，如果晶晶可以接受贝贝的邀请，输出YES，否则输出NO。注意YES和NO都是大写字母！

## 示例

### 用例输入 1

```text
2
```

### 用例输出 1

```text
YES
```
## 题解

### 解题思路

晶晶在星期 1、3、5 有课不能赴约，其余（2、4、6、7）可以。判断邀请日 `d` 是否为 1、3、5 之一即可。

### 算法分析

1. 读入邀请日 `d`（1~7）。
2. 若 `d == 1 || d == 3 || d == 5` 输出 `NO`，否则输出 `YES`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int d;
    cin >> d;
    if (d == 1 || d == 3 || d == 5) {  // 有课的日子
        cout << "NO" << endl;
    } else {
        cout << "YES" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
