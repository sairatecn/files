# 奇偶数判断

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个正整数 $n$ ，判断该数的奇偶性：

- 如果 $n$ 是奇数，输出 odd；
- 如果 $n$ 是偶数，输出 even。

## 输入描述

一行包含一个大于 $0$ 的正整数 $n$ 。

## 输出描述

如果 $n$ 是奇数输出 odd，如果 $n$ 是偶数输出 even。

## 示例

### 用例输入 1

```text
3
```

### 用例输出 1

```text
odd
```
## 题解

### 解题思路

整数对 2 取余，余数为 1（或不为 0）则是奇数，否则为偶数。题目保证 `n > 0`，直接判断 `n % 2` 即可。

### 算法分析

1. 读入正整数 `n`。
2. 若 `n % 2 != 0` 输出 `odd`，否则输出 `even`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 != 0) {  // 不能被 2 整除即为奇数
        cout << "odd" << endl;
    } else {
        cout << "even" << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
