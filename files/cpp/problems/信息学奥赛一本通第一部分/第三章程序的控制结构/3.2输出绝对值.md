# 输出绝对值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个浮点数，计算并输出该浮点数的绝对值，结果保留到小数点后两位。

## 输入描述

一行包含一个浮点数，其绝对值不超过 $10000$ 。

## 输出描述

输出该浮点数的绝对值，保留到小数点后两位。

## 示例

### 用例输入 1

```text
-3.14
```

### 用例输出 1

```text
3.14
```
## 题解

### 解题思路

浮点数取绝对值只需判断正负：负数取相反数即可。结果要求保留两位小数，用 `iomanip` 中的 `fixed` 与 `setprecision(2)` 控制输出格式。

### 算法分析

1. 读入浮点数 `x`。
2. 若 `x < 0` 则令 `x = -x`（取绝对值）。
3. 以定点方式保留两位小数输出 `x`。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x;
    cin >> x;
    if (x < 0) x = -x;                       // 负数取反得到绝对值
    cout << fixed << setprecision(2) << x << endl; // 保留两位小数输出
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$。
- **空间复杂度**：$O(1)$。
