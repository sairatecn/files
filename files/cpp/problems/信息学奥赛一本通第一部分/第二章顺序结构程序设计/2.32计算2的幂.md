# 计算2的幂

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个非负整数 $n$ ，计算并输出 $2n2^n2n$ ，即 $2$ 的 $n$ 次方。

## 输入描述

一行包含一个非负整数 $n$ 。

## 输出描述

输出一个整数，表示 $2n2^n2n$ 的值。

## 示例

### 用例输入 1

```text
3
```

### 用例输出 1

```text
8
```

## 题解

### 解题思路

给定非负整数 n，输出 2ⁿ。

- 若 n 较小（如 n ≤ 62），可用 `1LL << n`（左移运算，等价于 2ⁿ）得到 `long long` 结果，高效且准确。
- 若 n 可能更大（超过 62），则需用 `<cmath>` 的 `pow(2, n)` 或高精度。本题按时限与常规数据规模，用 `long long` 位运算即可。

### 算法分析

- 读入非负整数 `n`。
- 输出 `1LL << n`（`1LL` 是 long long 类型的 1，左移 n 位即 2ⁿ）。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    long long ans;
    cin >> n;
    ans = 1LL << n;   // 等价于 2 的 n 次方
    cout << ans << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)，位运算常数时间。
- 空间复杂度：O(1)。
