# 计算球的体积

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

对于半径为 $r$ 的球，其体积的计算公式为 $V=43πr3V = \frac{4}{3} \pi r^3V=34​πr3$ ，其中 $π=3.14\pi=3.14π=3.14$ 。现给定球的半径 $r$ （double 类型），求球的体积 $V$ ，结果保留两位小数。

## 输入描述

输入为一个非负实数 $r$ ，表示球的半径，类型为 double，且 $r≤100r \le 100r≤100$ 。

## 输出描述

输出一个实数，即球的体积 $V$ ，保留到小数点后 2 位。

## 示例

### 用例输入 1

```text
4.5
```

### 用例输出 1

```text
381.51
```

## 题解

### 解题思路

输入球半径 r（double），按公式 V = 4/3·π·r³ 计算体积，π 取 3.14，保留 2 位小数。

- 注意：`4/3` 是两个整数相除会得到 `1`，必须先写成浮点形式，如 `4.0/3` 或 `4.0/3.0`。
- 验证：`r=4.5` → `4/3·3.14·(4.5)³ = 4.1866…×91.125 ≈ 381.51`。

### 算法分析

- 读入 `double r`。
- 计算 `V = 4.0 / 3 * 3.14 * r * r * r`。
- 输出保留 2 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const double PI = 3.14;
    double r;
    cin >> r;
    double V = 4.0 / 3 * PI * r * r * r;
    cout << fixed << setprecision(2) << V << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
