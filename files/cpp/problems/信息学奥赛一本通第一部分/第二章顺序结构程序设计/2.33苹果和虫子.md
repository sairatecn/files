# 苹果和虫子

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

你买了一箱 $n$ 个苹果，箱子里混进了一条虫子。虫子每 $x$ 小时吃掉一个苹果，且在吃完一个苹果之前不会吃下一个。给定经过 $y$ 小时后，计算还剩下多少个完整的苹果。

## 输入描述

一行包含三个整数 $n,x,y$ ，分别表示苹果数量、虫子吃一个苹果所需时间和经过的总时间。

## 输出描述

输出一个整数，表示剩余的完整苹果个数。

## 示例

### 用例输入 1

```text
10 4 9
```

### 用例输出 1

```text
7
```

## 题解

### 解题思路

有 n 个苹果，虫子每 x 小时吃完一个（吃完前不吃下一个）。经过 y 小时后，求剩余完整苹果数。

- y 小时内虫子吃掉的苹果数 = ⌈y / x⌉（向上取整，因为哪怕只吃了一部分，那个苹果就不完整了）。
- 用整数技巧 `(y + x - 1) / x` 实现向上取整（y、x 均为正整数）。
- 剩余完整苹果 = `n − 吃掉数`，且结果不应为负（若虫子吃完了所有苹果，剩余为 0）。
- 验证：`n=10, x=4, y=9` → 吃掉 `⌈9/4⌉ = 3` 个 → 剩余 `10−3 = 7`。

### 算法分析

- 读入整数 `n, x, y`。
- 计算吃掉数 `eaten = (y + x - 1) / x`，剩余 `rem = n - eaten`。
- 若 `rem < 0` 则输出 `0`，否则输出 `rem`；或直接与 `0` 取大值。

### 参考代码（C++）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n, x, y;
    cin >> n >> x >> y;
    int eaten = (y + x - 1) / x;     // 向上取整求吃掉个数
    int rem = max(0, n - eaten);     // 剩余不能为负
    cout << rem << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
