# 保留3位小数的浮点数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

读入一个单精度浮点数，保留3位小数输出这个浮点数。

## 输入描述

只有一行，一个单精度浮点数。

## 输出描述

也只有一行，读入的单精度浮点数。

## 示例

### 用例输入 1

```text
12.34521
```

### 用例输出 1

```text
12.345
```

## 题解

### 解题思路

读入一个单精度浮点数，保留 3 位小数后输出（四舍五入到第 3 位）。

- 用 `fixed << setprecision(3)` 控制小数位数。
- 验证：`12.34521 → 12.345`。

### 算法分析

- 读入 `float f`。
- 用 `cout << fixed << setprecision(3) << f << endl;` 输出。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    float f;
    cin >> f;
    cout << fixed << setprecision(3) << f << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
