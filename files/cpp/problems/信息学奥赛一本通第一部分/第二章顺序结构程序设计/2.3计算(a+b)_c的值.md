# 计算(a+b)/c的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定 $3$ 个整数 $a、b、c$ ，计算表达式 $(a+b)÷c$ 的值。

## 输入描述

输入仅一行，包括三个整数 $a、b、c$ , 数与数之间以一个空格分开。
$－10,000<a,b,c<10,000$
$c$ 不等于 $0$ 。

## 输出描述

输出一行，即表达式的值，保留小数点后两位。

## 示例

### 用例输入 1

```text
1 1 3
```

### 用例输出 1

```text
0.67
```

## 题解

### 解题思路

读入三个整数 a、b、c（c≠0），计算 (a+b)/c 并保留小数点后两位输出。

- 关键陷阱：a、b、c 都是整数，`a + b` 是整数，若直接写 `(a+b)/c` 会做整数除法（截断小数部分）。
- 必须先把分子转为浮点数（乘 `1.0` 或强制转换为 `double`）再做除法，得到双精度结果，最后用 `fixed << setprecision(2)` 控制两位小数。
- 验证：输入 `1 1 3` → (1+1)/3 = 0.666… → 保留两位为 `0.67`。

### 算法分析

- 读入 a、b、c。
- 用 `(a + b) * 1.0 / c` 进行浮点除法。
- 输出保留两位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    double ans = (a + b) * 1.0 / c;
    cout << fixed << setprecision(2) << ans << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
