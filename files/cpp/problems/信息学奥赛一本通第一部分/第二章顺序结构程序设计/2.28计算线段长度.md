# 计算线段长度

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知线段的两个端点的坐标 $A(Xa,Ya)A(X_a, Y_a)A(Xa​,Ya​)$ 和 $B(Xb,Yb)B(X_b, Y_b)B(Xb​,Yb​)$ ，求线段 $AB$ 的长度，保留到小数点后 3 位。

## 输入描述

第一行是两个实数 $Xa,YaX_a, Y_aXa​,Ya​$ ，表示点 A 的坐标。
第二行是两个实数 $Xb,YbX_b, Y_bXb​,Yb​$ ，表示点 B 的坐标。
输入中所有实数的绝对值均不超过 10000。

## 输出描述

一个实数，即线段 $AB$ 的长度，保留到小数点后 3 位。

## 示例

### 用例输入 1

```text
1 1
2 2
```

### 用例输出 1

```text
1.414
```

## 题解

### 解题思路

已知两点 A(Xa, Ya)、B(Xb, Yb)，求线段 AB 长度（保留 3 位小数）。

- 由两点间距离公式：`len = √[(Xb−Xa)² + (Yb−Ya)²]`。
- 用 `<cmath>` 中的 `sqrt` 函数开平方。
- 验证：`(1,1)`、`(2,2)` → `√2 ≈ 1.414`。

### 算法分析

- 读入两行四个 `double` 坐标。
- 计算横坐标差、纵坐标差，套用距离公式。
- 输出保留 3 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    double xa, ya, xb, yb;
    cin >> xa >> ya >> xb >> yb;
    double dx = xb - xa;
    double dy = yb - ya;
    double len = sqrt(dx * dx + dy * dy);
    cout << fixed << setprecision(3) << len << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)，一次开方运算。
- 空间复杂度：O(1)。
