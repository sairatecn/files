# 字符菱形

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个字符，用它构造一个对角线长5个字符，倾斜放置的菱形。

## 输入描述

输入只有一行， 包含一个字符。

## 输出描述

该字符构成的菱形。

## 示例

### 用例输入 1

```text
*
```

### 用例输出 1

```text
  *
 ***
*****
 ***
  *
```

## 题解

### 解题思路

给定一个字符，构造对角线长 5、即 5 行的菱形。

- 以 `*` 为例，图形为：
```
  *
 ***
*****
 ***
  *
```
- 各行规律：第 1、2、3 行空格数依次为 2、1、0，字符数依次为 1、3、5（上半部分）；第 4、5 行空格数 1、2，字符数 3、1（下半部分）。
- 图形固定 5 行，可直接按行输出，也可用循环按"空格 = |3−i|、字符 = 2i−1"（i 为 1~5 行号）的规律生成。

### 算法分析

- 读入字符 `c`。
- 直接分 5 行输出对应空格与字符的组合（写法一）；或用循环按行号规律生成（写法二）。

### 参考代码（C++）

**写法一：直接输出**

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    cout << "  " << c << endl;
    cout << " " << c << c << c << endl;
    cout << c << c << c << c << c << endl;
    cout << " " << c << c << c << endl;
    cout << "  " << c << endl;
    return 0;
}
```

**写法二：循环构造**

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    for (int i = 1; i <= 5; i++) {
        int space = (i <= 3) ? (3 - i) : (i - 3);          // 上下对称
        int star  = (i <= 3) ? (2 * i - 1) : (2 * (6 - i) - 1);
        for (int j = 1; j <= space; j++) cout << ' ';
        for (int j = 1; j <= star;  j++) cout << c;
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)，固定 5 行、每行最多 5 个字符。
- 空间复杂度：O(1)。
