# A×B问题

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定两个正整数 $A$ 和 $B$ ，计算并输出它们的乘积 $A×BA\times BA×B$ 。注意乘积可能较大，需要选择合适的数据类型。

## 输入描述

一行包含两个正整数 $A,B$ ，中间用一个空格分隔。

## 输出描述

输出一个整数，表示 $A×BA\times BA×B$ 的值。

## 示例

### 用例输入 1

```text
3 4
```

### 用例输出 1

```text
12
```

## 题解

### 解题思路

计算两个正整数 A、B 的乘积，结果可能很大，需选择合适的数据类型。

- 若 A、B 达到 10⁹ 量级，乘积可达 10¹⁸，超过 `int` 范围（约 ±2.1×10⁹）。
- 应使用 64 位整数 `long long`（范围约 ±9.2×10¹⁸）来存放乘积，避免溢出。

### 算法分析

- 读入 `long long A, B`。
- 输出 `A * B`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    long long A, B;
    cin >> A >> B;
    cout << A * B << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
