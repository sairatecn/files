# A+B问题

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

大部分的在线题库，都会将A+B问题作为第一题，以帮助新手熟悉平台的使用方法。
A+B问题的题目描述如下：给定两个整数A和B，输出A+B的值。保证A、B及结果均在整型范围内。现在请你解决这一问题。

## 输入描述

一行，包含两个整数A，B，中间用单个空格隔开。A和B均在整型范围内。

## 输出描述

一个整数，即A+B的值。保证结果在整型范围内。

## 示例

### 用例输入 1

```text
1 2
```

### 用例输出 1

```text
3
```

## 题解

### 解题思路

这是最基础的输入/输出与加法运算题。读入两个整数 A、B，计算并输出它们的和 A+B。题目保证 A、B 及结果均在 `int`（32 位有符号整数）范围内，因此使用 `int` 类型存储并计算即可。

### 算法分析

- 使用 `cin` 连续读入两个整数 A 和 B（空格分隔，`cin` 会自动跳过空白符）。
- 用 `+` 运算符求和，用 `cout` 输出结果。
- 全程仅一次加法与一次输出，无分支、无循环。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int A, B;
    cin >> A >> B;
    cout << A + B << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)，仅一次读入和一次加法。
- 空间复杂度：O(1)，使用两个 `int` 变量。
