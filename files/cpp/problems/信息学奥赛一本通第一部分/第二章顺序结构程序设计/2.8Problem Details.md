# Problem Details

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

利用公式

$C=5×(F−32)÷9$

(其中 $C$ 表示摄氏温度， $F$ 表示华氏温度)进行计算转化,输入华氏温度 $F$ ，输出摄氏温度 $C$ ，要求精确到小数点后
$5$ 位。

## 输入描述

输入一行，包含一个实数 $F$ ，表示华氏温度。（ $F≥−459.67$ ）

## 输出描述

输出一行，包含一个实数，表示对应的摄氏温度，要求精确到小数点后 $5$ 位。

## 示例

### 用例输入 1

```text
297.63706
```

### 用例输出 1

```text
147.57614
```

## 题解

### 解题思路

（本题文件名虽为 "Problem Details"，实质为"华氏温度转摄氏温度"。）

输入华氏温度 F，按公式 C = 5×(F−32)÷9 转换为摄氏温度，精确到小数点后 5 位。

- 公式本质是浮点运算，为保证精度建议显式用浮点除法：`5.0 * (F - 32) / 9`。
- 验证：`F=297.63706` → `5*(265.63706)/9 = 147.57614`。

### 算法分析

- 读入 `double F`。
- 计算 `5.0 * (F - 32) / 9`。
- 输出保留 5 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double F;
    cin >> F;
    double C = 5.0 * (F - 32) / 9;
    cout << fixed << setprecision(5) << C << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
