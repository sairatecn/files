# 计算并联电阻的阻值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

对于阻值为 $r1r_1r1​$ 和 $r2r_2r2​$ 的电阻，其并联电阻阻值公式计算如下：

$R=11r1+1r2R=\frac{1}{\frac{1}{r_1}+\frac{1}{r_2}}R=r1​1​+r2​1​1​$

输入两个电阻阻抗大小，浮点型。输出并联之后的阻抗大小，结果保留小数点后 $2$ 位。

## 输入描述

两个电阻阻抗大小，浮点型，以一个空格分开。

## 输出描述

并联之后的阻抗大小，结果保留小数点后 $2$ 位。

## 示例

### 用例输入 1

```text
1 2
```

### 用例输出 1

```text
0.67
```

## 题解

### 解题思路

输入两个电阻 R1、R2（浮点型），按公式 R = 1 / (1/R1 + 1/R2) 计算并联阻值，保留 2 位小数。

- 公式可化简为 R = R1×R2 / (R1 + R2)，避免嵌套倒数带来的精度/溢出风险，也更直观。
- 验证：`R1=1, R2=2` → `2 / 3 ≈ 0.6667` → `0.67`。

### 算法分析

- 读入 `double r1, r2`。
- 计算 `r1 * r2 / (r1 + r2)`。
- 输出保留 2 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double r1, r2;
    cin >> r1 >> r2;
    double R = r1 * r2 / (r1 + r2);
    cout << fixed << setprecision(2) << R << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
