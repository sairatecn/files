# 保留12位小数的浮点数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

读入一个双精度浮点数，保留12位小数，输出这个浮点数。

## 输入描述

只有一行，一个双精度浮点数。

## 输出描述

也只有一行，保留12位小数的浮点数。

## 示例

### 用例输入 1

```text
3.1415926535798932
```

### 用例输出 1

```text
3.141592653580
```

## 题解

### 解题思路

读入一个双精度浮点数，保留 12 位小数后输出。

- `double` 约有 15~16 位有效数字，保留 12 位小数在精度范围内是安全的。
- 用 `fixed << setprecision(12)` 输出。
- 验证：`3.1415926535798932 → 3.141592653580`（第 12 位小数四舍五入）。

### 算法分析

- 读入 `double d`。
- 输出保留 12 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double d;
    cin >> d;
    cout << fixed << setprecision(12) << d << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
