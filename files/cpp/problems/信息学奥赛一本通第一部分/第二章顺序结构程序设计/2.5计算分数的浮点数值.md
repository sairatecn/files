# 计算分数的浮点数值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

两个整数 $a$ 和 $b$ 分别作为分子和分母，既分数 $ab\frac{a}{b}ba​$ ，求它的浮点数值(双精度浮点数，保留小数点后 $9$ 位)。

## 输入描述

输入仅一行，包括两个整数 $a$ 和 $b$ 。

## 输出描述

输出也仅一行，分数 $ab\frac{a}{b}ba​$ 的浮点数值（双精度浮点数，保留小数点后9位）。

## 示例

### 用例输入 1

```text
5 7
```

### 用例输出 1

```text
0.714285714
```

## 题解

### 解题思路

给定整数 a（分子）和 b（分母），求 a/b 的浮点数值，保留小数点后 9 位。

- 同样要避免整数除法：将 a 或 b 先转为 `double` 再做除法。
- 用 `fixed << setprecision(9)` 输出 9 位小数。
- 验证：`5 / 7 = 0.714285714…` → `0.714285714`。

### 算法分析

- 读入 a、b。
- 计算 `(double)a / b`（或 `a * 1.0 / b`）。
- 输出保留 9 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    double ans = (double)a / b;
    cout << fixed << setprecision(9) << ans << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
