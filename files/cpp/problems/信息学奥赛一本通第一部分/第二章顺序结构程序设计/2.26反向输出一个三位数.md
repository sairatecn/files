# 反向输出一个三位数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个三位数 $n$ ，将其数字反向输出。例如输入 358，输出 853。

## 输入描述

一个三位整数 $n$ 。

## 输出描述

输出整数 $n$ 的数字反向后的结果。

## 示例

### 用例输入 1

```text
358
```

### 用例输出 1

```text
853
```

## 题解

### 解题思路

给定一个三位数 n，将其数字反向输出（如 358 → 853），在同一行输出逆序整数。

- 分别取出百位、十位、个位：`bai = n/100`、`shi = n/10%10`、`ge = n%10`。
- 逆序整数 = `ge*100 + shi*10 + bai`。

### 算法分析

- 读入整数 `n`。
- 拆分各位后重组输出。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int bai = n / 100;
    int shi = n / 10 % 10;
    int ge  = n % 10;
    cout << ge * 100 + shi * 10 + bai << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
