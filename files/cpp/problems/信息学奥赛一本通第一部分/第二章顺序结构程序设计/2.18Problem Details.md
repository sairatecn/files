# Problem Details

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

我们曾经输出过的“Hello, World!”吗？它虽然不是本章所涉及的基本数据类型的数据，但我们同样可以用sizeof函数获得它所占用的空间大小。

## 输入描述

无

## 输出描述

一个整数，即`Hello, World!`的大小。

## 题解

### 解题思路

（本题文件名虽为 "Problem Details"，实质为"求字符串字面量 `Hello, World!` 所占字节数"。）

- 字符串字面量在 C++ 中以字符数组形式存储，并在末尾自动追加一个空字符 `\0` 作为结束标志。
- `"Hello, World!"` 共有 13 个可见字符（H e l l o , 空格 W o r l d !），加上结尾的 `\0`，共 **14 字节**。
- 用 `sizeof("Hello, World!")` 即可直接得到该值（注意 `sizeof` 在编译期求值且结果含 `\0`；不要用 `strlen`，那是运行期函数且不含 `\0`）。

### 算法分析

- 直接输出 `sizeof("Hello, World!")`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof("Hello, World!") << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)，`sizeof` 为编译期常量。
- 空间复杂度：O(1)。
