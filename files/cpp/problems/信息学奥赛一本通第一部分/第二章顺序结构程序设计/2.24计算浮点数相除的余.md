# 计算浮点数相除的余

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

计算两个双精度浮点数 $a$ 和 $b$ 的相除余数 $r$ ，满足 $a=k×b+ra = k \times b + ra=k×b+r$ ，其中 $k$ 为整数，且 $0≤r<b0 \le r < b0≤r<b$ 。

## 输入描述

输入仅一行，包括两个双精度浮点数 $a$ 和 $b$ ，以空格分隔。

## 输出描述

输出也仅一行， $a÷ba \div ba÷b$ 的余数，保留四位小数。

## 示例

### 用例输入 1

```text
73.263 0.9973
```

### 用例输出 1

```text
0.4601
```

## 题解

### 解题思路

给定双精度 a、b，求 a÷b 的余数 r，满足 a = k×b + r（k 为整数，0 ≤ r < b）。

- 这正是浮点取余运算，C/C++ 在 `<cmath>` 中提供 `fmod(a, b)` 函数，返回 a − ⌊a/b⌋×b，结果绝对值小于 |b|，符合题目要求。
- 结果保留 4 位小数。
- 验证：`73.263 / 0.9973` 的整数部分为 73，`r = 73.263 − 73×0.9973 = 73.263 − 72.8029 = 0.4601`。

### 算法分析

- 读入 `double a, b`。
- 用 `fmod(a, b)` 求余。
- 输出保留 4 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    double a, b;
    cin >> a >> b;
    double r = fmod(a, b);
    cout << fixed << setprecision(4) << r << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
