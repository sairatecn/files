# 其他数据类型存储空间大小

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

分别定义bool，char类型的变量各一个，并依次输出它们的存储空间大小(单位：字节)。

## 输入描述

（无）

## 输出描述

一行，两个整数，分别是两个变量的存储空间大小，用一个空格隔开。

## 题解

### 解题思路

分别定义 `bool`、`char` 类型的变量各一个，依次输出所占字节数。

- `bool` 占 1 字节，`char` 占 1 字节。

### 算法分析

- 定义 `bool a; char b;`。
- 输出 `sizeof(a)` 与 `sizeof(b)`，空格分隔。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    bool a;
    char b;
    cout << sizeof(a) << " " << sizeof(b) << endl;
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
