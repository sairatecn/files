# 地球人口承载力估计

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

假设地球上的新生资源按恒定速度增长。照此测算，地球上现有资源加上新生资源可供 $x$ 亿人生活 $a$ 年，或供 $y$ 亿人生活 $b$ 年。
为了能够实现可持续发展，避免资源枯竭，地球最多能够养活多少亿人？

## 输入描述

一行，包括四个正整数 $x，a，y，b$ ，两个整数之间用单个空格隔开。 $x>y，a<b，ax<by$ ，各整数均不大于10000.

## 输出描述

一个实数 $z$ ，表示地球最多养活 $z$ 亿人，舍入到小数点后两位。

## 示例

### 用例输入 1

```text
110 90 90 210
```

### 用例输出 1

```text
75.00
```

## 题解

### 解题思路

这是一道**数学建模**题：用代数方法求出地球资源能支撑的最大人口数。

设地球现有资源总量为 S，每年新生资源（可供 1 亿人消耗 1 年）的增长速度为 v 亿/年，每人每年消耗 1 个单位资源。

根据题意：
- 供 x 亿人生活 a 年：$S + v \cdot a = x \cdot a$（现有资源 + a 年新生的资源 = 总消耗量）
- 供 y 亿人生活 b 年：$S + v \cdot b = y \cdot b$

两式相减消去 S，得：

$$v \cdot (b - a) = y \cdot b - x \cdot a$$
$$v = \frac{yb - xa}{b - a}$$

当人口数 z 恰好等于资源年增长率 v 时，每年新生的资源刚好够当年消耗，现有资源 S 永不减少，人类可以无限期生存——这时的 z 就是"最多养活"的人数，即 $z = v = \dfrac{yb - xa}{b - a}$。

验证样例：x=110, a=90, y=90, b=210

$$z = \frac{90 \times 210 - 110 \times 90}{210 - 90} = \frac{18900 - 9900}{120} = \frac{9000}{120} = 75.00$$

与样例输出一致。

注意：
1. 题目保证 `x > y, a < b, ax < by`，所以分子、分母均为正，z 恒为正。
2. 运算结果可能是小数，必须用 `double` 存储，并输出到小数点后两位。
3. 各整数均不大于 10000，中间结果（如 10000 × 10000 = 10^8）虽不超出 `int` 范围，但用 `double` 参与除法可避免整数除法丢精度。

### 算法分析

- 读入 4 个整数 x, a, y, b。
- 按公式 $z = \dfrac{yb - xa}{b - a}$ 计算，注意先算乘法再除，保证精度。
- 用 `cout << fixed << setprecision(2)`（或 `printf("%.2f", z)`）保留两位小数输出。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>   // 使用 fixed 和 setprecision 需要此头文件
using namespace std;

int main() {
    int x, a, y, b;
    cin >> x >> a >> y >> b;
    double z = (double)(y * b - x * a) / (b - a); // 转换为 double 做除法，防止整数除法丢精度
    cout << fixed << setprecision(2) << z << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(1)，仅一次读入和一次四则运算。
- **空间复杂度**：O(1)，仅使用 4 个整型变量和 1 个浮点变量。
