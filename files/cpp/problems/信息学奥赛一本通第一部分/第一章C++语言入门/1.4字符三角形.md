# 字符三角形

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个字符，用它构造一个底边长5个字符，高3个字符的等腰字符三角形。

## 输入描述

输入只有一行，包含一个字符。

## 输出描述

该字符构成的等腰三角形，底边长5个字符，高3个字符。

## 示例

### 用例输入 1

```text
*
```

### 用例输出 1

```text
*
***
*****
```

## 题解

### 解题思路

题目给定一个字符，要求构造**高 3 行、底边 5 个字符**的等腰三角形。

先观察目标图形（以 `*` 为例）：

```text
  *
 ***
*****
```

每一行的规律是：**若干个空格 + 若干个字符**。
- 第 1 行：2 个空格 + 1 个字符
- 第 2 行：1 个空格 + 3 个字符
- 第 3 行：0 个空格 + 5 个字符

即第 i 行（i 从 1 开始）的空格数为 `3 - i`，字符数为 `2 * i - 1`，恰好构成以第 3 行为底边的等腰三角形。

实现方式：
1. **直接输出法（最简洁）**：把三行内容写死，用 `cout` 分三次输出，适合本题这种固定 3 行的小图形。
2. **循环构造法（可推广）**：用双重循环按行打印空格和字符，便于推广到任意高度。

本题图形固定，直接输出即可；但建议初学者理解"行号、空格数、字符数"之间的数学关系，这是后续打印各类图形的通用思路。

### 算法分析

- 读入一个 `char` 类型字符。
- 按 3 行输出：每行先输出 `3 - i` 个空格，再输出 `2 * i - 1` 个字符，行末换行。
- 直接输出版无需循环；循环版执行 3 次行循环，每次内部输出固定数量的字符。

### 参考代码（C++）

**写法一：直接输出**

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    cout << "  " << c << endl;                 // 2个空格 + 1个字符
    cout << " " << c << c << c << endl;        // 1个空格 + 3个字符
    cout << c << c << c << c << c << endl;     // 5个字符
    return 0;
}
```

**写法二：循环构造（推荐，便于推广）**

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    for (int i = 1; i <= 3; i++) {            // i 为行号，从 1 到 3
        for (int j = 1; j <= 3 - i; j++)      // 输出 3-i 个空格
            cout << ' ';
        for (int j = 1; j <= 2 * i - 1; j++)  // 输出 2*i-1 个字符
            cout << c;
        cout << endl;                         // 每行末尾换行
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(1)，图形只有固定的 3 行 5 列，输出字符总数恒为 9，与输入无关。
- **空间复杂度**：O(1)，仅使用一个 `char` 变量。
