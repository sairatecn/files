# Hello,World!

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

编写一个能够输出“Hello,World!”的程序，这个程序常常作为一个初学者接触一门新的编程语言所写的第一个程序，也经常用来测试开发、编译环境是否能够正常工作。

提示：“Hello,World!”中间没空格。

## 输入描述

无

## 输出描述

Hello,World!

## 示例

### 用例输入 1

```text

```

### 用例输出 1

```text
Hello,World!
```

## 题解

### 解题思路

这是学习任何一门编程语言的"第一课"：程序的任务极其简单——把字符串 `Hello,World!` 原样输出到屏幕。

关键注意点：
1. **大小写与标点必须完全一致**：`Hello,World!` 中 H 和 W 是大写，中间只有一个英文逗号、没有空格，结尾是英文感叹号。
2. **字符串要用双引号括起来**：C++ 中字符串字面量用双引号（`"..."`），单个字符用单引号（`'...'`），二者不能混用。
3. **输出后换行**：`endl` 会输出换行，使输出格式更规范。

本题不需要任何输入，也不涉及任何运算，是验证编译环境与"输出"这一基础操作是否正常的试金石。

### 算法分析

- 直接使用 C++ 标准输出流 `cout`，配合 `endl` 输出一行文本。
- 程序结构固定：头文件 `#include <iostream>`（提供输入输出流）、`using namespace std;`（简化命名空间写法）、`main` 主函数（程序入口）。
- 全程只有一次输出操作，无分支、无循环、无变量定义。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello,World!" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(1)，只有一次输出操作。
- **空间复杂度**：O(1)，未定义任何变量，不占用额外内存。
