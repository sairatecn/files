# 对齐输出

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

读入三个整数，按每个整数占8个字符的宽度，右对齐输出它们，按照格式要求依次输出三个整数，之间以一个空格分开。

## 输入描述

只有一行，包含三个整数，整数之间以一个空格分开。

## 输出描述

只有一行，按照格式要求依次输出三个整数，之间以一个空格分开。

## 示例

### 用例输入 1

```text
2469 3109 1416
```

### 用例输出 1

```text
2469     3109     1416
```

## 题解

### 解题思路

题目要求把三个整数按**每个占 8 个字符宽度、右对齐**输出，且相邻整数之间以一个空格分隔。

关键点在于"域宽 + 右对齐"的控制：
- C++ 风格：使用 `setw(8)`（需包含头文件 `<iomanip>`）设置输出域宽，`cout` 默认右对齐，正好符合要求。
- C 风格：`printf("%8d", n)` 中的 `%8d` 表示按 8 位宽度右对齐输出整数，不足 8 位时左侧补空格，超过 8 位则按实际位数输出。

注意点：
1. `setw` 只对紧随其后的**一个**输出项生效，所以每个整数前都要写一次 `setw(8)`。
2. 空格分隔：在两组数之间输出一个空格，注意是"数值间的空格"，而不是把空格也纳入域宽。
3. 观察样例 `2469     3109     1416`：2469 是 4 位数，占 8 位宽度需要左侧补 4 个空格，再与下一个数之间隔 1 个空格，共 5 个空格——恰好验证了"域宽 8 + 空格分隔"的格式。

### 算法分析

- 读入 3 个 `int` 变量。
- 使用 `setw(8)` + `cout`（默认右对齐）依次输出，数值间用一个空格分隔，行末换行。
- 整个程序只执行固定的输入输出指令，无循环、无判断。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>   // 使用 setw 需要此头文件
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    cout << setw(8) << a << ' '
         << setw(8) << b << ' '
         << setw(8) << c << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(1)，仅对固定数量的 3 个整数做输入输出。
- **空间复杂度**：O(1)，仅使用 3 个 `int` 变量。
