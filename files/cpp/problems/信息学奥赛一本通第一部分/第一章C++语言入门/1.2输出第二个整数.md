# 输出第二个整数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入三个整数，整数之间由一个空格分隔，整数是32位有符号整数。把第二个输入的整数输出。

## 输入描述

只有一行，共三个整数，整数之间由一个空格分隔。整数是32位有符号整数。

## 输出描述

只有一行，一个整数，即输入的第二个整数。

## 示例

### 用例输入 1

```text
506 3641 4431
```

### 用例输出 1

```text
3641
```

## 题解

### 解题思路

题目要求输入三个整数，并输出**第二个**整数。核心在于正确、有序地读取数据，然后只输出中间那个。

两种常见做法：
1. **定义三个变量**：用 `cin >> a >> b >> c;` 一次性读入，然后输出 `b`，思路直观、代码清晰。
2. **只保留中间值**：读入第一个数（丢弃）、第二个数（保留）、第三个数（丢弃），最后输出保留的值，可少定义一个变量。

需要注意：
- 整数是 32 位有符号整数，范围约为 ±21 亿，恰好落在 C++ 的 `int`（4 字节）范围内，用 `int` 即可。
- 三个数在同一行、以空格分隔，`cin` 会自动跳过空格和换行，直接连续读取即可，无需手动处理分隔符。

### 算法分析

- 使用 `cin` 连续读入 3 个 `int` 类型的值。
- 使用 `cout` 输出第二个变量的值。
- 输入输出是本题全部工作，不涉及任何计算、判断或循环。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;      // 依次读入三个整数
    cout << b << endl;       // 输出第二个整数
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(1)，读入 3 个数并输出 1 个数，操作次数与数据规模无关。
- **空间复杂度**：O(1)，仅使用 3 个 `int` 变量，占用固定内存。
