# 乘方计算

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个整数 $a$ 和一个正整数 $n$ ，计算乘方 $ana^nan$ 。题目保证最终结果的绝对值不超过 $1000000$ 。

## 输入描述

输入一行，包含两个整数 $a$ 和 $n$ ，其中 $−1000000≤a≤1000000-1000000 \le a \le 1000000−1000000≤a≤1000000$ ， $1≤n≤100001 \le n \le 100001≤n≤10000$ 。

## 输出描述

输出一个整数，表示乘方 $ana^nan$ 的结果。

## 示例

### 用例输入 1

```text
2 3
```

### 用例输出 1

```text
8
```

---

## 题解

### 解题思路

计算 $a^n$，即 $a$ 自乘 $n$ 次。用循环实现累乘即可。题目保证结果绝对值不超过 $1000000$，使用 `long long` 可避免中间溢出。

### 算法分析

1. 读入 $a$ 和 $n$。
2. 定义 `long long result = 1`，循环 $n$ 次每次 `result *= a`。
3. 输出 `result`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a;
    int n;
    cin >> a >> n;
    long long result = 1;
    for (int i = 0; i < n; i++) {
        result *= a;
    }
    cout << result << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
