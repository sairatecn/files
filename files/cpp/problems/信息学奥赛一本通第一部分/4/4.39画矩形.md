# 画矩形

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

根据输入的参数绘制矩形。输入四个参数：前两个为整数，分别表示矩形的高度 $H$ 和宽度 $W$ （ $3≤H≤103 \le H \le 103≤H≤10$ ， $5≤W≤105 \le W \le 105≤W≤10$ ）；第三个参数为字符 $C$ ，表示绘制矩形的符号；第四个参数为 $F$ ，1表示实心矩形，0表示空心矩形。

## 输入描述

一行输入四个参数： $H$ $W$ $C$ $F$ ，以空格隔开。

## 输出描述

根据参数绘制矩形，每行输出对应的字符行。

## 示例

### 用例输入 1

```text
7 7 @ 0
```

### 用例输出 1

```text
@@@@@@@
@     @
@     @
@     @
@     @
@     @
@@@@@@@
```

---

## 题解

### 解题思路

用嵌套循环输出矩形。若 $F=1$（实心），每行全部输出字符 $C$；若 $F=0$（空心），仅第一行、最后一行、每行的第一个和最后一个字符为 $C$，中间为空格。

### 算法分析

1. 读入 $H, W, C, F$。
2. 外层循环 $H$ 行，内层循环 $W$ 列：
   - 若 $F=1$，每格输出 $C$。
   - 若 $F=0$，首末行或首末列输出 $C$，否则输出空格。
3. 每行结束输出换行。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int H, W, F;
    char C;
    cin >> H >> W >> C >> F;
    for (int i = 0; i < H; i++) {
        for (int j = 0; j < W; j++) {
            if (F == 1) {
                cout << C;
            } else {
                if (i == 0 || i == H - 1 || j == 0 || j == W - 1)
                    cout << C;
                else
                    cout << ' ';
            }
        }
        cout << endl;
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(H \times W)$。
- **空间复杂度**：$O(1)$。
