# 正常血压

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

监护室每小时测量一次病人的血压，若收缩压在 $90−14090-14090−140$ 之间且舒张压在 $60−9060-9060−90$ 之间(包含端点)，则为正常。求连续正常血压的最长小时数。

## 输入描述

第一行一个正整数 $n$ ，表示测量次数。
接下来的 $n$ 行，每行两个正整数 $s$ 和 $d$ ，分别表示一次测量的收缩压和舒张压。

## 输出描述

一行一个整数，表示病人连续保持正常血压的最长小时数。

## 示例

### 用例输入 1

```text
4
100 80
90 50
120 60
140 90
```

### 用例输出 1

```text
2
```

---

## 题解

### 解题思路

维护一个"当前连续正常次数"和一个"历史最大连续正常次数"。每次测量判断是否血压正常：若正常则当前计数 +1 并更新最大值；若不正常则当前计数归零。

### 算法分析

1. 读入 $n$。
2. 定义 `current = 0, maxLen = 0`。
3. 循环 $n$ 次，每次读入收缩压 $s$ 和舒张压 $d$。
4. 若 $90 \le s \le 140$ 且 $60 \le d \le 90$，则 `current++`，`maxLen = max(maxLen, current)`；否则 `current = 0`。
5. 输出 `maxLen`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int current = 0, maxLen = 0;
    for (int i = 0; i < n; i++) {
        int s, d;
        cin >> s >> d;
        if (s >= 90 && s <= 140 && d >= 60 && d <= 90) {
            current++;
            if (current > maxLen) maxLen = current;
        } else {
            current = 0;
        }
    }
    cout << maxLen << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
