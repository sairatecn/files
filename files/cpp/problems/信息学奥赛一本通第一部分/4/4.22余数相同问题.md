# 余数相同问题

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知三个正整数 $a,b,ca, b, ca,b,c$ 。寻找大于1的整数 $x$ ，使 $amodx=bmodx=cmodxa \bmod x = b \bmod x = c \bmod xamodx=bmodx=cmodx$ 。求满足条件的最小 $x$ ，题目保证有解。

## 输入描述

输入一行，包含三个正整数 $a,b,ca, b, ca,b,c$ $(≤1000000)(\le 1000000)(≤1000000)$ ，用空格隔开。

## 输出描述

输出一个整数，为满足条件的最小 $x$ 。

## 示例

### 用例输入 1

```text
300 262 205
```

### 用例输出 1

```text
19
```

---

## 题解

### 解题思路

若 $a \bmod x = b \bmod x = c \bmod x$，则 $(a-b)$ 和 $(b-c)$ 都能被 $x$ 整除，即 $x$ 是 $(a-b)$ 和 $(b-c)$ 的公因子。从 $x = 2$ 开始逐个尝试，找到第一个满足条件的即可。

### 算法分析

1. 读入 $a, b, c$。
2. 从 $x = 2$ 开始递增，检查 `a % x == b % x && b % x == c % x`。
3. 找到第一个满足条件的 $x$ 即输出。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    for (int x = 2; ; x++) {
        if (a % x == b % x && b % x == c % x) {
            cout << x << endl;
            return 0;
        }
    }
}
```

### 复杂度分析

- **时间复杂度**：$O(x)$，$x$ 为答案值，通常很小。
- **空间复杂度**：$O(1)$。
