# 求平均年龄

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

班上有若干名学生，给出每名学生的年龄（整数），求班上所有学生的平均年龄，保留到小数点后两位。

## 输入描述

第一行有一个整数 $n$ ( $1≤n≤1001 \le n \le 1001≤n≤100$ )，表示学生的人数。其后 $n$ 行，每行有一个整数，表示每个学生的年龄，取值为 $15$ 到 $25$ 。

## 输出描述

一行，包含一个浮点数，为要求的平均年龄，保留到小数点后两位。

## 示例

### 用例输入 1

```text
4
17
18
16
19
```

### 用例输出 1

```text
17.50
```

---

## 题解

### 解题思路

求平均年龄是最基础的循环累加问题。读入 $n$ 个学生的年龄，用循环将所有年龄累加到一个变量中，最后除以人数 $n$ 即可。注意除法需要使用浮点除法，输出保留两位小数。

### 算法分析

1. 读入 $n$。
2. 定义 `sum = 0`，循环 $n$ 次，每次读入一个年龄并累加。
3. 计算 `sum / n`（浮点除法），用 `printf("%.2f", ...)` 或 `fixed << setprecision(2)` 输出。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        int age;
        cin >> age;
        sum += age;
    }
    cout << fixed << setprecision(2) << (double)sum / n << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，循环 $n$ 次。
- **空间复杂度**：$O(1)$。
