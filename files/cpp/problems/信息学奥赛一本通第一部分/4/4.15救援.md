# 救援

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

救生船从大本营出发营救屋顶上的人：

- 船速度 $50$ 米/分钟。
- 每人上船 $1$ 分钟。
- 每人下船 $0.5$ 分钟。
- 每次从大本营出发，救下屋顶所有人后返回大本营。
- 求所有人到达大本营所需的总时间。

## 输入描述

- 第一行：整数 $n$ ，屋顶数。
- 接下来 $n$ 行，每行三个数：屋顶 $x$ 坐标、 $y$ 坐标（单位米）、人数。

## 输出描述

- 救援总时间（分钟），向上取整）。

## 示例

### 用例输入 1

```text
1
30 40 3
```

### 用例输出 1

```text
7
```

---

## 题解

### 解题思路

对于每个屋顶，船需要：往返行驶距离（$2 \times \sqrt{x^2+y^2}$）÷ 速度 + 上船时间（人数 × 1）+ 下船时间（人数 × 0.5）。将所有屋顶的救援时间累加后向上取整。

### 算法分析

1. 读入 $n$。
2. 对每个屋顶，计算距离 $d = \sqrt{x^2+y^2}$，往返时间 $2d/50$，上船 $p \times 1$，下船 $p \times 0.5$。
3. 累加所有时间，最后用 `ceil()` 向上取整。

### 参考代码（C++）

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    double totalTime = 0;
    for (int i = 0; i < n; i++) {
        double x, y;
        int p;
        cin >> x >> y >> p;
        double dist = sqrt(x * x + y * y);
        totalTime += 2.0 * dist / 50.0 + p * 1.0 + p * 0.5;
    }
    cout << (int)ceil(totalTime) << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
