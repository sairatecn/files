# 药房管理

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

药房管理员已知每天初始库存 $m$ ，每天有 $n$ 名病人依次取药。每名病人希望取走指定数量，如果库存不足，将被拒绝。求每天被拒绝的病人数。

## 输入描述

第一行一个整数 $m$ ，表示初始药品数量。
第二行一个整数 $n$ ，表示病人数。
第三行 $n$ 个整数，每个表示病人希望取走的药品数量。

## 输出描述

一行一个整数，表示未能取到药品的病人数。

## 示例

### 用例输入 1

```text
10
5
20 6 7 8 4
```

### 用例输出 1

```text
3
```

---

## 题解

### 解题思路

模拟每个病人依次取药的过程。初始库存为 $m$，每个病人来取药时检查库存是否足够：若够则扣减库存，不够则被拒绝（拒绝计数 +1）。

### 算法分析

1. 读入 $m$（初始库存）和 $n$（病人数）。
2. 定义 `refused = 0`，循环 $n$ 次读入每个病人的需求量。
3. 若 `m >= need`，则 `m -= need`；否则 `refused++`。
4. 输出 `refused`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int m, n;
    cin >> m >> n;
    int refused = 0;
    for (int i = 0; i < n; i++) {
        int need;
        cin >> need;
        if (m >= need) {
            m -= need;
        } else {
            refused++;
        }
    }
    cout << refused << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
