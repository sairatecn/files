# 津津的储蓄计划

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

津津每月初得到300元零花钱，并根据预算花费。每月可将整百存入妈妈那里，年末妈妈会加上20％返还。

- 每月预算不超过手中可支配的钱，否则输出负号加月份。
- 计算到年末妈妈返还后的津津总钱数。

## 输入描述

12行，每行一个整数，表示1月到12月津津的预算。

## 输出描述

如果某个月预算超过可用钱，输出 -X（X为月份），否则输出年末总钱数。

## 示例

### 用例输入 1

```text
290
230
280
200
300
170
330
50
90
80
200
60
```

### 用例输出 1

```text
1580
```

---

## 题解

### 解题思路

模拟津津每月的收支过程。每月初津津手中有上月剩余 + 300 元零花钱。若当月预算超过可用金额则失败，输出负月份号。否则扣除预算后，将整百部分存入妈妈处，零头留在手中。年末妈妈返还存款 × 1.2，加上手中零头即为总数。

### 算法分析

1. 定义 `handMoney = 0`（手中钱）, `savedMoney = 0`（存妈妈处的钱）。
2. 循环 12 个月：每月 `handMoney += 300`，读入预算 `budget`。
3. 若 `handMoney < budget`，输出 `-月份` 并结束。
4. 否则 `handMoney -= budget`，存入 `saved = (handMoney / 100) * 100`，`savedMoney += saved`，`handMoney -= saved`。
5. 年末总数 = `savedMoney * 1.2 + handMoney`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int handMoney = 0, savedMoney = 0;
    for (int month = 1; month <= 12; month++) {
        int budget;
        cin >> budget;
        handMoney += 300;
        if (handMoney < budget) {
            cout << "-" << month << endl;
            return 0;
        }
        handMoney -= budget;
        int save = (handMoney / 100) * 100;
        savedMoney += save;
        handMoney -= save;
    }
    cout << (int)(savedMoney * 1.2 + handMoney) << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(1)$，固定 12 个月。
- **空间复杂度**：$O(1)$。
