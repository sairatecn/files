# 第n小的质数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入一个正整数 $n$ ，求第 $n$ 小的质数。 $n$ 的取值不超过 10000。

## 输入描述

一个正整数 $n$ $(1≤n≤10000)(1 \le n \le 10000)(1≤n≤10000)$ 。

## 输出描述

输出第 $n$ 小的质数。

## 示例

### 用例输入 1

```text
6
```

### 用例输出 1

```text
13
```

---

## 题解

### 解题思路

从 2 开始逐个判断是否为质数，每找到一个质数计数 +1，直到计数等于 $n$ 时输出当前数。判断质数用试除法：检查 $2$ 到 $\sqrt{x}$ 是否有因子。

### 算法分析

1. 读入 $n$。
2. 定义 `count = 0, num = 2`。
3. 循环：判断 `num` 是否为质数（试除法），若是则 `count++`；若 `count == n` 则输出 `num` 并结束。
4. `num++` 继续。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

int main() {
    int n;
    cin >> n;
    int count = 0, num = 2;
    while (true) {
        if (isPrime(num)) {
            count++;
            if (count == n) {
                cout << num << endl;
                return 0;
            }
        }
        num++;
    }
}
```

### 复杂度分析

- **时间复杂度**：$O(n \cdot \sqrt{p_n})$，其中 $p_n$ 是第 $n$ 个质数。$n \le 10000$ 时可接受。
- **空间复杂度**：$O(1)$。
