# 质因数分解

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知正整数 $n$ 是两个不同质数的乘积，求较大的那个质数。对于 60% 的数据， $6≤n≤10006 \le n \le 10006≤n≤1000$ ；对于 100% 的数据， $6≤n≤2×1096 \le n \le 2 \times 10^96≤n≤2×109$ 。

## 输入描述

一行输入一个正整数 $n$ 。

## 输出描述

输出一行，包含较大的那个质数 $p$ 。

## 示例

### 用例输入 1

```text
15
```

### 用例输出 1

```text
5
```

---

## 题解

### 解题思路

题目保证 $n$ 是两个不同质数的乘积。因此只需找到 $n$ 的最小质因子 $p$（从 2 开始逐个试除），则较大的质因子就是 $n / p$。由于 $p \le \sqrt{n}$，遍历到 $\sqrt{n}$ 即可。

### 算法分析

1. 读入 $n$。
2. 从 $i = 2$ 开始，若 $n \bmod i == 0$ 则 $i$ 是较小质因子，输出 $n / i$。
3. 题目保证有解，一定能找到。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            cout << n / i << endl;
            return 0;
        }
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\sqrt{n})$。
- **空间复杂度**：$O(1)$。
