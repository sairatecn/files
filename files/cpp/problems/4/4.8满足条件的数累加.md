# 满足条件的数累加

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

将正整数 $m$ 到 $n$ （包括 $m$ 和 $n$ ）之间所有能被 $17$ 整除的数进行累加，其中满足 $0<m<n<10000 < m < n < 10000<m<n<1000$ 。

## 输入描述

输入一行，包含两个整数 $m$ 和 $n$ ，两个数之间以一个空格分隔，满足 $0<m<n<10000 < m < n < 10000<m<n<1000$ 。

## 输出描述

输出一行，包含一个整数，表示满足条件的数的累加结果。

## 示例

### 用例输入 1

```text
50 85
```

### 用例输出 1

```text
204
```

---

## 题解

### 解题思路

遍历 $[m, n]$ 区间内的每个整数，判断是否能被 17 整除（即 `i % 17 == 0`），若满足则累加到结果中。

### 算法分析

1. 读入 $m$ 和 $n$。
2. 定义 `sum = 0`，从 $m$ 遍历到 $n$。
3. 对每个数判断 `i % 17 == 0`，满足则 `sum += i`。
4. 输出 `sum`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int m, n;
    cin >> m >> n;
    int sum = 0;
    for (int i = m; i <= n; i++) {
        if (i % 17 == 0) {
            sum += i;
        }
    }
    cout << sum << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n - m)$。
- **空间复杂度**：$O(1)$。
