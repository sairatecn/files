# 级数求和

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知调和级数 $Sn=1+1/2+1/3+...+1/nS_n = 1 + 1/2 + 1/3 + ... + 1/nSn​=1+1/2+1/3+...+1/n$ ，对于给定整数 $k$ $(1≤k≤15)(1 \le k \le 15)(1≤k≤15)$ ，求最小整数 $n$ 使得 $Sn>kS_n > kSn​>k$ 。

## 输入描述

输入一个整数 $k$ $(1≤k≤15)(1 \le k \le 15)(1≤k≤15)$ 。

## 输出描述

输出一个整数 $n$ ，满足 $Sn>kS_n > kSn​>k$ 的最小值。

## 示例

### 用例输入 1

```text
5
```

### 用例输出 1

```text
83
```

---

## 题解

### 解题思路

调和级数 $S_n = 1 + 1/2 + 1/3 + \dots + 1/n$ 是递增的。从 $n = 1$ 开始累加，直到 $S_n > k$ 时停止，输出当前的 $n$。

### 算法分析

1. 读入 $k$。
2. 定义 `sum = 0, n = 0`。
3. 当 `sum <= k` 时：`n++`，`sum += 1.0 / n`。
4. 输出 $n$。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int k;
    cin >> k;
    double sum = 0;
    int n = 0;
    while (sum <= k) {
        n++;
        sum += 1.0 / n;
    }
    cout << n << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(e^k)$，调和级数增长极慢，但 $k \le 15$ 时 $n$ 最大约 $1.8 \times 10^6$，完全可接受。
- **空间复杂度**：$O(1)$。
