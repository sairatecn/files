# 最大跨度值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

给定一个长度为 $n$ 的非负整数序列，计算该序列的最大跨度值（最大跨度值 = 最大值 − 最小值）。

## 输入描述

输入共两行：

- 第一行为一个整数 $n$ ( $1≤n≤10001 \le n \le 10001≤n≤1000$ )，表示序列长度；
- 第二行为 $n$ 个不超过 $1000$ 的非负整数，整数之间以一个空格分隔。

## 输出描述

输出一行，表示该序列的最大跨度值。

## 示例

### 用例输入 1

```text
6
0 8 7 5 9 3
```

### 用例输出 1

```text
9
```

---

## 题解

### 解题思路

本题要求计算一个非负整数序列的"最大跨度值"，即序列中最大值与最小值之差。核心思路非常直接：遍历整个序列，在遍历过程中同时维护当前遇到的最大值和最小值，最终输出两者的差即可。

### 算法分析

1. 读入序列长度 $n$。
2. 初始化 `maxVal` 为一个极小值（如 $-1$），`minVal` 为一个极大值（如 $10001$），确保第一个输入元素一定能更新这两个变量。
3. 依次读入 $n$ 个整数，每读入一个数就与 `maxVal` 和 `minVal` 比较并更新。
4. 遍历结束后，输出 `maxVal - minVal`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int maxVal = -1, minVal = 10001;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x > maxVal) maxVal = x;
        if (x < minVal) minVal = x;
    }

    cout << maxVal - minVal << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$，仅需一次遍历。
- **空间复杂度**：$O(1)$，只需常数级别的额外空间存储最大值和最小值。
