# 含k个3的数

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

输入两个正整数 $m$ 和 $k$ ，判断 $m$ 是否能被19整除且恰好包含 $k$ 个数字3。如果满足条件，输出 YES，否则输出 NO。

## 输入描述

输入一行，包含两个正整数 $m$ 和 $k$ ，中间用空格分隔，其中 $1<m<100000$ ， $1<k<5$ 。

## 输出描述

满足条件输出 YES，否则输出 NO。

## 示例

### 用例输入 1

```text
43833 3
```

### 用例输出 1

```text
YES
```

---

## 题解

### 解题思路

需要同时满足两个条件：① $m$ 能被 19 整除；② $m$ 的十进制表示中恰好有 $k$ 个数字 3。条件 ② 可通过逐位取余检查每一位是否为 3 来统计。

### 算法分析

1. 读入 $m$ 和 $k$。
2. 先检查 `m % 19 == 0`，若不满足直接输出 `NO`。
3. 统计 $m$ 中数字 3 的个数：循环取余 `m % 10`，若为 3 则计数 +1，`m /= 10`。
4. 若计数等于 $k$ 则输出 `YES`，否则 `NO`。

### 参考代码（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    int m, k;
    cin >> m >> k;
    if (m % 19 != 0) {
        cout << "NO" << endl;
        return 0;
    }
    int cnt = 0, temp = m;
    while (temp > 0) {
        if (temp % 10 == 3) cnt++;
        temp /= 10;
    }
    if (cnt == k) cout << "YES" << endl;
    else cout << "NO" << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(\log_{10} m)$。
- **空间复杂度**：$O(1)$。
