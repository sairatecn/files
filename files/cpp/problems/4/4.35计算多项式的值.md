# 计算多项式的值

## 题目信息

- 时间限制：C/C++ 1000MS，其他语言 2000MS
- 内存限制：C/C++ 256MB，其他语言 512MB

## 题目描述

已知多项式 $P(x)=xn+xn−1+⋯+x2+x+1P(x) = x^n + x^{n-1} + \dots + x^2 + x + 1P(x)=xn+xn−1+⋯+x2+x+1$ ，给定一个实数 $x$ 和整数 $n$ ，计算 $P(x)$ 的值，结果保留两位小数。

## 输入描述

输入一行，包含一个实数 $x$ 和一个正整数 $n$ （ $n≤106n \le 10^6n≤106$ ），用单个空格分隔。

## 输出描述

输出多项式 $P(x)$ 的值，保留小数点后两位。

## 示例

### 用例输入 1

```text
2.0 4
```

### 用例输出 1

```text
31.00
```

---

## 题解

### 解题思路

多项式 $P(x) = x^n + x^{n-1} + \dots + x + 1$ 可用秦九韶算法（Horner 方法）高效计算：$P(x) = (\dots((x+1)\cdot x + 1)\cdot x + 1)\dots)$。这样每次迭代只需一次乘法和一次加法，避免了重复计算幂次。

### 算法分析

1. 读入 $x$ 和 $n$。
2. 定义 `result = 1`（常数项），循环 $n$ 次：`result = result * x + 1`。
3. 输出 `result`，保留 2 位小数。

### 参考代码（C++）

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x;
    int n;
    cin >> x >> n;
    double result = 1;
    for (int i = 0; i < n; i++) {
        result = result * x + 1;
    }
    cout << fixed << setprecision(2) << result << endl;
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(n)$。
- **空间复杂度**：$O(1)$。
